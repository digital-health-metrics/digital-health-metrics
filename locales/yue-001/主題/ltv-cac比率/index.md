# LTV 對 CAC 比率

LTV 對 CAC 比率將客戶終身價值（LTV）——機構預期喺病人或客戶同產品整段關係期間賺取嘅總收入或利潤——同獲取該客戶嘅真實成本（見真實獲客成本）作比較。佢係判斷數碼健康機構增長係咪財務上可持續嘅最重要單位經濟指標，因為以虧損方式獲取而增長嘅客戶群，無論增長曲線睇落幾正面，都唔係健康嘅標誌。

## 點解重要

如果獲客成本超過終身價值，數碼健康機構可以穩步增長用戶群，同時喺每名新客戶身上悄悄地破壞價值；LTV 對 CAC 比率係令呢個情況變得可見嘅指標，單靠增長率或者原始客戶數目做唔到。3:1 比率（終身價值至少係獲客成本嘅三倍）係可持續訂閱或者經常性收入業務廣泛引用嘅基準，容許有足夠利潤去覆蓋獲客以外嘅營運成本，並且仍然產生回報；低於 1:1 嘅比率意味住機構喺每名獲取嘅客戶身上都蝕錢，而遠高於 3:1 嘅比率（例如 10:1 或者更高）實際上可以顯示增長投資不足，因為佢暗示機構可以有利潤咁獲取比目前更多嘅客戶。評估數碼健康公司財務可持續性嘅投資者、董事會同付款方，將呢個比率視為首批會問嘅數字之一。

## 點計算

```
LTV = 每名客戶每期平均收入（或利潤）× 同一期間單位下嘅
      平均客戶壽命

LTV 對 CAC 比率 = LTV / 真實 CAC

3:1 嘅比率係常被引用嘅可持續基準；低於 1:1
顯示機構喺獲客上蝕錢；遠高於 3:1
（例如 10:1 以上）可以顯示增長投資不足。
```

## 計算示例

一項數碼健康訂閱服務，每名病人產生平均每月收入 $40，而平均病人維持訂閱 18 個月，得出 LTV 為 $40 × 18 = $720。呢項服務嘅真實 CAC（見該主題嘅計算示例方法）計算為每名獲取病人 $180。LTV 對 CAC 比率為 $720 / $180 = 4:1，穩穩高於 3:1 嘅可持續基準。如果真實 CAC 只係用廣告平台匯報嘅成本（$120，未計入代理費用同接收人手）去計算，比率就會顯示為 6:1——比真實 4:1 數字，係實質上更有利、亦具誤導性嘅單位經濟圖像。

## 數據來源同注意事項

LTV 取決於有關平均客戶壽命嘅假設，而該假設本身係由機構自己嘅留存或者流失數據推算（見用戶留存率）——流失率高嘅業務，有效平均壽命較短，因此 LTV 較低，即使其每名客戶每期收入睇落健康。由於 LTV 係前瞻性估算而非已觀察到嘅歷史事實，所以應該隨留存數據累積而定期重新計算，並喺流失假設證實有誤時修訂，而唔係固定一次就任由過時。喺呢個比率中使用平台匯報嘅 CAC 而唔係真實 CAC，係機構可以令自己相信單位經濟比實際更健康嘅最常見方式之一，因為被低估嘅 CAC 會機械式咁膨脹比率。

## 常見陷阱

- **使用平台匯報嘅 CAC 而唔係真實 CAC**：咁樣會機械式咁膨脹比率，可以令不可持續嘅獲客策略睇落可持續；應該永遠使用全面負擔嘅真實 CAC 數字。
- **使用過時或者樂觀嘅平均客戶壽命假設**：根據過時留存曲線計算出嚟嘅 LTV，無法反映當前嘅流失行為，尤其係喺產品、定價或者市場改變令留存率轉變之後。
- **將極高比率視為絕對有利**：遠高於 3:1 嘅比率可能顯示增長投資不足，而非卓越效率，因為佢意味機構可能可以有利潤咁獲取比目前更多嘅客戶。
- **跨差異極大嘅客戶群計算單一混合比率**：收入高、流失低嘅客戶群，可以掩蓋另一個單位經濟欠佳嘅客戶群；喺數量許可嘅情況下，應該按有意義嘅客戶群（例如按獲客渠道或者產品線）計算比率。
