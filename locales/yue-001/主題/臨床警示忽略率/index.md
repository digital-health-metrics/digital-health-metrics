# 臨床警示忽略率

臨床警示忽略率量度臨床決策支援（CDS）警示，例如由電腦化醫囑輸入（CPOE）系統產生嘅藥物相互作用警告、過敏警示同劑量範圍檢查，被臨床人員忽略或者推翻而唔跟從行動嘅比例。佢係用嚟偵測同管理「警示疲勞」嘅標準量化訊號：當低價值警告數量多到令人應接不暇，臨床人員就會對警示麻木，呢個傾向有充分嘅文獻記錄。

## 點解重要

已發表嘅藥物相互作用警示忽略率，一般介乎約一半至超過百分之九十，而高比率並唔會自動等於安全失誤：好多打斷式警示係針對喺臨床情境中並不重要嘅相互作用而觸發，或者重複臨床人員早前喺同一組醫囑入面已經處理過嘅警示，所以一個調校良好嘅系統會刻意觸發較少、價值較高嘅警示，而唔係試圖將忽略率推至零。對安全真正重要嘅，係隨時間嘅趨勢、各嚴重程度層級嘅分佈，以及臨床人員喺忽略高嚴重程度警示時有冇記錄原因；即使所有警示嘅平均值睇落穩定，針對高嚴重程度、證據充分嘅相互作用嘅忽略率上升，都係真正嘅管治關注事項。

## 點計算

```
忽略率 = 被忽略嘅警示 / 觸發嘅警示總數 × 100

按以下方面分層：
  - 嚴重程度層級（例如禁忌、重大、中度）
  - 警示類型（藥物相互作用、過敏、重複治療、劑量範圍）
  - 有冇記錄忽略原因

「有記錄忽略率」追蹤附有已記錄理由嘅忽略所佔比例，
呢個本身就係一項管治量度。
```

## 計算示例

一間醫院嘅 CPOE 系統喺一個月內觸發 10,000 個藥物相互作用警示，其中 8,700 個被忽略，整體忽略率為 87%。按嚴重程度分層顯示，喺 500 個「禁忌」警示之中，有 60 個被忽略（12%），而 6,000 個「中度」警示之中，有 5,700 個被忽略（95%）。中度層級嘅數字同已發表基準大致一致，本身唔係令人擔憂嘅理由；禁忌層級嘅數字就需要個別個案檢討，而該層級 500 個被忽略嘅警示之中，只有 340 個附有已記錄原因，先係更具可操作性嘅管治發現。

## 數據來源同注意事項

電子健康紀錄嘅審計日誌，或者 CDS 供應商本身嘅警示模組，會記錄每個警示觸發同警示回應事件，包括臨床人員有冇輸入自由文字或結構化嘅理由。比較不同機構，甚至同一機構內不同部門嘅忽略率，需要檢查底層嘅警示規則集同嚴重程度分層係咪相同；一間警示規則調校得好進取嘅醫院，會顯示較低嘅忽略率，原因同臨床人員行為完全無關。

## 常見陷阱

- **將原始忽略率視為單一安全分數**：佢將對低價值警示有充分理由嘅忽略，同對真正危險嘅相互作用嘅不安全忽略混為一談；應該永遠按嚴重程度分層。
- **冇記錄忽略原因**：冇已記錄嘅原因，就無法分辨「呢個警示係錯嘅」同「呢個警示係啱嘅，而臨床人員作出咗不安全嘅判斷」，而後者先係對病人安全真正重要嘅區別。
- **警示規則隨時間膨脹**：為咗「保險起見」而增加更多警示，卻唔精簡低價值警示，係忽略率上升同警示疲勞嘅直接成因；警示管治應該包括定期檢討同淘汰表現欠佳嘅規則，而唔只係監察。
- **比較打斷設計唔同嘅系統嘅比率**：打斷式、強制停止嘅警示，同被動、唔阻擋嘅警示會產生唔同嘅忽略行為，所以兩者並非可直接比較嘅指標。
