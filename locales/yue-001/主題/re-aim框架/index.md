# RE-AIM 框架

RE-AIM 係一個公共衞生評估框架，從五個截然不同嘅維度——觸及（Reach）、成效（Effectiveness）、採用（Adoption）、實施（Implementation）同維持（Maintenance）——評估數碼健康干預措施，而唔係靠任何單一指標。佢存在嘅目的，係糾正數碼健康評估中一個特定而常見嘅失敗模式：一個計劃從細小、積極嘅試點人群匯報令人印象深刻嘅成效數據，卻從未被大規模採用，或者喺獲資助嘅試點期過後從未持續，實際上並冇展示出公共衞生價值，無論孤立睇其總體結果數字幾好。

## 點解重要

數碼健康試點經常只按成效去評估——使用者嘅結果指標有冇改善——而其他四個維度則未被量度或匯報，咁樣會系統性咁令證據基礎偏向喺理想、細規模條件下運作良好嘅干預措施，但完全冇說明佢哋係咪可以大規模運作、觸及最需要佢哋嘅人群，或者喺初期資助同熱情過後仍然存續。RE-AIM 專門為咗迫使評估者連同內部效度（呢度有冇效）一齊匯報外部效度（呢樣嘢喺其他地方會唔會有效、對邊啲人有效）而開發，對於任何根據單一研究或試點結果去決定是否資助、委託或擴展數碼健康干預措施嘅人嚟講極為重要。由於五個維度各自都可以喺個人層面同機構或環境層面量度，RE-AIM 亦會揭示取捨——例如一項由高度挑選、受過高度訓練嘅人員提供嘅高成效干預（成效強，但採用嘅代表性弱）——而單一合併指標會將呢啲完全隱藏。

## 點應用

```
觸及（Reach）          = 參與嘅合資格目標人群比例，以及
                         參與者對該合資格人群嘅代表程度
                         （而唔單止係原始參與者數目）

成效（Effectiveness）  = 對主要結果嘅影響，包括生活質素
                         同非預期嘅負面後果，而唔單止
                         係單一嘅總體結果指標

採用（Adoption）       = 採用該干預措施嘅環境同人員／
                         提供者，相對於所有合資格環境同
                         人員嘅比例同代表性

實施（Implementation） = 按原定方式提供嘅一致性同忠實度、
                         提供所需嘅時間同成本，以及
                         過程中作出嘅調適

維持（Maintenance）    = 干預措施長期成為常規做法嘅程度，
                         包括個人層面（持續嘅個人層面效果）
                         同環境／機構層面（制度化）
```

## 計算示例

一個數碼糖尿病預防計劃喺一個擁有 200 間合資格診所嘅地區，於 20 間基層醫療診所試點。觸及被評估為喺 20 間試點診所約 15,000 名合資格病人之中有 1,200 人參與（8%），而參與者被發現比全體合資格人群稍為年輕同數碼素養較高——呢個代表性差距值得注意而唔係忽略。成效顯示完成者之中平均 HbA1c 有具臨床意義嘅下降，但高退出率意味住喺所有已登記病人（而非只係完成者）按意向治療分析基準評估時，呢個效果被稀釋。採用為 200 間合資格診所之中有 20 間（10%），集中喺現有數碼基礎設施高於平均嘅診所——同樣係代表性問題。實施忠實度評估發現，大部分診所基本上按設計提供計劃，不過有兩間診所喺時間壓力下大幅縮短咗上手流程。喺試點資助結束一年後嘅維持評估發現，原本 20 間診所之中只有 6 間仍然積極運行計劃——呢個結果連同最初令人鼓舞嘅成效數字一齊匯報，比單靠成效數據，更完整同誠實咁反映計劃喺現實世界嘅前景。

## 數據來源同注意事項

RE-AIM 每個維度通常取材自唔同嘅數據來源：觸及同採用來自登記同資格紀錄；成效來自臨床或結果數據（往往係本書其他地方已用嚟計算特定指標嘅同一批數據，例如生物指標改善率）；實施來自忠實度檢查表、提供日誌或直接觀察；而維持則來自喺初步評估期過後好耐先進行嘅跟進評估——意味住完整嘅 RE-AIM 評估無法喺單一時間點完成，需要由一開始就計劃好評估，而唔係事後補加。由於誠實匯報全部五個維度（包括部分維度嘅薄弱結果）比只匯報成效更費功夫、亦更不討好，所以已發表嘅數碼健康評估，相比成效，不成比例咁少匯報觸及、採用同維持——呢個係已知嘅發表偏差模式，任何使用貼有 RE-AIM 標籤嘅證據去作出決定嘅人都應該留意。

## 常見陷阱

- **只匯報成效就稱為 RE-AIM 評估**：使用 RE-AIM 名稱，卻只匯報五個維度之中嘅一個，違背咗框架嘅目的，唔應該被描述為 RE-AIM 評估。
- **將觸及同採用以原始數目而非合資格人群比例量度**：龐大嘅原始參與者數目，仍然可能只代表干預措施理應觸及對象嘅一小部分、缺乏代表性；應該永遠按完整嘅合資格分母計算。
- **太早評估維持**：制度化同持續效果，只有喺初期資助或新鮮感消退之後好耐先可以判斷；喺試點結束後即時進行嘅評估，無論其他四個維度睇落點，都無法說明維持情況。
- **將五個維度視為同等權重或者可以合併成單一分數**：RE-AIM 刻意係多維度嘅概況，而非單一數字；將維度合併成一個綜合分數，會丟棄框架正正旨在保留嘅取捨可見性。
