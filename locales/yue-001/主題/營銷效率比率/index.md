# 營銷效率比率

營銷效率比率（Marketing Efficiency Ratio，MER）係指某界定時期內，總收入除以所有渠道嘅總營銷開支。佢係刻意作為平台匯報嘅廣告開支回報率（ROAS）嘅獨立現實檢查而存在：ROAS 量度每個渠道自己聲稱對收入嘅貢獻，結構上容易過度記功——而 MER 則係比較總收入同總開支，呢個數字係冇任何單一廣告平台可以扭曲嘅。

## 點解重要

每個廣告平台都使用自己嘅歸因模型匯報 ROAS，而由於大部分機構同時運行多個渠道，同一名轉化客戶經常被多於一個平台記功，所以各平台自行匯報嘅 ROAS 總和，同實際總收入比較時，通常會高估營銷總貢獻。MER 喺機構層面比較總收入同總開支，完全繞過呢個問題，令佢難以透過歸因操弄或者偏向平台嘅匯報而被扭曲，亦正正係點解財務同行政團隊越嚟越多將佢視為值得信賴嘅頂層效率檢查，用嚟校準個別平台匯報嘅數字。如果一個營銷團隊喺每個個別渠道都匯報強勁嘅 ROAS，而整體 MER 卻不斷下降，就存在真正嘅效率或者歸因重疊問題，單靠渠道層面嘅匯報並唔會揭示出嚟。

## 點計算

```
MER = 總收入 / 總營銷開支（所有渠道，同一時期）

唔似 ROAS，MER 唔按渠道計算——佢係單一嘅
全機構數字，正正因為佢嘅價值在於
不受任何單一平台歸因聲稱影響。

MER 隨時間上升而開支維持穩定或者增長，顯示整體
營銷效率改善；收入增長而 MER 穩定，可以
顯示增長來自並非由營銷帶動嘅來源
（例如轉介、自然搜尋、口碑）。
```

## 計算示例

一間數碼健康公司喺一個季度內產生 $2,400,000 收入，所有付費渠道嘅總營銷開支為 $480,000。MER 為 $2,400,000 / $480,000 = 5.0。個別而言，付費搜尋平台匯報 ROAS 為 6.0，付費社交平台匯報 ROAS 為 5.5，程式化展示平台匯報 ROAS 為 4.0——如果將呢啲數字簡單相加，作為對總收入貢獻嘅聲稱，就會暗示比公司實際產生更多嘅歸因收入，因為相當一部分轉化客戶接觸過多於一個渠道，被重複或者三重計算。全機構 MER 5.0 就係調和呢個差異嘅數字：佢唔會似平台層面嘅 ROAS 數字咁，在結構上被歸因重疊所膨脹。

## 數據來源同注意事項

總收入來自機構自己嘅財務或者賬單系統，而總營銷開支來自所有渠道實際已開發票同已支付嘅營銷成本——兩者都應該獨立於任何廣告平台自己嘅儀表板取得。MER 應該作為隨時間嘅趨勢追蹤，而唔係對照單一通用基準去判斷，因為「好」嘅 MER 會因業務模式、利潤結構同增長階段而差異極大：一間大力投資增長嘅早期公司，可能刻意接受比專注盈利嘅成熟公司更低嘅 MER。MER 並無診斷邊個渠道要為效率變化負責——呢項診斷工作仍然需要渠道層面嘅分析，最好輔以增量測試（唔接觸任何營銷嘅對照組），而唔係單靠平台匯報嘅歸因。

## 常見陷阱

- **將平台匯報嘅 ROAS 視為跨渠道可相加**：每當客戶接觸並被多於一個渠道記功（呢個好常見），將各平台自行匯報嘅 ROAS 相加，就會高估營銷總貢獻；MER 喺設計上避免咗呢個問題。
- **將 MER 同固定嘅通用基準比較**：適當嘅 MER 因業務模式、利潤同增長階段而異；應該將佢用作單一機構隨時間嘅趨勢，而唔係固定嘅合格／不合格門檻。
- **將 MER 當成渠道層面嘅診斷工具**：MER 刻意係全機構數字，本身無法識別邊個渠道帶動效率變化；為咗呢個目的，應該配合渠道層面分析同增量測試。
- **忽略非營銷嘅收入驅動因素**：收入增長而 MER 穩定或者改善，可以反映自然增長（轉介、口碑、贏得媒體）而非營銷效率；盡可能按獲客來源分拆收入，以免過度歸功於營銷。
