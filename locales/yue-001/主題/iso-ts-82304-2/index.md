# ISO/TS 82304-2

ISO/TS 82304-2 係一份國際技術規範，由 ISO 技術委員會 215（健康資訊學）發布，界定一套結構化方法，用嚟評估健康同保健應用程式嘅質素——涵蓋易用性、技術穩健性同可靠性、互操作性、內容質素，以及數據保安同私隱——適用於唔屬於完整醫療器械監管範圍、但仍然實質影響用戶健康決定或行為嘅產品。佢存在係為咗填補一個特定嘅缺口：絕大部分面向消費者嘅健康同保健應用程式（健身追蹤器、症狀日記、保健輔導應用程式）並未被監管為醫療器械，但以往並冇通用、結構化嘅方法去評估或者比較佢哋嘅基本質素同安全性。

## 點解重要

應用程式商店有數十萬個健康同保健應用程式，質素參差極大，而喺通用技術規範出現之前，病人、臨床人員或者醫療系統，除咗星級評分同營銷聲稱之外，並冇結構化、可比較嘅方法去判斷一個應用程式相比另一個嘅基本質素同安全性——呢個差距好重要，因為設計欠佳嘅健康應用程式，即使未達到醫療器械嘅監管門檻，仍然可以造成真正嘅傷害（內容不準確、數據保安欠佳、聲稱具誤導性）。ISO/TS 82304-2 刻意圍繞非專業審閱者可以一致評估嘅範疇而構建，令佢成為好幾個全國同商業健康應用程式質素標籤同策展服務嘅技術基礎，畀醫療系統同應用程式庫一個站得住腳、標準化嘅方法，去將應用程式納入或者排除出推薦名單，而唔係依賴臨時判斷。

## 點應用

```
評估圍繞界定嘅質素範疇組織，
透過結構化審閱而非單一數字公式進行評價：

易用性                — 對目標用戶群嘅清晰度、
                        無障礙程度同易用程度
技術穩健性／可靠性    — 穩定性、效能同
                        冇技術缺陷
互操作性              — 喺同應用程式功能相關嘅情況下，
                        與其他系統交換數據嘅能力
內容質素與安全性      — 準確性、時效性，以及冇有害或
                        誤導性嘅健康聲稱
保安與私隱            — 數據保護做法同
                        數據使用嘅透明度

每個範疇透過結構化審閱準則計分，並合併成整體
質素評估，好幾個健康應用程式質素標籤計劃
將其用作公開質素標籤或策展庫納入決定嘅
技術基礎。
```

## 計算示例

一個醫療系統嘅數碼應用程式庫計劃，想為病人策展一份推薦嘅保健應用程式名單，而唔係完全交由應用程式商店搜尋去選擇。每個候選應用程式都按 ISO/TS 82304-2 嘅範疇評估：一個睡眠追蹤應用程式喺易用性同技術穩健性方面得分良好，內容質素尚算足夠，但喺保安同私隱審閱期間被標記為未有清晰披露就將用戶數據分享畀第三方廣告商——呢個發現嚴重到足以將該應用程式排除出推薦名單，儘管其易用性分數其他方面強勁。呢種逐個範疇嘅結果，對策展團隊同（如果分享）應用程式嘅開發者本身而言，都比單一混合質素分數更具可操作性，因為佢精確識別出邊個方面需要補救，先可以重新考慮該應用程式。

## 數據來源同注意事項

按 ISO/TS 82304-2 嘅評估，通常由受過訓練嘅審閱者或者認可嘅評估服務，按該規範針對每個範疇嘅結構化審閱準則進行，而好幾個全國同商業計劃（健康應用程式質素標籤同策展機構，部分喺正式嘅國家衞生系統認可下運作）將該標準用作其自身面向公眾嘅應用程式質素標籤嘅技術基礎——意味住應用程式嘅「已認證」或者「已貼標籤」狀態，實際上往往反映特定標籤計劃對該標準嘅實施，而唔一定係所有計劃之間完全相同嘅過程，所以引用任何質素標籤時，應該查核同披露具體嘅評估機構及其方法。該規範評估嘅係應用程式作為軟件嘅質素同基本安全特徵；喺應用程式嘅聲稱或功能實際達到醫療器械門檻之處，佢並唔能取代醫療器械監管許可，將佢當成取代係範疇錯誤。

## 常見陷阱

- **將質素標籤視為監管許可**：按 ISO/TS 82304-2 評估同貼上標籤嘅應用程式，並未因此獲得醫療器械監管批准；兩者用途唔同，喺描述或營銷應用程式時絕不應該混為一談。
- **假設所有基於該標準嘅標籤計劃都相同**：唔同機構以自己特定嘅審閱流程同嚴謹程度實施基於 ISO/TS 82304-2 嘅評估；應該查核邊個機構進行評估同點樣進行，而唔係將任何「基於 ISO/TS 82304-2」嘅標籤視為可同任何其他標籤互換。
- **只評估易用性而忽略保安同私隱**：易用性問題對終端用戶最明顯，亦最容易非正式評估，可能令審閱者低估較唔明顯但潛在影響更大嘅保安同私隱範疇。
- **將評估視為一次性、永久嘅認證**：應用程式嘅內容、保安做法同第三方數據分享安排，喺初次評估之後都可以改變；可信嘅質素標籤計劃會定期重新評估，而唔係將初次通過視為永久。
