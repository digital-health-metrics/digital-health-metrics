# 數碼素養率

數碼素養率量度病人人群之中，能夠獨立而成功咁喺數碼健康平台上完成常見任務——登入、預約、加入視像診症或者閱讀檢驗結果——而無需他人協助嘅比例。佢有別於數碼接達率，亦應該永遠同數碼接達率分開量度：一位病人可以有智能手機同寬頻連線，但仍然無法獨立操作遠程醫療平台，而將兩個指標混為一談，會隱藏呢個指標存在嘅目的正正要揭示嘅人群。

## 點解重要

單靠數碼接達並唔保證病人可以有效使用數碼健康服務：健康素養較低、對科技普遍經驗有限、有認知或視覺障礙，或者同平台介面存在語言障礙嘅病人，即使擁有完整嘅技術接達，仍然可能無法獨立完成任務，而且呢個差距同已經面對其他健康差距嘅相同人口群組有系統性相關。HIMSS Digital Health Equity Measurement Framework 正正因為咁，將數碼素養視為同接達有別嘅獨立支柱：縮窄接達差距而冇同時處理素養差距，可以令人群喺技術上已連線，但實際上無法受惠。量度常見平台操作嘅任務完成率同完成時間，並按語言同社會經濟指標分層嘅機構，比起單靠接達指標或者整體滿意度分數嘅機構，可以更準確咁識別素養障礙，並針對性提供支援（簡化介面、協助上手、其他語言內容）。

## 點計算

```
數碼素養率 = 獨立完成界定任務而冇協助嘅病人 /
             嘗試該任務嘅病人 × 100

常見量度任務：帳戶登入、預約、加入
視像診症、查閱檢驗結果、完成接收表格。

按任務匯報，而唔係單一混合分數，因為簡單任務（登入）
同複雜任務（完成多步驟接收表格）嘅素養差異顯著，
混合會掩蓋具體障礙喺邊度。
```

## 計算示例

一個醫療系統將加入視像診症界定為任務，追蹤一個月內 5,000 次已安排嘅遠程醫療預約。其中 4,100 名病人冇需要任何支援電話或者診症期間嘅技術協助就成功加入（呢項任務嘅數碼素養率：82%）。按主要語言分拆顯示，說英語嘅病人比率為 89%，而主要語言同平台預設介面語言唔同嘅病人則為 61%——呢個 28 個百分點嘅差距，如果只匯報混合嘅 82% 數字就完全睇唔到，而佢直接指向一個具體、可以處理嘅干預措施（翻譯介面同說明），而唔係模糊嘅一般素養問題。

## 數據來源同注意事項

任務完成數據通常從平台本身嘅事件日誌捕捉（病人有冇到達視像診症、預約流程有冇冇被放棄而完成），並輔以支援電話或者服務台聯絡數據，以識別技術上「已完成」、但實際上係因為病人喺中途獲得實時協助嘅任務。純粹由系統日誌計為「已完成」嘅任務，可以掩蓋病人需要家人或支援人員打電話先可以完成嘅情況——喺平台可以區分兩者嘅地方，真正同素養無關嘅完成，應該同有協助嘅完成分開界定同追蹤。數碼素養同健康素養同一般素養有相關但在分析上有別；需要正式評估時，應該使用經驗證嘅工具，而唔係單憑年齡或人口特徵嘅非正式假設。

## 常見陷阱

- **將數碼素養同數碼接達混為一談**：擁有完整技術接達嘅病人，仍然可能缺乏有效使用嘅素養；呢兩者係需要獨立干預嘅分開指標，絕不應該作為單一合併數字匯報。
- **將有協助嘅完成計為獨立成功**：如果病人只係靠支援電話或者家人幫助先完成任務，呢個係平台掩飾咗而非解決咗嘅素養差距；喺數據許可嘅情況下，應該區分有協助同獨立完成。
- **匯報單一混合任務完成分數**：簡單任務（登入）同複雜任務（完成詳細接收表格）嘅素養差異顯著；按任務匯報，以準確識別障礙所在。
- **假設單靠年齡可以預測數碼素養**：雖然整體而言年齡同較低數碼素養相關，但喺平台介面語言嘅語言能力同一般科技熟悉度，往往係更強嘅個人預測因素，應該直接量度而唔係由年齡推斷。
