# LTV与CAC比率

LTV与CAC比率将客户生命周期价值（LTV）——机构预期从一名患者或客户与产品个整个关系中获得个总收入或利润——与获取该客户个真实成本（参见真实客户获取成本）进行比较。这是判断数字健康机构增长是否具有财务可持续性个单一最重要个单位经济指标，因为如果获取成本超过生命周期价值，不断增长个客户基础实际上是在亏损，无论增长曲线看起来多么积极，都勿是健康个迹象。

## 为何重要

一家数字健康机构可能在稳步扩大用户基础个同时，悄悄地在每一位新客户身上摧毁价值——只要获取成本超过生命周期价值；LTV与CAC比率是唯一能够以增长率或原始客户数无法做到个方式，将这一点变得可见个指标。3:1个比率（生命周期价值至少是获取成本个三倍）是被广泛引用个可持续订阅或经常性收入业务个基线基准，能留出足够个利润来覆盖获取之外个运营成本并仍能产生回报；低于1:1个比率意味着机构在每获取一名客户上都在亏钱，而远高于3:1（例如10:1或更高）个比率实际上可能表明增长投资不足，因为这暗示该机构本可以盈利地获取比目前更多个客户。评估数字健康公司财务可持续性个投资者、董事会和支付方，都将这一比率视为伊拉最先要求了解个数字之一。

## 计算方法

```
LTV = 每位客户每期的平均收入（或利润）× 该期间单位下的
      平均客户生命周期

LTV与CAC比率 = LTV / 真实CAC

3:1是被普遍引用的可持续基线；低于1:1表明机构在获取上
亏钱；远高于3:1（例如10:1以上）可能表明增长投资不足。
```

## 实例解析

某数字健康订阅服务每位患者个平均月收入为40美元，平均患者保持订阅18个月，得出LTV为40美元 × 18 = 720美元。该服务个真实CAC（参见该主题个实例解析方法）计算为每获取一名患者180美元。LTV与CAC比率为720 / 180 = 4:1，舒适地高于3:1个可持续基线。如果真实CAC仅使用广告平台报告个成本（120美元，未计入代理费用和接诊人力）计算，该比率将显示为6:1——这是一幅比真实个4:1数字明显更有利、也更具误导性个单位经济图景。

## 数据来源与注意事项

LTV依赖于对平均客户生命周期个假设，而该假设本身又源自机构自身个留存或流失数据（参见用户留存率）——流失率高个企业其有效平均生命周期更短，因此LTV更低，即使其每期每客户收入看起来不错也是如此。由于LTV是一个前瞻性估算而非已观察到个历史事实，应随留存数据个积累而定期重新计算，并在流失假设被证明有误时予以修正，而非一次性设定后便任其陈旧。在这一比率中使用平台报告个CAC而非真实CAC，是机构说服自己相信其单位经济状况比实际更健康个最常见方式之一，因为被低估个CAC会机械地虚增该比率。

## 常见误区

- **使用平台报告个CAC而非真实CAC**：这会机械地虚增该比率，并可能使不可持续个获取策略看起来可持续；应始终使用完全负载个真实CAC数字。
- **使用陈旧或乐观个平均客户生命周期假设**：根据过时个留存曲线计算出个LTV，无法反映当前个流失行为，尤其是在产品、定价或市场变化改变留存之后。
- **将非常高个比率视为绝对良好**：远高于3:1个比率可能表明增长投资不足，而非卓越效率，因为它暗示该机构蛮可能能够盈利地获取比目前更多个客户。
- **对差异蛮大个客户细分市场计算单一综合比率**：一个收入高、流失低个细分市场可能掩盖另一个单位经济状况不佳个细分市场；在数据量允许个情况下，应按有意义个细分（例如获取渠道或产品线）计算该比率。
