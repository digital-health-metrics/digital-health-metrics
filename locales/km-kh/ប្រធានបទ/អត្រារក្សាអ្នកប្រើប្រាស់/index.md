# អត្រារក្សាអ្នកប្រើប្រាស់

អត្រារក្សាអ្នកប្រើប្រាស់ (user retention rate) គឺជាសមាមាត្រនៃអ្នកប្រើសកម្មក្នុងរយៈពេលចាប់ផ្តើម ដែលនៅតែសកម្មក្នុងរយៈពេលក្រោយ ហើយបញ្ច្រាសរបស់វា គឺអត្រាចាកចេញ (churn ឬ dropout) ជាសមាមាត្រនៃអ្នកដែលឈប់ប្រើផលិតផលទាំងស្រុង។ ខណៈដែលអត្រាទទួលយកផតថលអ្នកជំងឺ (សូមមើលប្រធានបទនោះ) វាស់ថាអ្នកជំងឺធ្លាប់ធ្វើឱ្យផលិតផលសុខភាពឌីជីថលសកម្មយ៉ាងមានន័យឬអត់ ការរក្សាវាស់ថាពួកគេបន្តប្រើវាឬអត់ ហើយសម្រាប់ផលិតផលសុខភាពឌីជីថលណាដែលមានលក្ខណៈជាការជាវ ឬការថែទាំជាប់ជាប្រចាំ ការរក្សាជាធម្មតាគឺជារង្វាស់តែមួយដែលទាក់ទងជិតស្និទ្ធបំផុតទាំងនឹងផលប៉ះពាល់គ្លីនិក និងនិរន្តរភាពពាណិជ្ជកម្ម។

## ហេតុអ្វីបានជាសំខាន់

ផលិតផលសុខភាពឌីជីថលដែលមិនអាចរក្សាអ្នកប្រើបាន មិនអាចផ្តល់អត្ថប្រយោជន៍គ្លីនិកបន្តទៅមុខបានទេ ទោះលេខការទទួលយក ឬការធ្វើឱ្យសកម្មដំបូងរបស់វារឹងមាំប៉ុនណា៖ ឧបករណ៍គ្រប់គ្រងជំងឺរ៉ាំរ៉ៃដែលប្រើពីរសប្តាហ៍ រួចបោះបង់ តិចនឹងអាចផ្លាស់ប្តូរលទ្ធផលជីវមាត្រដែលអាស្រ័យលើការផ្លាស់ប្តូរឥរិយាបថជាបន្តបន្ទាប់ជាច្រើនខែ។ ការរក្សាក៏ជារង្វាស់មួយដែលមានផលវិបាកពាណិជ្ជកម្មខ្លាំងបំផុតដែលក្រុមហ៊ុនសុខភាពឌីជីថលរាយការណ៍ទៅអ្នកវិនិយោគ និងអ្នកទូទាត់ ព្រោះខ្សែកោងរក្សា (រូបរាងនៃការធ្លាក់ចុះតាមពេលវេលា មិនមែនត្រឹមភាគរយរក្សាតែមួយ) បង្ហាញថាផលិតផលបានរកឃើញលំនាំប្រើប្រាស់ស្ថិរភាពពិតប្រាកដ ឬគ្រាន់តែចាប់យកចំណាប់អារម្មណ៍ដំបូងដែលកើតពីភាពថ្មីថ្មោង ហើយរសាត់បាត់ដូចការរំពឹងទុក។ ខ្សែកោងរក្សាដែលរាបស្មើបន្ទាប់ពីធ្លាក់ដំបូង (អ្នកជំងឺដែលឆ្លងផុតខែដំបូងតែងនៅបន្ត) គឺជាសញ្ញាខុសគ្នាស្រឡះ និងមានសុខភាពល្អជាងខ្សែកោងដែលបន្តធ្លាក់ចុះជាប់លាប់ដោយគ្មានបាតទប់។

## របៀបគណនា

```
អត្រារក្សា (រយៈពេល N) = អ្នកប្រើសកម្មក្នុងរយៈពេល N ដែលក៏សកម្មដែរ
                         ក្នុងរយៈពេលក្រុមចាប់ផ្តើម / អ្នកប្រើក្នុងរយៈពេល
                         ក្រុមចាប់ផ្តើម × 100

អត្រាចាកចេញ = 1 − អត្រារក្សា (សម្រាប់រយៈពេលដូចគ្នា)

រាយការណ៍ជាខ្សែកោងរក្សាតាមក្រុម (cohort) (ការរក្សានៅថ្ងៃ/សប្តាហ៍/ខែទី 1, 2, 3…)
មិនមែនតួលេខតែមួយពេលនោះទេ ព្រោះរូបថតតែមួយច្រឡំអ្នកប្រើដែលទើបចូលរួម
(មិនទាន់មានឱកាសចាកចេញ) ជាមួយអ្នកដែលបានប្រើយូរមកហើយ។
```

## ឧទាហរណ៍អនុវត្ត

កម្មវិធីសុខភាពឌីជីថលមួយចុះឈ្មោះក្រុមអ្នកប្រើថ្មី ១,០០០ នាក់នៅខែមករា។ ត្រឹមចុងខែទី ១ អ្នកប្រើដើម ៦៤០ នាក់ក្នុងចំណោម ១,០០០ នៅតែសកម្ម (អត្រារក្សាខែទី ១ 64%)។ ត្រឹមចុងខែទី ៣ នៅសល់ ៤១០ នាក់សកម្ម (អត្រារក្សាខែទី ៣ 41%)។ ដល់ខែទី ៦ នៅសល់ ៣៨០ នាក់សកម្ម (អត្រារក្សាខែទី ៦ 38%)។ រូបរាងនៃខ្សែកោងនេះ គឺការធ្លាក់ចុះយ៉ាងចោតដំបូង បន្ទាប់មករាបស្មើរវាងខែទី ៣ និងទី ៦ បង្ហាញថាផលិតផលរក្សាស្នូលអ្នកប្រើស្ថិរភាពមួយ នៅពេលពួកគេឆ្លងផុតឧបសគ្គនៃការទទួលយកដំបូង ដែលជាសញ្ញាខុសគ្នាច្បាស់ និងលើកទឹកចិត្តជាងប្រសិនបើការធ្លាក់ចុះពីខែទី ៣ ដល់ទី ៦ បន្តក្នុងអត្រាដូចខែទី ១ ដល់ទី ៣។

## ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន

ការរក្សាត្រូវបានគណនាពីកំណត់ហេតុព្រឹត្តិការណ៍ចូលប្រើ ឬសកម្មភាពរបស់ផលិតផលផ្ទាល់ ដោយកំណត់ "សកម្ម" ឱ្យជាប់លាប់ (ឧទាហរណ៍ វគ្គមានលក្ខណៈសម្បត្តិយ៉ាងហោចណាស់មួយក្នុងរយៈពេល) ក្នុងគ្រប់ក្រុមដែលកំពុងប្រៀបធៀប។ ក្រុមគួរត្រូវបានប្រៀបធៀបដោយផ្អែកលើមូលដ្ឋានដូចគ្នា គឺនិយមន័យចាប់ផ្តើមនៃ "សកម្ម" ដូចគ្នា និងប្រវែងបង្អួចសង្កេតដូចគ្នា ព្រោះភាពខុសគ្នាតូចតាចនៃនិយមន័យ (ខែ ៣០ ថ្ងៃ ធៀបនឹង ២៨ ថ្ងៃ ឬកម្រិត "សកម្ម" តឹងជាង ធៀបនឹងរលុងជាង) អាចផ្លាស់ប្តូរភាគរយរក្សាដែលរាយការណ៍បានច្រើនពិន្ទុ ដោយគ្មានភាពខុសគ្នាពិតនៃឥរិយាបថអ្នកប្រើ។ ឥទ្ធិពលតាមរដូវកាលជារឿងធម្មតាក្នុងកម្មវិធីសុខភាពដែលភ្ជាប់នឹងការសន្យាចូលឆ្នាំថ្មី ឬរយៈពេលផ្សព្វផ្សាយសុខភាពជាក់លាក់ ដូច្នេះការប្រៀបធៀបក្រុមឆ្នាំទល់ឆ្នាំជាធម្មតាផ្តល់ព័ត៌មានច្រើនជាងការប្រៀបធៀបក្រុមជាប់គ្នាពីពេលវេលាខុសគ្នាក្នុងឆ្នាំ។

## កំហុសដែលតែងកើតមាន

- **រាយការណ៍រូបថតការរក្សាតែមួយ ជំនួសខ្សែកោង**៖ តួលេខតែមួយ "X% នៃអ្នកប្រើនៅតែសកម្ម" ដោយគ្មានរូបរាងនៃការធ្លាក់ចុះតាមពេលវេលា មិនអាចញែកផលិតផលដែលរាបស្មើ (មានសុខភាពល្អ) ពីផលិតផលដែលធ្លាក់ចុះជាបន្តបន្ទាប់ (មិនល្អ)។
- **ផ្លាស់ប្តូរនិយមន័យ "សកម្ម" រវាងរយៈពេលរាយការណ៍**៖ ការបន្ធូរនិយមន័យអ្នកប្រើសកម្ម (ឧទាហរណ៍ រាប់ការបើកកម្មវិធីអកម្ម ជំនួសសកម្មភាពដែលបានបញ្ចប់) អាចធ្វើឱ្យការរក្សាមើលទៅប្រសើរឡើង ខណៈពេលដែលការប្រើប្រាស់ពិតមិនបានផ្លាស់ប្តូរទាល់តែសោះ។
- **មិនអើពើរដូវកាលរបស់ក្រុម**៖ ការប្រៀបធៀបការរក្សារបស់ក្រុមខែមករា (តែងត្រូវបានបំប៉នដោយការចុះឈ្មោះតាមការសន្យាចូលឆ្នាំថ្មី ដែលនាំចូលក្រុមមានការលើកទឹកចិត្តតិចជាងជាមធ្យម) ធៀបនឹងក្រុមដែលទទួលបានក្នុងពេលផ្សេងនៃឆ្នាំ អាចបង្កើតការសន្និដ្ឋាននិន្នាការដែលបំភ័ន្ត។
- **លាយក្រុមធម្មជាតិ និងក្រុមបង់ប្រាក់ទទួលបាន**៖ អ្នកប្រើដែលទទួលបានតាមបណ្តាញខុសគ្នាតែងមានការរក្សាខុសគ្នាខ្លាំង ការលាយពួកគេជាតួលេខរក្សារួមតែមួយ អាចលាក់បញ្ហារក្សាជាក់លាក់តាមបណ្តាញ។
