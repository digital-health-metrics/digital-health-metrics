# ອັດຕາການຮັບການປິ່ນປົວທາງໄກ

ອັດຕາການຮັບການປິ່ນປົວທາງໄກ (telehealth visit rate) ແມ່ນສັດສ່ວນຂອງການພົບແພດທັງໝົດຂອງບໍລິການທີ່ສົ່ງມອບທາງໄກ ດ້ວຍວິດີໂອ ຫຼື ໂທລະສັບ ແທນທີ່ຈະເປັນຕໍ່ໜ້າ. ມັນເປັນຕົວຊີ້ວັດການປະສົມຊ່ອງທາງການສົ່ງມອບ ບໍ່ແມ່ນຕົວຊີ້ວັດກິດຈະກຳ: ມັນບອກວ່າການດູແລຖືກສົ່ງມອບແນວໃດ ເຊິ່ງສຳຄັນຕໍ່ການວາງແຜນກຳລັງການຮອງຮັບ, ການເຂົ້າເຖິງ ແລະ ຄວາມເໝາະສົມທາງຄລີນິກ ແຍກຈາກວ່າມີການດູແລສົ່ງມອບທັງໝົດເທົ່າໃດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ສັດສ່ວນຂອງການດູແລທີ່ສົ່ງມອບທາງໄກໄດ້ປ່ຽນຮູບແບບການດຳເນີນງານຂອງຫຼາຍບໍລິການຫຼັງການຂະຫຍາຍຕົວຢ່າງໄວວາຂອງການປຶກສາເສມືນໃນລະຫວ່າງການລະບາດຂອງ COVID-19 ແລະ ອົງການຕ້ອງການວິທີທີ່ໝັ້ນຄົງໃນການຕິດຕາມວ່າການປ່ຽນແປງນັ້ນຍັງຄົງຢູ່, ກຳລັງຖອຍກັບໄປສູ່ມາດຕະຖານກ່ອນການລະບາດ ຫຼື ຖືກຊີ້ນຳຢ່າງຈິງຈັງໂດຍນະໂຍບາຍ. Telehealth ບໍ່ແມ່ນຕົວແທນທີ່ເປັນເອກະພາບຂອງການພົບແພດຕໍ່ໜ້າ: ຄວາມເໝາະສົມແຕກຕ່າງຕາມສາຂາຊ່ຽວຊານ, ຕາມປະເພດຂອງການປຶກສາ (ການທົບທວນຢາແຕກຕ່າງຫຼາຍຈາກການກວດຮ່າງກາຍ) ແລະ ຕາມຄວາມມັກຂອງຄົນເຈັບ ດັ່ງນັ້ນອັດຕາທີ່ "ຖືກຕ້ອງ" ເປັນການຕັດສິນທາງຄລີນິກ ແລະ ການດຳເນີນງານ ບໍ່ແມ່ນເປົ້າໝາຍທີ່ຈະເຮັດໃຫ້ສູງສຸດ. ຜູ້ໃຫ້ທຶນ ແລະ ຜູ້ກຳກັບດູແລຍັງໃຊ້ອັດຕານີ້ ຄຽງຄູ່ກັບຕົວຊີ້ວັດຜົນໄດ້ຮັບ ແລະ ຄວາມປອດໄພ ເພື່ອຕັດສິນນະໂຍບາຍການຈ່າຍຄືນ ແລະ ກວດວ່າການດູແລທາງໄກບໍ່ໄດ້ຖືກນຳໄປແທນທີ່ກັບກໍລະນີທີ່ຕ້ອງພົບແພດຕໍ່ໜ້າພຽງເທົ່ານັ້ນ.

## ວິທີຄຳນວນ

```
ອັດຕາການຮັບການປິ່ນປົວທາງໄກ = ການພົບແພດ telehealth / (ການພົບແພດ telehealth + ການພົບແພດຕໍ່ໜ້າ) × 100

ລາຍງານແຍກຕາມຮູບແບບ ເມື່ອເປັນໄປໄດ້:
  ອັດຕາວິດີໂອ    = ການພົບແພດດ້ວຍວິດີໂອ / ການພົບແພດທັງໝົດ × 100
  ອັດຕາໂທລະສັບ   = ການພົບແພດດ້ວຍໂທລະສັບເທົ່ານັ້ນ / ການພົບແພດທັງໝົດ × 100

ຕົວຫານຄວນນັບສະເພາະການພົບແພດທີ່ສຳເລັດ (ເບິ່ງຈຸດອ່ອນ) ສຳລັບບໍລິການ,
ສາຂາຊ່ຽວຊານ ແລະ ໄລຍະເວລາທີ່ກຳນົດ.
```

## ຕົວຢ່າງການຄຳນວນ

ບໍລິການສຸຂະພາບຈິດຊຸມຊົນບັນທຶກການຕິດຕໍ່ຄົນເຈັບນອກທີ່ສຳເລັດ 4,000 ຄັ້ງໃນໜຶ່ງໄຕມາດ: 1,200 ຕໍ່ໜ້າ, 1,600 ດ້ວຍວິດີໂອ ແລະ 1,200 ດ້ວຍໂທລະສັບ. ອັດຕາການຮັບການປິ່ນປົວທາງໄກແມ່ນ (1,600 + 1,200) / 4,000 × 100 = 70% ໂດຍອັດຕາວິດີໂອ 40% ແລະ ອັດຕາໂທລະສັບເທົ່ານັ້ນ 30%. ການລາຍງານສະເພາະຕົວເລກລວມ 70% ຈະປິດບັງວ່າສ່ວນຫຼາຍຂອງ "telehealth" ໃນທີ່ນີ້ເປັນສຽງລ້ວນໆ ເຊິ່ງໂດຍທົ່ວໄປມີໂປຣໄຟລ໌ຄວາມສ່ຽງທາງຄລີນິກ ແລະ ປະສົບການຄົນເຈັບທີ່ແຕກຕ່າງຈາກວິດີໂອ.

## ແຫຼ່ງຂໍ້ມູນ ແລະ ຂໍ້ຄວນລະວັງ

ປະເພດການພົບແພດໂດຍທົ່ວໄປຖືກບັນທຶກເປັນຊ່ອງທີ່ມີໂຄງສ້າງໃນບັນທຶກສຸຂະພາບເອເລັກໂຕຣນິກ (ປະເພດການມາ ຫຼື ສະຖານທີ່) ຫຼື ສັນນິຖານຈາກລະຫັດການເກັບເງິນ ເຊັ່ນ ລະຫັດສະຖານທີ່ບໍລິການ ຫຼື ຕົວປັບ telehealth ໃນການເຄລມ. ການປະຕິບັດການໃຫ້ລະຫັດແຕກຕ່າງກັນຢ່າງຫຼວງຫຼາຍລະຫວ່າງອົງການ ແລະ ແມ້ແຕ່ລະຫວ່າງແພດໃນອົງການດຽວກັນ ດັ່ງນັ້ນການປຽບທຽບອັດຕາຂ້າມສະຖານທີ່ຄວນຢືນຢັນກ່ອນວ່າ "telehealth" ຖືກໃຫ້ລະຫັດແບບດຽວກັນໃນແຕ່ລະບ່ອນ. ການພົບແພດທີ່ເລີ່ມເປັນວິດີໂອແຕ່ຫຼຸດລົງເປັນໂທລະສັບເນື່ອງຈາກບັນຫາທາງເຕັກນິກ ຄວນຖືກໃຫ້ລະຫັດຢ່າງສອດຄ່ອງ (ໂດຍທົ່ວໄປເປັນຮູບແບບທີ່ໃຊ້ສົ່ງເນື້ອຫາທາງຄລີນິກສ່ວນໃຫຍ່) ແລະ ກົດນັ້ນຄວນຖືກບັນທຶກເປັນເອກະສານ ແທນທີ່ຈະປ່ອຍໃຫ້ເປັນການຕັດສິນສ່ວນບຸກຄົນ.

## ຈຸດອ່ອນທີ່ຄວນລະວັງ

- **ການນັບການນັດພົບທີ່ພະຍາຍາມ ແທນທີ່ຈະເປັນທີ່ສຳເລັດ**: ການນັດໝາຍ telehealth ທີ່ເຊື່ອມຕໍ່ບໍ່ສຳເລັດ ແລະ ຖືກນັດໃໝ່ ບໍ່ຄວນເຮັດໃຫ້ຕົວຫານ telehealth ສູງຂຶ້ນສອງເທື່ອ.
- **ການຖືວ່າວິດີໂອ ແລະ ໂທລະສັບແລກປ່ຽນກັນໄດ້**: ພວກມັນມີຜົນສະທ້ອນທາງຄລີນິກ ແລະ ຄວາມເທົ່າທຽມແຕກຕ່າງກັນ (ໂທລະສັບຕັດການປະເມີນດ້ວຍສາຍຕາອອກ ແຕ່ເຂົ້າເຖິງໄດ້ງ່າຍກວ່າສຳລັບຄົນເຈັບທີ່ບໍ່ມີສະມາດໂຟນ, ຂໍ້ມູນທີ່ເຊື່ອຖືໄດ້ ຫຼື ພື້ນທີ່ສ່ວນຕົວສຳລັບວິດີໂອ); ຄວນລາຍງານແຍກກັນເມື່ອເປັນໄປໄດ້.
- **ການບໍ່ສົນໃຈຄວາມສຳພັນກັບການບໍ່ມາຕາມນັດ**: ພຶດຕິກຳການບໍ່ມາຕາມນັດມັກແຕກຕ່າງຕາມຮູບແບບ; ເບິ່ງ [ອັດຕາການບໍ່ມາຕາມນັດ](../ອັດຕາການບໍ່ມາຕາມນັດ/) ກ່ອນສະຫຼຸບກ່ຽວກັບ "ການເຂົ້າເຖິງທີ່ດີຂຶ້ນ" ຈາກອັດຕາ telehealth ທີ່ເພີ່ມຂຶ້ນພຽງຢ່າງດຽວ.
- **ການຖືວ່າອັດຕາສູງດີໂດຍພື້ນຖານ**: ສຳລັບບາງພະຍາດ ແລະ ປະເພດການປຶກສາ ອັດຕາ telehealth ທີ່ເໝາະສົມຕ່ຳໂດຍການອອກແບບທາງຄລີນິກ ບໍ່ແມ່ນຄວາມລົ້ມເຫຼວຂອງຄວາມເປັນຜູ້ໃຫຍ່ດ້ານດິຈິຕອນ.
