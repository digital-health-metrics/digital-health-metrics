# Tingkat Stabilisasi Biometrik

Tingkat stabilisasi biometrik yaiku persentase pasien sing kadaftar sing entuk lan njaga rentang target sing wis ditemtokake sacara klinis kanggo ukuran biometrik — sing paling umum tekanan darah ing sangisore ambang kayata 130/80 mmHg — nggunakake piranti pemantauan sing nyambung, sajrone periode lestari, dudu ing siji titik wektu. Iki beda karo tingkat perbaikan biometrik (deleng topik kasebut): perbaikan ngukur gedhene owah-owahan saka baseline, dene stabilisasi ngukur apa pasien tetep dijaga kanthi dipercaya ing rentang aman sawise perawatan utawa pemantauan diwiwiti, yaiku asil sing paling penting kanggo pasien sing wis cedhak target utawa wis ana ing perawatan.

## Kenapa penting

Kanggo bagean gedhe pasien ing program penyakit kronis — utamane hipertensi, ing ngendi target tekanan darah pandhuan wis mapan lan langsung ana gandhengane karo risiko kardiovaskular — tujuan klinis dudu perbaikan sepisan nanging kontrol sing lestari, lan pasien sing mundhak-mudhun metu-lebu rentang target nuwuhake risiko sing beda sacara materi tinimbang pasien sing apik sepisan banjur tetep ana kono. Piranti sing nyambung (manset tekanan darah seluler, monitor glukosa terus-terusan) ndadekake stabilisasi bisa diukur terus-terusan, ora mung ing kunjungan klinik, nuduhake pasien sing bacaan ing klinike katon kekontrol nanging bacaan ing omahe ora stabil — pola sing dikenal minangka hipertensi samaran sing ora bisa dideteksi mung dening pangukuran langsung periodik. Nglaporake tingkat stabilisasi, tinimbang mung gambaran "ing target" sepisan, meksa program ngadhepi seberapa konsisten, dudu mung sepira kerep, program njaga pasien ing rentang.

## Carane ngetung

```
Tingkat stabilisasi biometrik = pasien kanthi ≥ 80% bacaan ing rentang
                                target sajrone periode pangukuran /
                                pasien kanthi jumlah minimal bacaan
                                valid ing periode kuwi × 100

Conto ambang:
  Tekanan darah — target < 130/80 mmHg (utawa ambang pandhuan klinis
                  sing ditrapake kanggo profil risiko pasien)
  Glukosa       — rentang target miturut pandhuan pemantauan glukosa
                  terus-terusan, dilaporake minangka "time in range"

Ambang frekuensi bacaan minimal (umpamane paling ora 3 bacaan saben
minggu) kudu ditetepake sadurunge pasien dilebokake ing penyebut,
supaya pembaca sing arang ora katon stabil kanthi buatan.
```

## Conto petungan

Program pemantauan jarak adoh hipertensi ndaftarake 600 pasien nganggo manset tekanan darah seluler, saben pasien diarepake njupuk paling ora 3 bacaan saben minggu. Saka jumlah kuwi, 540 nyukupi ambang frekuensi bacaan minimal sajrone periode pangukuran 3 sasi lan dilebokake ing penyebut. Saka 540 kuwi, 350 duwe paling ora 80% bacaane ing sangisore 130/80 mmHg, mula tingkat stabilisasi biometrik yaiku 350 / 540 × 100 = 65%. 60 pasien sing dikecualekake amarga bacaan sing ora cukup dilaporake kapisah minangka kesenjangan kelengkapan data, ora digabung menyang pembilang utawa klompok "ora stabil", amarga status kontrol sejatine pancen ora dingerteni, dudu elek.

## Sumber data lan pangati-ati

Bacaan asale langsung saka aliran data piranti sing nyambung, sing luwih objektif lan luwih kerep tinimbang pangukuran ing klinik, nanging kesalahan panggonan lan teknik piranti (manset tekanan darah sing ukurane utawa panggonane salah) bisa nuwuhake bias sistematis sing ora mesthi kecekel dening siji bacaan validasi ing klinik. Pilihan rentang target kudu ngetutake pandhuan klinis saiki sing ditrapake kanggo profil risiko lan komorbiditas pasien tartamtu, dudu siji ambang universal, amarga target pandhuan beda miturut umur pasien, fungsi ginjel, lan risiko kardiovaskular. Pasien kanthi frekuensi bacaan sithik ora kena diétung meneng-menengan minangka "stabil" kanthi baku; ngecualekake dheweke saka penyebut kanthi pelaporan transparan babagan pengecualian kuwi luwih jujur tinimbang ngétung dheweke minangka kekontrol utawa ora kekontrol adhedhasar data sing kurang.

## Kesalahan umum

- **Nganggep siji bacaan ing rentang minangka stabilisasi**: stabilisasi iku bab kontrol lestari sajrone periode tartamtu, dudu gambaran sepisan; tansah mbutuhake proporsi minimal bacaan ing rentang sajrone periode kuwi, dudu siji pangukuran sing nyukupi.
- **Meneng-menengan ngecualekake pembaca arang tanpa nglaporake**: pasien sing arang njupuk bacaan ora otomatis stabil utawa ora stabil; kecualekake dheweke kanthi transparan saka penyebut lan laporake tingkat pengecualian minangka metrik kelengkapan data sing kapisah.
- **Ngabaikake kalibrasi piranti lan kesalahan teknik**: manset sing dipasang elek utawa piranti sing ora dikalibrasi bisa nyebabake bias bacaan sacara sistematis ing siji arah, sing ora bakal kecekel dening tingkat stabilisasi sing diétung kanthi naif saka data piranti mentah tanpa validasi periodik.
- **Nggunakake siji rentang target universal kanggo kabeh pasien**: target pandhuan klinis beda miturut profil risiko lan komorbiditas pasien; nrapake siji ambang umum ing populasi sing heterogen sacara klinis bakal salah ngklasifikasi sawetara pasien minangka stabil utawa ora stabil dibandhingake karo target individu sing sejati.
