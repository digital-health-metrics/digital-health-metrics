# 真實獲客成本

真實獲客成本（true CAC）係獲取一名新付費客戶或者已登記病人嘅全面負擔成本，唔單止包括付費廣告開支，亦包括對該次獲客有實質貢獻嘅所有其他成本：代理商同創意費用、營銷科技同分析基礎設施，以及——數碼健康特有嘅——接收、資格核實同上手引導嘅臨床或營運人手成本。佢作為獨立指標存在，係因為廣告平台匯報嘅獲客成本數字，經常而且大幅低估機構每名獲取客戶嘅真實成本。

## 點解重要

單單憑廣告平台匯報嘅每次獲客成本數字去管理增長嘅數碼健康機構，經常根據遺漏咗 30-50% 真實獲客成本嘅數字去作出資源分配決策，因為該等平台數字只捕捉媒體開支，而排除代理費用、營銷科技授權，以及——對醫療保健嚟講至關重要——臨床或營運團隊喺每名新病人可以被計作已獲取之前，所要進行嘅勞動密集型接收同資格核實工作。呢個差距喺數碼健康比大部分其他行業更重要，正正因為臨床接收人手成本高昂而且必須，唔似電子商務，「銷售」基本上唔需要可比擬嘅後勤人手。針對人為偏低嘅 CAC 數字去優化營銷開支嘅團隊，會系統性咁過度投資喺平台儀表板上睇落平、但一旦計算真實 CAC 就昂貴嘅渠道。

## 點計算

```
真實 CAC = （付費媒體開支 + 代理商同創意費用 + 營銷
             科技同分析成本 + 臨床／營運接收
             人手成本）/ 該時期獲取嘅新客戶或病人

臨床／營運接收人手成本應該根據全面負擔人手成本
（薪金、福利、間接開支）× 每名獲取病人用於接收、
資格核實同上手引導嘅平均時數去估算。
```

## 計算示例

一間數碼健康公司喺一個月內獲取 500 名新病人。廣告平台儀表板匯報混合每次獲客成本為 $120，根據 $60,000 嘅付費媒體開支。加上 $9,000 嘅代理費用、$6,000 嘅營銷科技成本，以及按每名病人 45 分鐘、全面負擔員工成本每小時 $40 估算嘅接收人手成本（500 × 0.75 × $40 = $15,000），總獲客成本為 $60,000 + $9,000 + $6,000 + $15,000 = $90,000。真實 CAC 為 $90,000 / 500 = $180——比單靠廣告平台匯報嘅 $120 高 50%，而呢個先係應該真正用嚟指導渠道預算分配同單位經濟決策嘅數字。

## 數據來源同注意事項

付費媒體開支同平台匯報嘅每次獲客成本，直接來自廣告平台本身（搜尋、社交、程式化）；代理費用同營銷科技成本來自財務或者應付帳款紀錄；接收人手成本係最難準確取得嘅部分，通常需要時間與動作研究，或者同營運領導層協定嘅合理估算，因為大部分機構本身並不追蹤每次獲客所用嘅員工時間。喺數量許可嘅情況下，真實 CAC 應該按獲客渠道計算，因為每名病人嘅接收人手成本喺各渠道之間往往相似，而媒體成本卻差異極大，意味住平台匯報同真實 CAC 之間嘅差距，喺睇落最平嘅渠道按比例最大。

## 常見陷阱

- **完全依賴廣告平台儀表板**：平台匯報嘅每次獲客成本，結構上排除咗代理費用、營銷科技成本同接收人手，唔可以取代真實 CAC 計算。
- **遺漏臨床或營運接收人手**：呢個係數碼健康特別經常被忽略嘅成本部分，亦往往係平台匯報成本同真實 CAC 之間差距嘅最大單一成因。
- **跨所有渠道平均真實 CAC**：混合嘅真實 CAC 數字，可以隱藏某個渠道一旦計入全面負擔成本就貴得多，即使佢單靠廣告平台睇落最平。
- **接收流程改變時冇更新人手成本估算**：接收流程重新設計（例如將資格核實自動化）可以實質改變真實 CAC，而過時嘅人手估算會誤報當前數字。
