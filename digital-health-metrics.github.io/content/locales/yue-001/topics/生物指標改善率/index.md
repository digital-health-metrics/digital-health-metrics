# 生物指標改善率

生物指標改善率係指數碼健康計劃之中已登記嘅病人，喺界定嘅登記期內，喺所追蹤嘅生物指標上取得具臨床意義改善嘅比例——最常見係糖尿病同心血管代謝計劃嘅糖化血紅蛋白（HbA1c），或者體重管理計劃嘅身體質量指數（BMI）。佢係最終證明數碼健康產品臨床聲稱嘅結果指標：參與度同採用數字描述產品係點樣被使用，而生物指標改善則更接近證明佢有效嘅證據。

## 點解重要

數碼健康計劃經常憑改善健康結果嘅承諾而被銷售同委託，而生物指標改善率係用一個具體、臨床認可嘅門檻，而唔係含糊嘅「更健康」聲稱，去驗證呢個承諾最直接、可量化嘅方法。付款方、僱主同醫療系統越嚟越多將報銷或者合約續期同已證明嘅生物指標變化掛鈎，所以無法可信咁匯報呢個比率嘅計劃，喺商業同臨床上都處於劣勢。呢個指標亦係計劃設計嘅紀律檢查：匯報參與度（登入、已發送訊息）遠比匯報結果容易，如果一個計劃熱衷匯報前者、對後者卻含糊其辭，團隊就應該提高警覺。

## 點計算

```
生物指標改善率 = 達到界定嘅具臨床意義改善嘅病人 /
                 有有效基線同跟進量度嘅病人 × 100

常見具臨床意義嘅門檻：
  HbA1c   — 下降 ≥ 0.5 個百分點，或者由超出範圍嘅基線
            達到界定嘅目標（例如 < 7.0%）
  BMI     — 下降 ≥ 基線體重嘅 5%，並且維持到
            跟進量度時間點

每個所追蹤嘅生物指標分開匯報；絕不可以將 HbA1c 同 BMI
嘅改善合併成單一嘅「改善」百分比。
```

## 計算示例

一個心血管代謝數碼健康計劃登記 800 名基線 HbA1c 超出範圍嘅病人。當中 620 人有有效基線同 6 個月跟進量度（180 人失去跟進，並從分母剔除，而唔係計作失敗）。喺 620 名有配對量度嘅病人之中，340 人達到至少下降 0.5 個百分點。生物指標改善率為 340 / 620 × 100 = 55%。如果對照全部 800 名已登記病人匯報（340 / 800 = 42.5%），就會將失去跟進同治療失敗混為一談，低估咗實際完成量度嘅病人嘅比率。

## 數據來源同注意事項

基線同跟進嘅生物指標數值，通常來自連接裝置（藍牙血糖計或者智能體重磅）、從電子健康紀錄匯入嘅化驗結果，或者病人自行輸入嘅自述數值——而呢三種來源嘅可靠程度好唔同，所以應該連同比率一齊匯報來源。失去跟進好少係隨機嘅：脫離計劃嘅病人，往往亦係最唔可能有改善嘅一群，所以只根據完成跟進嘅病人計算出嚟嘅高改善率，可能高估計劃真正嘅人群層面效果。季節性同回歸均值效應，對 HbA1c 同體重都係真實存在，所以計劃應該盡可能同同期或者歷史對照組比較，而唔係將任何改善都視為計劃效果嘅證明。

## 常見陷阱

- **剔除而非匯報失去跟進嘅情況**：靜靜地將冇跟進量度嘅病人從分母剔除，可以大幅膨脹表面改善率；應該永遠連同改善率本身一齊匯報跟進量度嘅完成率。
- **混合自述同裝置來源嘅量度而冇標示**：自述體重系統性咁比連接智能體重磅嘅讀數更唔可靠，混合兩種來源會掩蓋表面改善之中有幾多只係量度雜訊。
- **冇對照組或者反事實比較**：好多慢性生物指標量度會自行波動或者向均值回歸；單臂改善率如果冇任何比較組，只能提示、而非確證計劃嘅效果。
- **將輕微嘅平均變化視為廣泛改善嘅證據**：人群層面輕微嘅平均改善，可以由少數大幅回應者帶動，而大部分病人並無變化；應該匯報分佈（例如越過具臨床意義門檻嘅比例），而唔係只匯報平均變化。
