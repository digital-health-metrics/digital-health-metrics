# 病人淨推薦值

病人淨推薦值（Net Promoter Score，NPS）量度病人願意將數碼健康產品或者遠程醫療服務推薦畀其他人嘅程度，根據一條單一問卷問題——「你有幾大可能會將呢項服務推薦畀朋友或者同事？」——以 0 至 10 分計算。評分 9-10 嘅受訪者係「推薦者」，7-8 係「被動者」，0-6 係「貶低者」；NPS 係推薦者百分比減去貶低者百分比。佢係數碼健康入面最廣泛使用、亦最廣受批評嘅病人滿意度指標，因為簡單而備受重視，但單靠佢本身所能診斷嘅內容有限。

## 點解重要

NPS 畀數碼健康團隊一個簡單、標準化、可跨項目比較嘅滿意度訊號，收集成本低，而且非專業持份者（行政人員、董事會、委託機構）一眼就容易理解，所以儘管方法學上嘅局限有充分記錄，佢仍然受歡迎。專門針對遠程醫療同數碼前門產品，NPS 往往係病人喺兩者皆可選擇時，會否繼續揀數碼渠道而唔係親身診症嘅領先指標，直接影響渠道組合規劃同容量。不過，NPS 係一個單一嘅高層次總結數字：NPS 下降話畀團隊知有啲嘢出錯，但唔知係咩，所以應該永遠配合開放文字逐字回饋或者更細緻嘅易用性工具，先可以付諸行動，而唔係淪為記分卡上嘅一個數字。

## 點計算

```
NPS = 推薦者百分比（評分 9-10）− 貶低者百分比（評分 0-6）

結果係由 −100 至 +100 嘅數字，而唔係百分比，
雖然佢由百分比推算——切勿喺 NPS 數字後面加上「%」符號。

應連同以下資料一齊匯報：
  回應率（受調查病人之中有回應嘅百分比）
  樣本量
  所用嘅確切問題措辭
```

## 計算示例

一個遠程醫療平台喺視像診症之後調查 1,000 名病人，收到 400 份回應（回應率 40%）。喺呢 400 名受訪者之中，220 人評分 9-10（推薦者，55%），100 人評分 7-8（被動者，25%），80 人評分 0-6（貶低者，20%）。NPS 為 55 − 20 = 35。呢個數字要放喺脈絡之中先有意義：35 嘅 NPS 同更廣泛嘅遠程醫療行業比較，可能係強勁嘅結果，但同呢個平台上一季自己嘅 48 分比較，就可能係令人擔憂嘅下滑——NPS 用嚟睇同一個產品隨時間嘅趨勢，遠比用作同另一個產品比較嘅一次性絕對基準有用。

## 數據來源同注意事項

NPS 透過互動後問卷收集，通常喺視像診症、應用程式使用或者護理個案之後即時觸發，而回應率極為重要：低回應率（遠低於計算示例中約 40% 嘅水平）有無回應偏差嘅風險，即只有非常滿意或者非常不滿嘅病人先會回應，令分數被拉向極端，偏離真實人群嘅情緒。比較不同機構，甚至同一機構唔同渠道（例如遠程醫療對比親身診症）嘅 NPS，只有喺問題措辭、時間同調查人群真正可比較嘅情況下先有效；已知細微嘅措辭改變都會明顯移動分數。NPS 應該被視為要解釋嘅結果，而唔係目的本身——通常伴隨 NPS 問卷嘅開放文字評論，往往比分數更具可操作性。

## 常見陷阱

- **比較以唔同問題措辭或時間收集嘅 NPS 數字**：即使細微嘅問卷設計差異，都可以令分數移動幾分，令跨機構 NPS 基準比較遠不及睇落咁可靠。
- **忽略回應率**：由 10% 回應率計算出嚟嘅總體 NPS，可信度遠低於由 60% 回應率計算出嚟嘅，因為低回應率容易出現偏向最極端意見嘅無回應偏差。
- **將 NPS 當成診斷工具而唔係總結指標**：NPS 下跌話畀你知有啲嘢出錯，但從不說明係咩；應該永遠配合定性回饋或者更細緻嘅滿意度或易用性工具，去找出原因。
- **將 NPS 本身當成目標去追逐**：狹隘咁針對 NPS 數字作優化（例如只喺異常正面嘅互動之後調查病人），可以改善匯報嘅分數，但背後嘅病人體驗並冇好轉，甚至更差。
