# 每診療個案成本

每診療個案成本係指治療某個界定臨床個案——例如髖關節置換及其相關康復，或者糖尿病管理期——所產生嘅總成本，並同未接受被評估數碼干預嘅歷史基線同期群作比較。佢係價值為本護理中財務比較嘅標準單位，因為佢捕捉嘅係整個個案嘅完整經濟圖像，而唔係孤立嘅任何單一成本項目，亦係付款方同醫療系統同意大規模資助數碼健康計劃之前，最常要求嘅指標。

## 點解重要

價值為本護理合約越嚟越多按結果同個案而非個別服務付款，意味住數碼健康計劃嘅財務理據，必須用同一種貨幣去論證：每個個案嘅總成本，同干預措施出現之前同類個案嘅成本作比較。一個減少某個成本類別（例如較少親身跟進診症）、同時增加另一類別（更多裝置成本、更多臨床監測人手時間）嘅計劃，未必減少咗每個個案嘅總成本，只有完整嘅個案層面成本計算先可以捕捉呢種取捨；孤立咁睇任何單一成本項目，都有得出誤導性結論嘅風險，無論偏向邊個方向。由於個案定義同基線時期可以用偏向特定結論嘅方式建構，所以呢個指標需要比本書大部分其他指標更高嘅方法透明度，先可以獲得持懷疑態度嘅付款方或財務團隊嘅信任。

## 點計算

```
每診療個案成本 = 界定個案時間窗內提供嘅所有護理總成本
                 （所有護理環境、所有成本類別）/ 個案數目

同歷史基線同期群針對同一臨床界定個案類型嘅每個個案
成本作比較，並按兩個同期群之間嘅個案組合
（年齡、合併症、嚴重程度）進行調整。

包括但唔限於直接臨床成本：科技平台同裝置成本、
額外臨床人手時間，以及轉移咗環境（例如由住院
轉到居家）而非完全消失嘅任何護理。
```

## 計算示例

一個醫療系統嘅全髖關節置換個案（由手術到 90 日康復）歷史基線成本為每個個案 $28,000，根據 200 個歷史個案。引入一個新嘅數碼手術後監測計劃，使用該計劃嘅 150 個新個案顯示平均成本為每個個案 $24,500——每個個案減少 $3,500，主要由康復期間較少急症室診症同較短嘅平均住院日數帶動。喺針對數碼監測同期群相比歷史基線稍為年輕、合併症較低嘅個案組合進行風險調整之後，經調整嘅節省收窄至每個個案 $2,100——仍然係真正嘅改善，但實質上比原始、未經調整嘅比較所顯示嘅細。

## 數據來源同注意事項

個案總成本通常由醫療系統自己嘅成本核算或者財務系統匯集，結合索償數據、內部成本分配，以及（如涉及數碼平台）其授權同硬件成本——準確匯集呢個數字，通常係任何數碼健康價值分析中最困難、最耗資源嘅部分，因為成本經常被記錄喺從未設計成喺個案層面合併嘅獨立系統入面。每當數碼管理同期群同歷史基線同期群並非透過真正隨機分配時，個案組合調整都係必要，因為數碼計劃經常首先提供畀參與度更高、一般更健康或者動機更強嘅病人，可以產生表面上嘅成本節省，但實際上係選擇效應而非真正嘅計劃效果。

## 常見陷阱

- **比較個案組合唔同嘅同期群嘅未經調整成本**：碰巧比歷史基線更健康或風險更低嘅數碼管理同期群，會因為同數碼干預本身無關嘅原因，顯示較低嘅每個個案成本；比較之前應該永遠進行風險調整。
- **喺比較嘅「數碼」一方遺漏科技同人手成本**：只追蹤減少嘅臨床使用量、而忽略運行數碼計劃嘅平台、裝置同人手成本嘅成本分析，會高估淨節省。
- **喺不同同期群之間不一致咁界定個案時間窗**：將一個同期群嘅 90 日個案時間窗，同另一個同期群嘅 60 日時間窗比較，所產生嘅成本比較，實際上並唔係量度同一樣嘢。
- **將成本轉移視為成本減少**：由一個護理環境轉移到另一個（例如由住院轉到受監測嘅居家環境）嘅成本，係真實而有價值嘅發現，但在分析上有別於完全消除嘅成本，兩者應該分開匯報。
