# 分流轉送準確度

分流轉送準確度係指病人個案之中，自動或者人工智能輔助分流工具，根據經臨床驗證嘅參考標準判斷，正確將病人轉送到適當護理層級同環境嘅比例——例如自我護理、基層醫療、緊急護理或者急症護理。佢係任何數碼前門、症狀檢查器或者 AI 分流系統嘅安全性同成效指標：工具嘅整個價值主張，建基於正確、快速而一致咁轉送病人。

## 點解重要

不準確嘅分流工具會向兩個方向造成傷害：分流不足（將病人轉送到比所需更低嘅護理層級）可能延誤真正緊急情況嘅治療，而分流過度（將病人轉送到比所需更高嘅護理層級）則浪費稀缺嘅急症同緊急護理容量，無臨床效益而增加成本同病人焦慮。由於呢兩種失敗模式嘅後果好唔同，分流轉送準確度應該永遠連同錯誤方向一齊匯報，而唔係單一嘅總準確度數字，因為後者會隱藏工具係安全定危險咁出錯。評估 AI 分流工具部署嘅監管機構同醫療系統，越嚟越多要求呢類分層準確度匯報，作為臨床批准嘅條件，尤其係對於喺某程度上獨立於臨床人員運作嘅工具。

## 點計算

```
分流轉送準確度 = 正確轉送嘅個案 / 已分流個案總數 × 100

分開匯報分流不足同分流過度：
  分流不足率 = 轉送到比參考標準更低緊急程度嘅個案 /
               已分流個案總數 × 100
  分流過度率 = 轉送到比參考標準更高緊急程度嘅個案 /
               已分流個案總數 × 100

參考標準通常係臨床人員對同一個案嘅回顧性審視，
盡可能對工具嘅輸出採取盲法。
```

## 計算示例

一個 AI 症狀檢查器工具喺一個月內分流 5,000 個病人個案。對其中隨機抽樣嘅 500 個個案進行盲法臨床人員審視，發現 430 個被轉送到正確嘅緊急程度（準確度 86%），45 個分流不足（9%），25 個分流過度（5%）。9% 嘅分流不足率係最需要緊急調查嘅數字，因為佢代表病人可能被引導到比實際所需更低緊急程度嘅護理嘅個案；5% 嘅分流過度率係容量同成本方面嘅關注，但並非直接嘅安全問題。

## 數據來源同注意事項

用嚟量度分流準確度嘅參考標準極為重要：由單一臨床人員審視，會引入該臨床人員自身判斷嘅變異性，所以可信嘅準確度數字通常需要多名獨立審視者並有文件記錄嘅評分者間一致性，或者同其後確認嘅臨床結果（事後確定病人實際需要嘅護理）作比較。抽樣亦都重要：只審視方便樣本，或者只審視被標記為異常嘅個案，唔會產生可以推廣到工具整體表現嘅數字。喺底層個案數量許可嘅情況下，準確度數字應該按就診症狀或者主訴類別分開匯報，因為分流工具好少喺所有病況上表現一致。

## 常見陷阱

- **匯報單一混合準確度數字**：將分流不足同分流過度合併成一個數字，會隱藏工具嘅錯誤係咪偏向更危險嘅失敗模式；應該永遠分開匯報。
- **使用單一、非盲法嘅審視者作為參考標準**：咁樣會靜靜地令準確度數字偏向該審視者自己會做嘅決定，而唔係獨立嘅臨床標準。
- **只喺回顧性、方便嘅數據上驗證**：工具喺實時、含糊嘅病人輸入下嘅真實轉送準確度，往往同其喺開發期間組建嘅整理驗證集上嘅準確度有實質差異。
- **忽略部署後嘅表現漂移**：AI 分流模型嘅準確度，會隨病人人群、就診症狀或者護理路徑可用性嘅改變而隨時間下降；準確度應該定期重新量度，而唔係驗證一次就假設穩定。
