# 遠程醫療診症率

遠程醫療診症率，係指一項服務嘅全部診症之中，以視像或者電話遠程進行（而唔係親身到診）嘅比例。佢係一個服務模式組合指標，而唔係活動量指標：佢話你知護理係點樣提供，呢點對於容量規劃、可及性同臨床適切性好重要，同時同提供咗幾多護理嘅總量完全係兩回事。

## 點解重要

COVID-19 疫情期間，視像診症急速擴張之後，好多服務嘅運作模式都改變咗，機構需要一個穩定嘅方法去監察呢個轉變係持續緊、慢慢回落到疫情前嘅水平，定係受政策積極引導。遠程醫療並唔係親身診症嘅統一替代品：適切性因專科、診症類型（藥物檢討同身體檢查嘅情況大不相同）同病人喜好而異，所以「啱嘅」比率係臨床同營運上嘅判斷，而唔係一個要盡量推高嘅目標。資助機構同監管機構亦會連同結果同安全指標，用呢個比率去決定報銷政策，並且檢查遠程護理有冇被單純套用喺本來需要親身診症嘅個案上面。

## 點計算

```
遠程醫療診症率 = 遠程醫療診症 / (遠程醫療診症 + 親身診症) × 100

盡可能按模式分開匯報：
  視像率 = 視像診症 / 全部診症 × 100
  電話率 = 純電話診症 / 全部診症 × 100

分母應該只計算已完成嘅診症（見陷阱），
並且針對界定好嘅服務、專科同時間段。
```

## 計算示例

一個社區精神健康服務喺一個季度內記錄咗 4,000 次已完成嘅門診接觸：1,200 次親身、1,600 次視像、1,200 次電話。遠程醫療診症率為 (1,600 + 1,200) / 4,000 × 100 = 70%，其中視像率 40%，純電話率 30%。如果只匯報合併嘅 70%，就會掩蓋咗呢度大部分「遠程醫療」其實係純語音，而純語音通常同視像有唔同嘅臨床風險特徵同病人體驗。

## 數據來源同注意事項

診症類型通常記錄喺電子健康紀錄嘅結構化欄位（診症類型或地點），或者由賬單編碼推斷，例如服務地點編碼或者索償單上嘅遠程醫療修飾碼。編碼做法喺不同機構之間，甚至同一機構內嘅不同臨床人員之間，都有顯著差異，所以跨站點比較比率之前，應該先確認各處對「遠程醫療」嘅編碼方式相同。如果一次診症開始時係視像，但因為技術問題轉為電話，應該一致咁編碼（通常按承載大部分臨床內容嘅模式），而且呢條規則應該有文件記錄，而唔係交由個別人員自行判斷。

## 常見陷阱

- **計算嘗試中而非已完成嘅診症**：一次連線失敗然後重新預約嘅遠程醫療診症，唔應該將遠程醫療分母膨脹兩次。
- **將視像同電話視為可互換**：兩者有唔同嘅臨床同公平性含義（電話缺乏視覺評估，但對冇智能手機、穩定數據或者私隱空間進行視像嘅病人更易使用）；盡可能分開匯報。
- **忽略同爽約嘅關係**：爽約行為往往因模式而異；喺單憑遠程醫療比率上升就得出「可及性改善」嘅結論之前，請參閱[預約爽約率](../預約爽約率/)。
- **將高比率視為本身就好**：對於某啲病況同診症類型，適當嘅遠程醫療比率係因臨床設計而偏低，並非數碼成熟度嘅失敗。
