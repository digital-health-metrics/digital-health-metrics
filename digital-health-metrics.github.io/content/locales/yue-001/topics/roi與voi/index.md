# 投資回報（ROI）同投資價值（VOI）

投資回報（ROI）係數碼健康平台相對其總成本——授權、硬件部署、實施同持續人手——所產生嘅淨財務回報，以比率或百分比表示。投資價值（VOI）係更廣泛嘅配套指標，捕捉純財務 ROI 計算無法反映嘅回報：護理質素改善、病人同臨床人員滿意度、健康公平性影響同機構聲譽，呢啲都無法乾淨咁轉換成金額數字，但全部都關乎數碼健康投資應否被視為成功。兩者一齊回答兩條唔同而互補嘅問題：ROI 問「呢項投資喺財務上有冇收回成本？」；VOI 問「考慮到所有重要嘅事情，呢件事值唔值得做？」

## 點解重要

一項喺第一年顯示欠佳或者負 ROI 嘅數碼健康投資，並唔自動等於失敗，而一項顯示強勁 ROI 嘅投資，亦唔自動等於成功，如果 ROI 計算忽略咗計劃喺純成本抵銷之外產生嘅重大價值——呢個正正係 VOI 存在要彌補嘅差距，而單靠 ROI 嘅機構，有削減資助具真正價值、但尚未或者永遠唔會以直接財務回報形式出現嘅計劃嘅風險。同時，VOI 比 ROI 更主觀、更難基準比較，令佢容易被用嚟為一個並未實際帶來任何可量度價值嘅計劃繼續投資辯護；將兩者一齊匯報，並盡可能令 VOI 嘅組成部分具體同可量度，先係令呢個框架保持誠實、而唔會變成逃避財務問責方式嘅紀律。長期數碼健康投資決策——尤其係價值為本護理，其中質素同公平性結果直接同付款掛鈎——越嚟越多要求並列兩個數字。

## 點計算

```
ROI = （財務效益 − 總投資成本）/ 總投資成本 × 100

財務效益來源：每診療個案成本減少、病床日減少
（轉換成成本數字）、避免嘅急症室診症（見急症室
分流率）、減少嘅再入院罰款，以及任何直接收入。

總投資成本：平台授權、硬件／裝置部署同維護、
實施同整合成本、持續嘅臨床同技術人手。

VOI 並非單一公式，而係一個結構化、多維度嘅
記分卡，將 ROI 同界定、追蹤嘅非財務價值範疇結合，
例如：
  臨床質素（例如生物指標改善率、再入院率）
  病人體驗（例如病人淨推薦值、SUS 分數）
  公平性  （例如數碼接達率、數碼素養率）
  人力資源（例如醫生職業倦怠率）
每個範疇按其自身標準匯報，而唔係人為轉換成
金額數字，並連同財務 ROI 數字一齊呈現。
```

## 計算示例

一個遠程監測計劃第一年成本 $600,000（平台授權、裝置部署同額外臨床人手），並產生 $750,000 可量化財務效益（病床日減少同避免嘅再入院罰款）。ROI 為 ($750,000 − $600,000) / $600,000 × 100 = 25%。除咗呢個數字，機構嘅 VOI 記分卡匯報病人淨推薦值改善 5 分、已登記高血壓病人嘅生物指標穩定率為 68%，以及已登記臨床人員嘅非辦公時間記錄時間有可量度嘅減少。呢三項額外發現都唔會改變 25% 嘅 ROI 數字，但合起上嚟，為繼續投資建立咗比單靠 ROI 數字所能支持嘅更強有力嘅理據，尤其係對於同樣重視質素同公平性結果、不亞於財務回報嘅持份者（臨床領導層、病人權益團體）。

## 數據來源同注意事項

ROI 嘅財務效益一方，取材自本書其他地方使用嘅同一批成本同結果數據——每診療個案成本、病床日減少、急症室分流率——並使用機構自己嘅成本核算方法轉換成金額數字，應該使用保守、站得住腳嘅假設，而唔係樂觀嘅最佳情況假設，因為建基於進取假設嘅 ROI 數字，經不起持懷疑態度嘅財務團隊審視。VOI 嘅非財務範疇，每個都應該使用本書其他地方已經驗證嘅指標（生物指標穩定率、病人淨推薦值、數碼接達率、醫生職業倦怠率），而唔係非正式自創嘅替代指標，咁樣 VOI 記分卡本身先可以保持可審核同可隨時間比較，而唔會變成定義鬆散嘅敘述。

## 常見陷阱

- **對具有重大非財務價值嘅計劃只匯報 ROI**：咁樣有削減資助具真正臨床、公平性或人力資源價值嘅計劃嘅風險，純粹因為該價值喺純財務計算中睇唔到；應該將 ROI 同結構化 VOI 記分卡配合使用。
- **將 VOI 視為逃避財務問責嘅方法**：VOI 應該為每個非財務範疇使用具體、已驗證嘅指標，而唔係含糊或者未經量度嘅價值聲稱，否則就變成喺冇真正證據之下為持續開支辯護嘅方法。
- **喺 ROI 成本避免計算中使用樂觀或未經驗證嘅假設**：建基於有關避免成本嘅進取假設嘅 ROI 數字，經不起審視，並可能損害未來投資理據嘅可信度。
- **喺未經調整下比較成本結構差異極大嘅計劃嘅 ROI 數字**：前期資本成本高、回本期長嘅計劃，唔應該喺冇考慮不同時間跨度之下，同前期成本低、回本快嘅計劃，用單一年度 ROI 數字作比較。
