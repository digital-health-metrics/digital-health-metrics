# ອັດຕາສ່ວນ LTV ຕໍ່ CAC

ອັດຕາສ່ວນ LTV ຕໍ່ CAC ປຽບທຽບມູນຄ່າຕະຫຼອດຊີວິດຂອງລູກຄ້າ (LTV) — ລາຍຮັບ ຫຼື ກຳໄລຂັ້ນຕົ້ນທັງໝົດທີ່ອົງການຄາດວ່າຈະໄດ້ຮັບຈາກຄົນເຈັບ ຫຼື ລູກຄ້າຕະຫຼອດຄວາມສຳພັນທັງໝົດກັບຜະລິດຕະພັນ — ກັບຕົ້ນທຶນແທ້ຈິງໃນການຫາລູກຄ້ານັ້ນ (ເບິ່ງຕົ້ນທຶນການຫາລູກຄ້າທີ່ແທ້ຈິງ). ມັນເປັນຕົວຊີ້ວັດເສດຖະສາດຫົວໜ່ວຍ (unit-economics) ທີ່ສຳຄັນທີ່ສຸດຢ່າງດຽວສຳລັບການຕັດສິນວ່າການເຕີບໂຕຂອງອົງການສຸຂະພາບດິຈິຕອນຍືນຍົງທາງການເງິນຫຼືບໍ່ ເພາະຖານລູກຄ້າທີ່ເຕີບໃຫຍ່ຂຶ້ນໂດຍຂາດທຶນບໍ່ແມ່ນສັນຍານຂອງສຸຂະພາບທີ່ດີ ບໍ່ວ່າເສັ້ນໂຄ້ງການເຕີບໂຕຈະເບິ່ງເປັນບວກປານໃດ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ອົງການສຸຂະພາບດິຈິຕອນສາມາດເຮັດໃຫ້ຖານຜູ້ໃຊ້ເຕີບໂຕຢ່າງຕໍ່ເນື່ອງ ໃນຂະນະທີ່ທຳລາຍມູນຄ່າຢ່າງງຽບໆໃນລູກຄ້າໃໝ່ທຸກຄົນ ຖ້າຕົ້ນທຶນການຫາລູກຄ້າເກີນມູນຄ່າຕະຫຼອດຊີວິດ; ອັດຕາສ່ວນ LTV ຕໍ່ CAC ເປັນຕົວຊີ້ວັດທີ່ເຮັດໃຫ້ເຫັນສິ່ງນີ້ໃນແບບທີ່ອັດຕາການເຕີບໂຕ ຫຼື ຈຳນວນລູກຄ້າດິບພຽງຢ່າງດຽວເຮັດບໍ່ໄດ້. ອັດຕາສ່ວນ 3:1 (ມູນຄ່າຕະຫຼອດຊີວິດຢ່າງໜ້ອຍສາມເທົ່າຂອງຕົ້ນທຶນການຫາລູກຄ້າ) ແມ່ນຄ່າອ້າງອີງພື້ນຖານທີ່ອ້າງເຖິງຢ່າງກວ້າງຂວາງສຳລັບທຸລະກິດແບບສະໝັກສະມາຊິກ ຫຼື ລາຍຮັບຊ້ຳ ທີ່ຍືນຍົງ ເຊິ່ງໃຫ້ຊ່ອງພໍທີ່ຈະຄຸ້ມຕົ້ນທຶນດຳເນີນງານນອກເໜືອຈາກການຫາລູກຄ້າ ແລະ ຍັງສ້າງຜົນຕອບແທນ; ອັດຕາສ່ວນຕ່ຳກວ່າ 1:1 ໝາຍຄວາມວ່າອົງການຂາດທຶນໃນທຸກລູກຄ້າທີ່ຫາມາ ແລະ ອັດຕາສ່ວນທີ່ສູງກວ່າ 3:1 ຫຼາຍ (ເຊັ່ນ 10:1 ຂຶ້ນໄປ) ສາມາດຊີ້ບອກວ່າລົງທຶນໃນການເຕີບໂຕໜ້ອຍເກີນໄປ ເພາະມັນຊີ້ໃຫ້ເຫັນວ່າອົງການສາມາດຫາລູກຄ້າເພີ່ມໄດ້ຢ່າງມີກຳໄລຫຼາຍກວ່າທີ່ເຮັດໃນປັດຈຸບັນ. ນັກລົງທຶນ, ຄະນະກຳມະການ ແລະ ຜູ້ຈ່າຍເງິນທີ່ປະເມີນຄວາມຍືນຍົງທາງການເງິນຂອງບໍລິສັດສຸຂະພາບດິຈິຕອນຖືວ່າອັດຕາສ່ວນນີ້ເປັນໜຶ່ງໃນຕົວເລກທຳອິດທີ່ເຂົາເຈົ້າຖາມຫາ.

## ວິທີຄຳນວນ

```
LTV = ລາຍຮັບສະເລ່ຍ (ຫຼື ກຳໄລຂັ້ນຕົ້ນ) ຕໍ່ລູກຄ້າຕໍ່ໄລຍະ × ໄລຍະເວລາຕະຫຼອດ
      ຊີວິດຂອງລູກຄ້າສະເລ່ຍໃນຫົວໜ່ວຍໄລຍະດຽວກັນ

ອັດຕາສ່ວນ LTV ຕໍ່ CAC = LTV / CAC ທີ່ແທ້ຈິງ

ອັດຕາສ່ວນ 3:1 ເປັນຄ່າພື້ນຖານທີ່ຍືນຍົງທີ່ອ້າງເຖິງທົ່ວໄປ; ຕ່ຳກວ່າ 1:1
ຊີ້ວ່າອົງການຂາດທຶນໃນການຫາລູກຄ້າ; ສູງກວ່າ 3:1 ຫຼາຍ (ເຊັ່ນ 10:1+) ສາມາດ
ຊີ້ບອກການລົງທຶນໃນການເຕີບໂຕໜ້ອຍເກີນໄປ.
```

## ຕົວຢ່າງການຄຳນວນ

ບໍລິການສະໝັກສະມາຊິກສຸຂະພາບດິຈິຕອນສ້າງລາຍຮັບສະເລ່ຍລາຍເດືອນ $40 ຕໍ່ຄົນເຈັບ ແລະ ຄົນເຈັບສະເລ່ຍຢູ່ເປັນສະມາຊິກ 18 ເດືອນ ໃຫ້ LTV ເທົ່າກັບ $40 × 18 = $720. CAC ທີ່ແທ້ຈິງຂອງບໍລິການນີ້ (ເບິ່ງວິທີຕົວຢ່າງການຄຳນວນຂອງຫົວຂໍ້ນັ້ນ) ຄຳນວນໄດ້ $180 ຕໍ່ຄົນເຈັບທີ່ຫາມາ. ອັດຕາສ່ວນ LTV ຕໍ່ CAC ແມ່ນ $720 / $180 = 4:1 ສູງກວ່າເກນພື້ນຖານຄວາມຍືນຍົງ 3:1 ຢ່າງສະບາຍ. ຖ້າ CAC ທີ່ແທ້ຈິງຄຳນວນໂດຍໃຊ້ສະເພາະຕົ້ນທຶນທີ່ລາຍງານໂດຍແພລດຟອມໂຄສະນາ ($120 ກ່ອນລວມຄ່າທຳນຽມອົງການ ແລະ ແຮງງານຮັບເຂົ້າ) ອັດຕາສ່ວນຈະປາກົດເປັນ 6:1 — ພາບເສດຖະສາດຫົວໜ່ວຍທີ່ດີກວ່າ ແລະ ເຂົ້າໃຈຜິດຢ່າງມີນັຍສຳຄັນເມື່ອທຽບກັບຕົວເລກ 4:1 ທີ່ແທ້ຈິງ.

## ແຫຼ່ງຂໍ້ມູນ ແລະ ຂໍ້ຄວນລະວັງ

LTV ຂຶ້ນກັບການສົມມຸດກ່ຽວກັບຕະຫຼອດຊີວິດລູກຄ້າສະເລ່ຍ ເຊິ່ງຖືກສັງເຄາະຈາກຂໍ້ມູນການຮັກສາ ຫຼື ການຍົກເລີກ (churn) ຂອງອົງການເອງ (ເບິ່ງອັດຕາການຮັກສາຜູ້ໃຊ້) — ທຸລະກິດທີ່ມີ churn ສູງມີຕະຫຼອດຊີວິດສະເລ່ຍທີ່ມີປະສິດທິພາບສັ້ນກວ່າ ແລະ ດັ່ງນັ້ນ LTV ຕ່ຳກວ່າ ເຖິງແມ່ນລາຍຮັບຕໍ່ລູກຄ້າຕໍ່ໄລຍະຈະເບິ່ງດີ. ເນື່ອງຈາກ LTV ເປັນການປະມານການແບບຄາດການ ບໍ່ແມ່ນຂໍ້ເທັດຈິງໃນອະດີດທີ່ສັງເກດໄດ້ ມັນຄວນຖືກຄຳນວນຄືນເປັນປະຈຳເມື່ອຂໍ້ມູນການຮັກສາສະສົມ ແລະ ປັບປຸງຖ້າການສົມມຸດ churn ພິສູດວ່າຜິດ ແທນທີ່ຈະກຳນົດຄັ້ງດຽວແລ້ວປະໄວ້ລ້າສະໄໝ. ການໃຊ້ CAC ທີ່ລາຍງານໂດຍແພລດຟອມແທນ CAC ທີ່ແທ້ຈິງໃນອັດຕາສ່ວນນີ້ເປັນໜຶ່ງໃນວິທີທົ່ວໄປທີ່ສຸດທີ່ອົງການສາມາດເຮັດໃຫ້ຕົນເອງເຊື່ອວ່າເສດຖະສາດຫົວໜ່ວຍແຂງແຮງກວ່າທີ່ເປັນຈິງ ເພາະ CAC ທີ່ຕ່ຳກວ່າຄວາມຈິງເຮັດໃຫ້ອັດຕາສ່ວນສູງຂຶ້ນຕາມກົນໄກ.

## ຈຸດອ່ອນທີ່ຄວນລະວັງ

- **ການໃຊ້ CAC ທີ່ລາຍງານໂດຍແພລດຟອມແທນ CAC ທີ່ແທ້ຈິງ**: ສິ່ງນີ້ເຮັດໃຫ້ອັດຕາສ່ວນສູງຂຶ້ນຕາມກົນໄກ ແລະ ສາມາດເຮັດໃຫ້ຍຸດທະສາດການຫາລູກຄ້າທີ່ບໍ່ຍືນຍົງເບິ່ງຄືວ່າຍືນຍົງ; ຄວນໃຊ້ຕົວເລກ CAC ທີ່ແທ້ຈິງແບບລວມຕົ້ນທຶນເຕັມສະເໝີ.
- **ການໃຊ້ການສົມມຸດຕະຫຼອດຊີວິດລູກຄ້າສະເລ່ຍທີ່ລ້າສະໄໝ ຫຼື ມອງໂລກໃນແງ່ດີ**: LTV ທີ່ຄຳນວນຈາກເສັ້ນໂຄ້ງການຮັກສາທີ່ລ້າສະໄໝຈະບໍ່ສະທ້ອນພຶດຕິກຳ churn ປັດຈຸບັນ ໂດຍສະເພາະຫຼັງການປ່ຽນແປງຂອງຜະລິດຕະພັນ, ລາຄາ ຫຼື ຕະຫຼາດທີ່ເຮັດໃຫ້ການຮັກສາປ່ຽນໄປ.
- **ການຖືວ່າອັດຕາສ່ວນສູງຫຼາຍເປັນສິ່ງທີ່ດີຢ່າງບໍ່ກຳກວມ**: ອັດຕາສ່ວນທີ່ສູງກວ່າ 3:1 ຫຼາຍສາມາດສື່ເຖິງການລົງທຶນໃນການເຕີບໂຕໜ້ອຍເກີນໄປ ແທນທີ່ຈະເປັນປະສິດທິພາບທີ່ຍອດຢ້ຽມ ເພາະມັນໝາຍຄວາມວ່າອົງການອາດຫາລູກຄ້າເພີ່ມໄດ້ຢ່າງມີກຳໄລຫຼາຍກວ່າທີ່ເຮັດໃນປັດຈຸບັນ.
- **ການຄຳນວນອັດຕາສ່ວນລວມດຽວຂ້າມສ່ວນລູກຄ້າທີ່ແຕກຕ່າງກັນຫຼາຍ**: ສ່ວນທີ່ມີລາຍຮັບສູງ ແລະ churn ຕ່ຳສາມາດປິດບັງສ່ວນອື່ນທີ່ມີເສດຖະສາດຫົວໜ່ວຍບໍ່ດີ; ຄຳນວນອັດຕາສ່ວນຕໍ່ແຕ່ລະສ່ວນທີ່ມີນັຍສຳຄັນ (ເຊັ່ນ ຕາມຊ່ອງທາງການຫາລູກຄ້າ ຫຼື ສາຍຜະລິດຕະພັນ) ເມື່ອປະລິມານອະນຸຍາດ.
