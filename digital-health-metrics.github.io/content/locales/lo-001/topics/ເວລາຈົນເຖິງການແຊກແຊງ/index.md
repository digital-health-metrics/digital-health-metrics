# ເວລາຈົນເຖິງການແຊກແຊງ

ເວລາຈົນເຖິງການແຊກແຊງ (time to intervention) ແມ່ນເວລາທີ່ຜ່ານໄປ ນັບແຕ່ການແຈ້ງເຕືອນສຸຂະພາບອັດຕະໂນມັດຖືກສ້າງຂຶ້ນ — ຕົວຢ່າງ ອຸປະກອນຕິດຕາມທາງໄກກວດພົບສັນຍານຊີບທີ່ຢູ່ນອກຊ່ວງ ຫຼື ເຄື່ອງມືຄັດກອງດິຈິຕອນໝາຍຄົນເຈັບທີ່ອາການຮ້າຍແຮງຂຶ້ນ — ຈົນຮອດສະມາຊິກທີມທາງຄລີນິກເລີ່ມຕອບສະໜອງຢ່າງແທ້ຈິງ. ມັນເປັນຕົວຊີ້ວັດກະບວນການທີ່ກຳນົດວ່າລະບົບແຈ້ງເຕືອນອັດຕະໂນມັດສົ່ງມອບຄຳສັນຍາຫຼັກຂອງມັນຫຼືບໍ່: ຈັບບັນຫາໄດ້ໄວກວ່າແບບຈຳລອງດັ້ງເດີມຂອງການເຊັກອິນຕາມກຳນົດ ຫຼື ການໂທລະສັບທີ່ຄົນເຈັບເປັນຜູ້ເລີ່ມຕົ້ນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ລະບົບແຈ້ງເຕືອນທີ່ສ້າງການແຈ້ງເຕືອນທີ່ຖືກຕ້ອງທາງຄລີນິກແຕ່ບໍ່ຖືກຕິດຕາມດ້ວຍການຕອບສະໜອງທັນເວລາ ບໍ່ໄດ້ປັບປຸງຄວາມປອດໄພຂອງຄົນເຈັບແທ້; ຄຸນຄ່າທັງໝົດຂອງການຕິດຕາມທາງໄກ ແລະ ການແຈ້ງເຕືອນອັດຕະໂນມັດອີງໃສ່ການປິດວົງຈອນໄດ້ໄວກວ່າເສັ້ນທາງທາງເລືອກທີ່ບໍ່ມີການຕິດຕາມ. ເນື່ອງຈາກລະດັບຄວາມຮ້າຍແຮງຂອງການແຈ້ງເຕືອນຕ່າງກັນຮັບປະກັນຄວາມຮີບດ່ວນຂອງການຕອບສະໜອງທີ່ແຕກຕ່າງກັນ ເວລາຈົນເຖິງການແຊກແຊງຄວນລາຍງານຕາມລະດັບຄວາມຮ້າຍແຮງສະເໝີ ແທນທີ່ຈະເປັນຄ່າສະເລ່ຍດຽວ ເພາະຄ່າສະເລ່ຍທີ່ໄວຂ້າມການແຈ້ງເຕືອນທັງໝົດສາມາດປິດບັງການຕອບສະໜອງທີ່ຊ້າຢ່າງອັນຕະລາຍຕໍ່ການແຈ້ງເຕືອນທີ່ຮ້າຍແຮງທີ່ສຸດຈຳນວນນ້ອຍ. ຕົວຊີ້ວັດນີ້ຍັງເປັນໜຶ່ງໃນວິທີທີ່ຊັດເຈນ ແລະ ຊັກຊວນທີ່ສຸດທີ່ຈະສະແດງຄຸນຄ່າຂອງໂຄງການຕິດຕາມອັດຕະໂນມັດຕໍ່ຜູ້ນຳທາງຄລີນິກ ແລະ ຜູ້ຈ່າຍເງິນ ເພາະມັນສາມາດປຽບທຽບໂດຍກົງກັບເວລາຕອບສະໜອງແບບບໍ່ອັດຕະໂນມັດກ່ອນໜ້າຂອງອົງການດຽວກັນສຳລັບສະຖານະການທາງຄລີນິກທີ່ຄ້າຍຄືກັນ.

## ວິທີຄຳນວນ

```
ເວລາຈົນເຖິງການແຊກແຊງ = ເວລາ(ການຕອບສະໜອງທາງຄລີນິກເລີ່ມຕົ້ນ) −
                          ເວລາ(ການແຈ້ງເຕືອນຖືກສ້າງ)

ລາຍງານຄ່າມັດທະຍານ ແລະ ເປີເຊັນໄທລ໌ສູງ (ເຊັ່ນ ທີ 90) ແບ່ງຕາມລະດັບ
ຄວາມຮ້າຍແຮງຂອງການແຈ້ງເຕືອນ ບໍ່ແມ່ນຄ່າສະເລ່ຍລວມດຽວ.

"ການຕອບສະໜອງທາງຄລີນິກເລີ່ມຕົ້ນ" ຄວນຖືກກຳນົດຢ່າງຊັດເຈນ ແລະ
ສອດຄ່ອງ — ເຊັ່ນ ແພດເປີດບັນທຶກຂອງຄົນເຈັບ ແລະ ດຳເນີນການ, ຫຼື ການພະຍາຍາມ
ຕິດຕໍ່ອອກທີ່ມີການບັນທຶກ — ບໍ່ແມ່ນພຽງແຕ່ການແຈ້ງເຕືອນຖືກເບິ່ງ ຫຼື
ຮັບຊາບໂດຍບໍ່ມີການດຳເນີນການ.
```

## ຕົວຢ່າງການຄຳນວນ

ລະບົບແຈ້ງເຕືອນຂອງໂຄງການຕິດຕາມຫົວໃຈທາງໄກໝາຍການແຈ້ງເຕືອນຄວາມຮ້າຍແຮງສູງຂອງຈັງຫວະຫົວໃຈຜິດປົກກະຕິ 200 ຄັ້ງໃນເດືອນໜຶ່ງ. ເວລາມັດທະຍານຈາກການສ້າງການແຈ້ງເຕືອນຈົນຮອດແພດເລີ່ມຕິດຕໍ່ອອກແມ່ນ 12 ນາທີ ໂດຍເວລາເປີເຊັນໄທລ໌ທີ 90 ແມ່ນ 38 ນາທີ. ຂໍ້ມູນໃນອະດີດຈາກເສັ້ນທາງກ່ອນໜ້າທີ່ບໍ່ໄດ້ຕິດຕາມຂອງປະຊາກອນດຽວກັນ (ບ່ອນທີ່ເຫດການທີ່ຄ້າຍຄືກັນໂດຍທົ່ວໄປຈະປາກົດພຽງໃນການມາຄລີນິກຕາມກຳນົດຄັ້ງຕໍ່ໄປ ຫຼື ການມາໂຮງໝໍ) ສະແດງເວລາມັດທະຍານຈົນເຖິງການຕອບສະໜອງທາງຄລີນິກໃດໆທີ່ວັດເປັນມື້ ບໍ່ແມ່ນນາທີ. ການປຽບທຽບນີ້ — ບໍ່ແມ່ນຕົວເລກ 12 ນາທີທີ່ແຍກຕ່າງຫາກ — ແມ່ນສິ່ງທີ່ສະແດງຄຸນຄ່າທາງຄລີນິກຂອງໂຄງການຕິດຕາມ; ຕົວເລກເປີເຊັນໄທລ໌ທີ 90 ສຳຄັນເທົ່າທຽມກັນ ເພາະມັນລະບຸຫາງຂອງການແຈ້ງເຕືອນທີ່ໃຊ້ເວລາເກີນເຄິ່ງຊົ່ວໂມງກວ່າຈະດຳເນີນການ ແລະ ສົມຄວນໄດ້ຮັບການທົບທວນສາເຫດຫຼັກຂອງຕົນເອງ.

## ແຫຼ່ງຂໍ້ມູນ ແລະ ຂໍ້ຄວນລະວັງ

ເວລາການສ້າງການແຈ້ງເຕືອນມາຈາກບັນທຶກເຫດການຂອງແພລດຟອມຕິດຕາມເອງ; ເວລາການຕອບສະໜອງທາງຄລີນິກໂດຍທົ່ວໄປມາຈາກບັນທຶກການກວດສອບຂອງບັນທຶກສຸຂະພາບເອເລັກໂຕຣນິກ ຫຼື ລະບົບຂະບວນການເຮັດວຽກ ຫຼື ການຈັດການໜ້າວຽກຂອງທີມດູແລເອງ ແລະ ທັງສອງລະບົບນີ້ຕ້ອງຖືກຊິງຄ໌ເວລາຢ່າງແມ່ນຍຳເພື່ອໃຫ້ຊ່ວງເວລາທີ່ຄຳນວນໜ້າເຊື່ອຖື. "ການຕອບສະໜອງເລີ່ມຕົ້ນ" ຕ້ອງການນິຍາມທີ່ເຂັ້ມງວດ ແລະ ບັນທຶກໄວ້ ເພາະແພດທີ່ພຽງແຕ່ເບິ່ງ ຫຼື ປິດການແຈ້ງເຕືອນໂດຍບໍ່ດຳເນີນການຕໍ່ ເປັນເຫດການທີ່ແຕກຕ່າງຢ່າງພື້ນຖານ ແລະ ໜ້າໝັ້ນໃຈໜ້ອຍກວ່າຫຼາຍ ຈາກທີ່ກະຕຸ້ນການຕິດຕໍ່ອອກ ຫຼື ການແຊກແຊງຈິງ — ການປົນສອງຢ່າງນີ້ຈະເຮັດໃຫ້ເວລາຕອບສະໜອງເບິ່ງດີກວ່າຄວາມເປັນຈິງທາງຄລີນິກ. ລະດັບພະນັກງານໃນເວລາກາງຄືນ ແລະ ທ້າຍອາທິດມັກມີຜົນຕໍ່ເວລາຈົນເຖິງການແຊກແຊງຢ່າງມີນັຍສຳຄັນ ດັ່ງນັ້ນຕົວຊີ້ວັດນີ້ຄວນຖືກລາຍງານຕາມສ່ວນເວລາຂອງມື້ ແລະ ມື້ຂອງອາທິດ ເມື່ອປະລິມານການແຈ້ງເຕືອນອະນຸຍາດ ແທນທີ່ຈະເປັນພຽງຄ່າສະເລ່ຍລວມ 24/7 ທີ່ສາມາດປິດບັງຊ່ອງຫວ່າງການຕອບສະໜອງນອກຊົ່ວໂມງທີ່ຮ້າຍແຮງ.

## ຈຸດອ່ອນທີ່ຄວນລະວັງ

- **ການນັບການຮັບຊາບການແຈ້ງເຕືອນເປັນການຕອບສະໜອງ**: ແພດເບິ່ງ ຫຼື ປິດການແຈ້ງເຕືອນບໍ່ຄືກັນກັບການເລີ່ມການຕອບສະໜອງທາງຄລີນິກ; ກຳນົດການຕອບສະໜອງຢ່າງເຂັ້ມງວດວ່າເປັນການດຳເນີນການທີ່ບັນທຶກໄວ້ ບໍ່ແມ່ນການຮັບຊາບແບບຕັ້ງຮັບ.
- **ການລາຍງານເວລາລວມດຽວຂ້າມທຸກລະດັບຄວາມຮ້າຍແຮງ**: ຄ່າສະເລ່ຍທີ່ໄວຂ້າມການແຈ້ງເຕືອນຄວາມຮ້າຍແຮງຕ່ຳ ແລະ ສູງລວມກັນສາມາດປິດບັງເວລາຕອບສະໜອງທີ່ຊ້າຢ່າງອັນຕະລາຍສະເພາະສຳລັບການແຈ້ງເຕືອນຄວາມຮ້າຍແຮງສູງສຸດ ເຊິ່ງສຳຄັນທີ່ສຸດ.
- **ການບໍ່ສົນໃຈຜົນກະທົບຂອງຮູບແບບພະນັກງານ**: ເວລາຕອບສະໜອງມັກແຕກຕ່າງຢ່າງມີນັຍສຳຄັນຕາມເວລາຂອງມື້ ແລະ ມື້ຂອງອາທິດ ເນື່ອງຈາກລະດັບພະນັກງານ; ຄ່າສະເລ່ຍລວມດຽວສາມາດປິດບັງຊ່ອງຫວ່າງການຕອບສະໜອງນອກຊົ່ວໂມງ ຫຼື ທ້າຍອາທິດຢ່າງເປັນລະບົບ.
- **ການປຽບທຽບເວລາຈົນເຖິງການແຊກແຊງຂ້າມອົງການທີ່ມີເກນການແຈ້ງເຕືອນຕ່າງກັນ**: ອົງການທີ່ມີເກນການແຈ້ງເຕືອນທີ່ລະມັດລະວັງກວ່າ (ອ່ອນໄຫວກວ່າ) ຈະສ້າງການແຈ້ງເຕືອນຄວາມຮີບດ່ວນຕ່ຳຫຼາຍກວ່າ ເຊິ່ງສາມາດເຈືອຈາງເວລາຕອບສະໜອງສະເລ່ຍທຽບກັບອົງການທີ່ໃຊ້ເກນທີ່ເຂັ້ມງວດກວ່າ ເປັນອິດສະຫຼະຈາກການຕອບສະໜອງທາງຄລີນິກທີ່ແທ້ຈິງ.
