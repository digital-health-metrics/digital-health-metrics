# អត្រាទស្សនកិច្ចសុខភាពពីចម្ងាយ

អត្រាទស្សនកិច្ចសុខភាពពីចម្ងាយ (telehealth visit rate) គឺជាសមាមាត្រនៃការជួបពិគ្រោះសរុបរបស់សេវាមួយ ដែលត្រូវបានផ្តល់ពីចម្ងាយ តាមវីដេអូ ឬទូរស័ព្ទ ជាជាងដោយផ្ទាល់។ វាជារង្វាស់នៃការលាយឡំនៃបណ្តាញផ្តល់សេវា មិនមែនរង្វាស់សកម្មភាពទេ៖ វាប្រាប់អ្នកថាការថែទាំត្រូវបានផ្តល់យ៉ាងដូចម្តេច ដែលសំខាន់សម្រាប់ការធ្វើផែនការសមត្ថភាព ការទទួលបានសេវា និងភាពសមស្របផ្នែកគ្លីនិក ដោយដាច់ដោយឡែកពីបរិមាណនៃការថែទាំសរុបដែលត្រូវបានផ្តល់។

## ហេតុអ្វីបានជាសំខាន់

សមាមាត្រនៃការថែទាំដែលផ្តល់ពីចម្ងាយបានផ្លាស់ប្តូរគំរូប្រតិបត្តិការរបស់សេវាជាច្រើន បន្ទាប់ពីការពង្រីកយ៉ាងឆាប់រហ័សនៃការពិគ្រោះនិម្មិតក្នុងអំឡុងជំងឺរាតត្បាត COVID-19 ហើយអង្គការត្រូវការវិធីស្ថិរភាពដើម្បីតាមដានថាតើការផ្លាស់ប្តូរនោះកំពុងបន្ត កំពុងត្រឡប់ទៅរកបទដ្ឋានមុនជំងឺរាតត្បាត ឬកំពុងត្រូវបានដឹកនាំយ៉ាងសកម្មដោយគោលនយោបាយ។ សុខភាពពីចម្ងាយមិនមែនជាជម្រើសជំនួសឯកសណ្ឋានសម្រាប់ការជួបផ្ទាល់ទេ៖ ភាពសមស្របប្រែប្រួលតាមឯកទេស តាមប្រភេទនៃការពិគ្រោះ (ការពិនិត្យថ្នាំខុសពីការពិនិត្យរាងកាយខ្លាំង) និងតាមចំណូលចិត្តរបស់អ្នកជំងឺ ដូច្នេះអត្រា "ត្រឹមត្រូវ" គឺជាការវិនិច្ឆ័យផ្នែកគ្លីនិក និងប្រតិបត្តិការ មិនមែនជាគោលដៅដែលត្រូវបង្កើនអតិបរមាទេ។ អ្នកផ្តល់មូលនិធិ និងនិយតករក៏ប្រើអត្រានេះ រួមជាមួយរង្វាស់លទ្ធផល និងសុវត្ថិភាព ដើម្បីសម្រេចគោលនយោបាយសំណង និងដើម្បីពិនិត្យថាការថែទាំពីចម្ងាយមិនត្រូវបានជំនួសលើករណីដែលត្រូវជួបផ្ទាល់។

## របៀបគណនា

```
អត្រាទស្សនកិច្ចសុខភាពពីចម្ងាយ = ការជួបពិគ្រោះពីចម្ងាយ / (ការជួបពិគ្រោះពីចម្ងាយ + ការជួបពិគ្រោះផ្ទាល់) × 100

រាយការណ៍ដោយឡែកតាមទម្រង់នៅពេលអាចធ្វើបាន៖
  អត្រាវីដេអូ   = ការជួបពិគ្រោះតាមវីដេអូ / ការជួបពិគ្រោះសរុប × 100
  អត្រាទូរស័ព្ទ = ការជួបពិគ្រោះតាមទូរស័ព្ទតែប៉ុណ្ណោះ / ការជួបពិគ្រោះសរុប × 100

ភាគបែងគួររាប់តែការជួបពិគ្រោះដែលបានបញ្ចប់ប៉ុណ្ណោះ (មើលកំហុសដែលតែងកើតមាន)
សម្រាប់សេវា ឯកទេស និងរយៈពេលដែលបានកំណត់។
```

## ឧទាហរណ៍អនុវត្ត

សេវាសុខភាពផ្លូវចិត្តសហគមន៍មួយកត់ត្រាការទាក់ទងអ្នកជំងឺក្រៅដែលបានបញ្ចប់ ៤,០០០ ក្នុងមួយត្រីមាស៖ ១,២០០ ជួបផ្ទាល់ ១,៦០០ តាមវីដេអូ និង ១,២០០ តាមទូរស័ព្ទ។ អត្រាទស្សនកិច្ចសុខភាពពីចម្ងាយគឺ (1,600 + 1,200) / 4,000 × 100 = 70% ដោយមានអត្រាវីដេអូ 40% និងអត្រាទូរស័ព្ទតែប៉ុណ្ណោះ 30%។ ការរាយការណ៍តែតួលេខរួម 70% នឹងបិទបាំងការពិតដែលថា ភាគច្រើននៃ "សុខភាពពីចម្ងាយ" នៅទីនេះគឺសំឡេងតែប៉ុណ្ណោះ ដែលជាធម្មតាមានទម្រង់ហានិភ័យគ្លីនិក និងបទពិសោធន៍អ្នកជំងឺខុសពីវីដេអូ។

## ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន

ប្រភេទនៃការជួបពិគ្រោះជាធម្មតាត្រូវបានកត់ត្រាជាវាលមានរចនាសម្ព័ន្ធក្នុងកំណត់ត្រាសុខភាពអេឡិចត្រូនិក (ប្រភេទ ឬទីតាំងនៃការជួប) ឬត្រូវបានសន្និដ្ឋានពីកូដចេញវិក្កយបត្រ ដូចជាកូដទីកន្លែងផ្តល់សេវា ឬកូដកែប្រែសុខភាពពីចម្ងាយលើសំណើទូទាត់។ ការអនុវត្តកូដប្រែប្រួលខ្លាំងរវាងអង្គការ ហើយថែមទាំងរវាងគ្លីនិកករក្នុងអង្គការតែមួយ ដូច្នេះការប្រៀបធៀបអត្រារវាងទីតាំង គួរបញ្ជាក់ជាមុនសិនថា "សុខភាពពីចម្ងាយ" ត្រូវបានកូដតាមរបៀបដូចគ្នាក្នុងទីតាំងនីមួយៗ។ ការជួបដែលចាប់ផ្តើមជាវីដេអូ ប៉ុន្តែធ្លាក់មកទូរស័ព្ទដោយសារបញ្ហាបច្ចេកទេស គួរត្រូវបានកូដជាប់លាប់ (ជាទូទៅជាទម្រង់ដែលផ្ទុកខ្លឹមសារគ្លីនិកភាគច្រើន) ហើយច្បាប់នោះគួរមានឯកសារ ជាជាងទុកឱ្យការវិនិច្ឆ័យផ្ទាល់ខ្លួន។

## កំហុសដែលតែងកើតមាន

- **រាប់ការជួបដែលបានព្យាយាម ជាជាងការជួបដែលបានបញ្ចប់**៖ ការណាត់ជួបសុខភាពពីចម្ងាយដែលភ្ជាប់មិនបាន ហើយត្រូវកក់ឡើងវិញ មិនគួរបំប៉នភាគបែងសុខភាពពីចម្ងាយពីរដងទេ។
- **ចាត់ទុកវីដេអូ និងទូរស័ព្ទជាអ្វីដែលអាចផ្លាស់ប្តូរគ្នាបាន**៖ ពួកវាមានផលប៉ះពាល់គ្លីនិក និងសមធម៌ខុសគ្នា (ទូរស័ព្ទមិនអាចវាយតម្លៃដោយមើលឃើញបាន ប៉ុន្តែងាយស្រួលចូលដំណើរការជាងសម្រាប់អ្នកជំងឺគ្មានស្មាតហ្វូន ទិន្នន័យអាចទុកចិត្តបាន ឬទីកន្លែងឯកជនសម្រាប់វីដេអូ) ដូច្នេះគួររាយការណ៍ដោយឡែកជានិច្ចនៅពេលអាចធ្វើបាន។
- **មិនអើពើទំនាក់ទំនងជាមួយការមិនមកណាត់ជួប**៖ ឥរិយាបថមិនមកណាត់ជួបតែងខុសគ្នាតាមទម្រង់ សូមមើល [អត្រាមិនមកតាមការណាត់ជួប](../អត្រាមិនមកតាមការណាត់ជួប/) មុនសន្និដ្ឋានអំពី "ការទទួលបានសេវាប្រសើរឡើង" ពីអត្រាសុខភាពពីចម្ងាយដែលកើនឡើងតែម្យ៉ាង។
- **ចាត់ទុកអត្រាខ្ពស់ថាល្អដោយខ្លួនឯង**៖ សម្រាប់ជំងឺ និងប្រភេទនៃការពិគ្រោះមួយចំនួន អត្រាសុខភាពពីចម្ងាយដែលសមស្របគឺទាបដោយការរចនាផ្នែកគ្លីនិក មិនមែនដោយការបរាជ័យនៃភាពចាស់ទុំឌីជីថលទេ។

## ប្រភព

- Centers for Medicare & Medicaid Services (CMS) ទិន្នន័យការប្រើប្រាស់សុខភាពពីចម្ងាយរបស់ Medicare និងឯកសារគោលនយោបាយ
- NHS England ស្ថិតិសកម្មភាពសេវាអ្នកជំងឺក្រៅ និងសហគមន៍ រួមទាំងការបែងចែកការចូលរួមនិម្មិត/ពីចម្ងាយ
- អក្សរសាស្ត្រដែលមានការត្រួតពិនិត្យដោយមិត្តរួមការងារ អំពីនិន្នាការប្រើប្រាស់សុខភាពពីចម្ងាយ និងលទ្ធផលតាមទម្រង់
