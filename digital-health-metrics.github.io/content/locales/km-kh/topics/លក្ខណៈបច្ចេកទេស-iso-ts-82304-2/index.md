# ISO/TS 82304-2

ISO/TS 82304-2 គឺជាលក្ខណៈបច្ចេកទេសអន្តរជាតិ (technical specification) ដែលបោះពុម្ពក្រោមគណៈកម្មាធិការបច្ចេកទេស ISO 215 (Health Informatics ព័ត៌មានវិទ្យាសុខភាព) ដែលកំណត់វិធីសាស្ត្រមានរចនាសម្ព័ន្ធសម្រាប់វាយតម្លៃគុណភាពនៃកម្មវិធីសុខភាព និងសុខុមាលភាព — គ្របដណ្តប់ភាពងាយប្រើ ភាពរឹងមាំ និងភាពអាចទុកចិត្តបានផ្នែកបច្ចេកទេស អន្តរប្រតិបត្តិការ គុណភាពមាតិកា និងសុវត្ថិភាព និងឯកជនភាពទិន្នន័យ — សម្រាប់ផលិតផលដែលស្ថិតនៅក្រៅវិសាលភាពនៃនិយតកម្មឧបករណ៍វេជ្ជសាស្ត្រពេញលេញ ប៉ុន្តែនៅតែជះឥទ្ធិពលសំខាន់ដល់ការសម្រេចចិត្ត ឬឥរិយាបថសុខភាពរបស់អ្នកប្រើ។ វាមានដើម្បីបំពេញគម្លាតជាក់លាក់មួយ៖ កម្មវិធីសុខភាព និងសុខុមាលភាពសម្រាប់អ្នកប្រើប្រាស់ភាគច្រើន (ឧបករណ៍តាមដានសុខភាព កំណត់ហេតុរោគសញ្ញា កម្មវិធីណែនាំសុខុមាលភាព) មិនត្រូវបានគ្រប់គ្រងជាឧបករណ៍វេជ្ជសាស្ត្រទេ ប៉ុន្តែពីមុនមកមិនមានវិធីរួម មានរចនាសម្ព័ន្ធដើម្បីវាយតម្លៃ ឬប្រៀបធៀបគុណភាព និងសុវត្ថិភាពមូលដ្ឋានរបស់វាឡើយ។

## ហេតុអ្វីបានជាសំខាន់

ហាងកម្មវិធី (app store) ផ្ទុកកម្មវិធីសុខភាព និងសុខុមាលភាពរាប់រយពាន់ដែលមានគុណភាពប្រែប្រួលខ្លាំង ហើយមុនពេលមានលក្ខណៈបច្ចេកទេសរួម អ្នកជំងឺ គ្លីនិកករ ឬប្រព័ន្ធសុខភាពគ្មានវិធីប្រៀបធៀបមានរចនាសម្ព័ន្ធដើម្បីវិនិច្ឆ័យគុណភាព និងសុវត្ថិភាពមូលដ្ឋានរបស់កម្មវិធីមួយធៀបនឹងមួយទៀតលើសពីពិន្ទុផ្កាយ និងការអះអាងទីផ្សារ — ជាគម្លាតដែលសំខាន់ព្រោះកម្មវិធីសុខភាពដែលរចនាមិនល្អនៅតែអាចបង្កគ្រោះថ្នាក់ពិតប្រាកដ (មាតិកាមិនត្រឹមត្រូវ សុវត្ថិភាពទិន្នន័យអន់ ការអះអាងបំភ័ន្ត) ទោះមិនបំពេញកម្រិតនិយតកម្មនៃឧបករណ៍វេជ្ជសាស្ត្រក៏ដោយ។ ISO/TS 82304-2 ត្រូវបានរៀបចំដោយចេតនាជុំវិញដែនដែលអ្នកពិនិត្យមិនមែនអ្នកឯកទេសអាចវាយតម្លៃបានជាប់លាប់ ដែលធ្វើឱ្យវាក្លាយជាមូលដ្ឋានបច្ចេកទេសសម្រាប់សេវាដាក់ស្លាកគុណភាព និងរៀបចំបញ្ជីកម្មវិធីសុខភាពថ្នាក់ជាតិ និងពាណិជ្ជកម្មជាច្រើន ផ្តល់ដល់ប្រព័ន្ធសុខភាព និងបណ្ណាល័យកម្មវិធីនូវវិធីស្តង់ដារដែលអាចការពារបានដើម្បីរួមបញ្ចូល ឬដកកម្មវិធីចេញពីបញ្ជីណែនាំ ជាជាងពឹងលើការវិនិច្ឆ័យបណ្តោះអាសន្ន។

## របៀបអនុវត្ត

```
ការវាយតម្លៃត្រូវបានរៀបចំជុំវិញដែនគុណភាពដែលបានកំណត់ ដែលត្រូវបានវាយតម្លៃ
តាមការពិនិត្យមានរចនាសម្ព័ន្ធ ជាជាងរូបមន្តលេខតែមួយ៖

ភាពងាយប្រើ (Usability)                    — ភាពច្បាស់លាស់ ភាពចូលដំណើរការបាន និង
                                               ភាពងាយប្រើសម្រាប់ក្រុមអ្នកប្រើគោលដៅ
ភាពរឹងមាំ/ភាពអាចទុកចិត្តបានផ្នែកបច្ចេកទេស — ស្ថិរភាព ដំណើរការ និងការគ្មាន
(Technical robustness/reliability)            ចំណុចខ្វះខាតបច្ចេកទេស
អន្តរប្រតិបត្តិការ (Interoperability)       — សមត្ថភាពប្តូរទិន្នន័យជាមួយប្រព័ន្ធផ្សេង
                                               នៅកន្លែងពាក់ព័ន្ធនឹងមុខងាររបស់កម្មវិធី
គុណភាព និងសុវត្ថិភាពមាតិកា                — ភាពត្រឹមត្រូវ ភាពទាន់សម័យ និងអវត្តមាន
(Content quality and safety)                   នៃការអះអាងសុខភាពគ្រោះថ្នាក់ ឬបំភ័ន្ត
សុវត្ថិភាព និងឯកជនភាព                      — ការអនុវត្តការពារទិន្នន័យ និងតម្លាភាព
(Security and privacy)                          អំពីការប្រើប្រាស់ទិន្នន័យ

ដែននីមួយៗត្រូវបានដាក់ពិន្ទុតាមលក្ខណៈវិនិច្ឆ័យពិនិត្យមានរចនាសម្ព័ន្ធ ហើយរួមបញ្ចូលគ្នា
ជាការវាយតម្លៃគុណភាពរួម ដែលគម្រោងដាក់ស្លាកគុណភាពកម្មវិធីសុខភាពជាច្រើនប្រើជា
មូលដ្ឋានបច្ចេកទេសសម្រាប់ស្លាកគុណភាពសាធារណៈ ឬការសម្រេចរួមបញ្ចូលក្នុងបណ្ណាល័យដែលរៀបចំ។
```

## ឧទាហរណ៍អនុវត្ត

កម្មវិធីបណ្ណាល័យកម្មវិធីឌីជីថលរបស់ប្រព័ន្ធសុខភាពមួយចង់រៀបចំបញ្ជីកម្មវិធីសុខុមាលភាពដែលណែនាំសម្រាប់អ្នកជំងឺ ជាជាងទុកការជ្រើសរើសកម្មវិធីទាំងស្រុងទៅនឹងការស្វែងរកក្នុងហាងកម្មវិធី។ កម្មវិធីបេក្ខភាពនីមួយៗត្រូវបានវាយតម្លៃធៀបនឹងដែន ISO/TS 82304-2៖ កម្មវិធីតាមដានការគេងមួយទទួលបានពិន្ទុល្អលើភាពងាយប្រើ និងភាពរឹងមាំផ្នែកបច្ចេកទេស សមរម្យលើគុណភាពមាតិកា ប៉ុន្តែត្រូវបានដាក់ទង់ក្នុងអំឡុងការពិនិត្យសុវត្ថិភាព និងឯកជនភាព ព្រោះចែករំលែកទិន្នន័យអ្នកប្រើជាមួយអ្នកផ្សព្វផ្សាយភាគីទីបីដោយគ្មានការបង្ហាញច្បាស់លាស់ — ការរកឃើញធ្ងន់ធ្ងរគ្រប់គ្រាន់ដើម្បីដកកម្មវិធីចេញពីបញ្ជីណែនាំ ទោះពិន្ទុភាពងាយប្រើខ្លាំងផ្សេងទៀតក៏ដោយ។ លទ្ធផលតាមដែននេះអាចអនុវត្តបានជាងសម្រាប់ទាំងក្រុមរៀបចំបញ្ជី និង ប្រសិនបើត្រូវបានចែករំលែក អ្នកអភិវឌ្ឍន៍កម្មវិធីខ្លួនឯង ជាងពិន្ទុគុណភាពលាយតែមួយ ព្រោះវាកំណត់យ៉ាងច្បាស់ថាទិដ្ឋភាពណាត្រូវការកែតម្រូវមុនកម្មវិធីអាចត្រូវបានពិចារណាឡើងវិញ។

## ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន

ការវាយតម្លៃធៀបនឹង ISO/TS 82304-2 ជាធម្មតាត្រូវបានអនុវត្តដោយអ្នកពិនិត្យដែលបានបណ្តុះបណ្តាល ឬសេវាវាយតម្លៃដែលទទួលស្គាល់ តាមលក្ខណៈវិនិច្ឆ័យពិនិត្យមានរចនាសម្ព័ន្ធរបស់លក្ខណៈបច្ចេកទេសសម្រាប់ដែននីមួយៗ ហើយគំនិតផ្តួចផ្តើមថ្នាក់ជាតិ និងពាណិជ្ជកម្មជាច្រើន (អង្គការដាក់ស្លាកគុណភាព និងរៀបចំបញ្ជីកម្មវិធីសុខភាព ខ្លះដំណើរការក្រោមការគាំទ្រប្រព័ន្ធសុខភាពជាតិផ្លូវការ) ប្រើស្តង់ដារជាមូលដ្ឋានបច្ចេកទេសសម្រាប់ស្លាកគុណភាពកម្មវិធីសាធារណៈរបស់ពួកគេ — មានន័យថាស្ថានភាព "បានបញ្ជាក់" ឬ "បានដាក់ស្លាក" របស់កម្មវិធីក្នុងការអនុវត្តតែងឆ្លុះបញ្ចាំងការអនុវត្តស្តង់ដាររបស់គម្រោងដាក់ស្លាកជាក់លាក់មួយ មិនចាំបាច់ជាដំណើរការដូចគ្នាឆ្លងគ្រប់គម្រោងទេ ដូច្នេះគួរពិនិត្យ និងបង្ហាញអង្គការវាយតម្លៃជាក់លាក់ និងវិធីសាស្ត្ររបស់វារួមជាមួយស្លាកគុណភាពណាមួយដែលបានដកស្រង់។ លក្ខណៈបច្ចេកទេសវាយតម្លៃលក្ខណៈគុណភាព និងសុវត្ថិភាពមូលដ្ឋានរបស់កម្មវិធីជាកម្មវិធី វាមិនមែនជាជំនួសការអនុញ្ញាតនិយតកម្មឧបករណ៍វេជ្ជសាស្ត្រ នៅកន្លែងដែលការអះអាង ឬមុខងាររបស់កម្មវិធីបំពេញកម្រិតឧបករណ៍វេជ្ជសាស្ត្រពិតប្រាកដនោះឡើយ ហើយការប្រើវាជំនួសនឹងជាកំហុសប្រភេទ (category error)។

## កំហុសដែលតែងកើតមាន

- **ចាត់ទុកស្លាកគុណភាពជាការអនុញ្ញាតនិយតកម្ម**៖ កម្មវិធីដែលបានវាយតម្លៃ និងដាក់ស្លាកក្រោម ISO/TS 82304-2 មិនមែនទទួលបានការអនុម័តនិយតកម្មឧបករណ៍វេជ្ជសាស្ត្រដោយសារនោះទេ ទាំងពីរបម្រើគោលបំណងខុសគ្នា ហើយមិនគួរត្រូវបានច្រឡំក្នុងរបៀបពិពណ៌នា ឬទីផ្សារកម្មវិធី។
- **សន្មតថាគម្រោងដាក់ស្លាកទាំងអស់ដែលផ្អែកលើស្តង់ដារស្មើគ្នា**៖ អង្គការខុសគ្នាអនុវត្តការវាយតម្លៃផ្អែកលើ ISO/TS 82304-2 ដោយមានដំណើរការពិនិត្យ និងភាពម៉ត់ចត់ជាក់លាក់ផ្ទាល់ខ្លួន ដូច្នេះគួរពិនិត្យថាអង្គការណាបានអនុវត្តការវាយតម្លៃ និងតាមរបៀបណា ជាជាងចាត់ទុកស្លាក "ផ្អែកលើ ISO/TS 82304-2" ណាមួយថាអាចផ្លាស់ប្តូរជាមួយស្លាកផ្សេង។
- **វាយតម្លៃតែភាពងាយប្រើ ខណៈធ្វេសប្រហែសសុវត្ថិភាព និងឯកជនភាព**៖ បញ្ហាភាពងាយប្រើគឺជាអ្វីដែលអ្នកប្រើចុងក្រោយមើលឃើញច្បាស់បំផុត និងងាយវាយតម្លៃមិនផ្លូវការបំផុត ដែលអាចនាំឱ្យអ្នកពិនិត្យផ្តល់ទម្ងន់តិចចំពោះដែនសុវត្ថិភាព និងឯកជនភាពដែលមើលឃើញតិចជាង ប៉ុន្តែអាចមានផលវិបាកធំជាង។
- **ចាត់ទុកការវាយតម្លៃជាការបញ្ជាក់ជាអចិន្ត្រៃយ៍តែមួយដង**៖ មាតិការបស់កម្មវិធី ការអនុវត្តសុវត្ថិភាព និងការរៀបចំចែករំលែកទិន្នន័យជាមួយភាគីទីបីអាចផ្លាស់ប្តូរទាំងអស់បន្ទាប់ពីការវាយតម្លៃដំបូង គម្រោងដាក់ស្លាកគុណភាពដែលអាចជឿជាក់បានវាយតម្លៃឡើងវិញតាមកាលកំណត់ ជាជាងចាត់ទុកការជាប់ដំបូងថាអចិន្ត្រៃយ៍។
