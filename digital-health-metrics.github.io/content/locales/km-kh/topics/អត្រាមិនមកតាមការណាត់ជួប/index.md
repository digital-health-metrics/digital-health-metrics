# អត្រាមិនមកតាមការណាត់ជួប

អត្រាមិនមកតាមការណាត់ជួប (appointment no-show rate ហៅម្យ៉ាងទៀតថា "did not attend" ឬអត្រា DNA) គឺជាសមាមាត្រនៃការណាត់ជួបដែលបានកំណត់ពេល ដែលអ្នកជំងឺមិនបានមកចូលរួម ហើយក៏មិនបានលុបចោលដោយជូនដំណឹងជាមុនគ្រប់គ្រាន់។ វាជារង្វាស់ប្រតិបត្តិការចំណាស់ជាងគេមួយក្នុងវិស័យថែទាំសុខភាព ហើយឧបករណ៍ឌីជីថល ជាពិសេសការរំលឹក ការកំណត់ពេលណាត់ជួបឡើងវិញដោយខ្លួនឯង និងការកក់តាមផតថល ឥឡូវនេះស្ថិតក្នុងចំណោមមធ្យោបាយមានប្រសិទ្ធភាពបំផុត និងមានភស្តុតាងច្បាស់បំផុតសម្រាប់កាត់បន្ថយអត្រានេះ។

## ហេតុអ្វីបានជាសំខាន់

ការមិនមកណាត់ជួបរាល់លើកគឺជាឯកតានៃសមត្ថភាពគ្លីនិកដែលជាធម្មតាមិនអាចយកមកវិញបាន ព្រោះសេវាភាគច្រើនមិនអាចបំពេញចន្លោះពេលក្នុងថ្ងៃតែមួយដោយមានការជូនដំណឹងខ្លីបានទេ។ ដូច្នេះអត្រានេះជះឥទ្ធិពលដោយផ្ទាល់ដល់ប្រវែងបញ្ជីរង់ចាំ ថ្លៃដើមក្នុងមួយការណាត់ជួបដែលបានបញ្ចប់ និងពេលវេលាគ្លីនិកករដែលបាត់បង់។ ឥរិយាបថមិនមកណាត់ជួបមិនបែងចែកស្មើគ្នាទេ៖ វាទាក់ទងនឹងភាពខ្វះខាត លទ្ធភាពធ្វើដំណើរ ទំនួលខុសត្រូវមើលថែអ្នកដទៃ និងបន្ទុកនៃការគ្រប់គ្រងជំងឺរ៉ាំរ៉ៃច្រើន។ ដូច្នេះ ការចាត់ទុកអត្រាខ្ពស់ថាជាបញ្ហាឥរិយាបថរបស់អ្នកជំងឺសុទ្ធសាធ ជាជាងជាសញ្ញាមួយផ្នែកអំពីឧបសគ្គក្នុងការទទួលបានសេវា តែងនាំឱ្យមានអន្តរាគមន៍ (ដូចជាការពិន័យទូទៅ) ដែលបង្កើនវិសមភាពជាជាងកាត់បន្ថយវា។ ការរំលឹកឌីជីថល និងការកំណត់ពេលណាត់ជួបឡើងវិញតាមឌីជីថលដោយងាយស្រួល គឺជាអន្តរាគមន៍ថ្លៃទាប ដែលមានប្រសិទ្ធភាពស្ថិតក្នុងចំណោមកំពូលជានិច្ច ហេតុនេះរង្វាស់នេះគួរស្ថិតក្នុងកម្មវិធីវាស់វែងសុខភាពឌីជីថលដោយផ្ទាល់ មិនមែនត្រឹមតែក្នុងរបាយការណ៍ប្រតិបត្តិការប៉ុណ្ណោះទេ។

## របៀបគណនា

```
អត្រាមិនមកណាត់ជួប = ការណាត់ជួបដែលសម្គាល់ថា "មិនមក" / ការណាត់ជួបដែលបានកំណត់ពេលសរុប × 100
```

ការណាត់ជួបដែលបានកំណត់ពេលជាធម្មតាត្រូវដកចេញពីភាគបែង ឬផ្លាស់ទៅប្រភេទដាច់ដោយឡែក ប្រសិនបើភាគីណាមួយបានលុបចោលមុនរយៈពេលជូនដំណឹងដែលបានកំណត់ (ជាទូទៅ ២៤ ម៉ោង)។ ការលុបចោលយឺត (ក្រោមរយៈពេលជូនដំណឹងនោះ) ជាធម្មតាត្រូវរាយការណ៍ដោយឡែកពីការមិនមកពិតប្រាកដ ព្រោះផលប៉ះពាល់ផ្នែកប្រតិបត្តិការ និងឥរិយាបថខុសគ្នា។

## ឧទាហរណ៍អនុវត្ត

គ្លីនិកសហគមន៍មួយកំណត់ពេលណាត់ជួប ២,០០០ ក្នុងមួយខែ។ ក្នុងនោះ ១៤០ ត្រូវបានលុបចោលដោយជូនដំណឹងលើសពី ២៤ ម៉ោង (កក់ឡើងវិញ និងដកចេញពីភាគបែង) ៦០ ត្រូវបានលុបចោលយឺត (ក្រោម ២៤ ម៉ោង) និង ១៨០ ត្រូវបានកត់ត្រាថាជាការមិនមកពិតប្រាកដ ដោយគ្មានការទាក់ទងអ្វីទាំងអស់។ អត្រាមិនមកណាត់ជួបគឺ 180 / 2,000 × 100 = 9%។ ប្រសិនបើការលុបចោលយឺតទាំង ៦០ ត្រូវបានបញ្ចូលក្នុងប្រភេទតែមួយជាមួយការមិនមកពិតប្រាកដ អត្រាដែលរាយការណ៍នឹងកើនដល់ 12% ដូច្នេះនិយមន័យដែលប្រើត្រូវតែបញ្ជាក់ជានិច្ចជាមួយតួលេខ។

## ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន

ប្រព័ន្ធកំណត់ពេលណាត់ជួប ឬប្រព័ន្ធគ្រប់គ្រងគ្លីនិកគឺជាប្រភពចម្បង ដោយប្រើកូដស្ថានភាពនៃការណាត់ជួបរបស់វា។ គុណភាពនៃរង្វាស់នេះអាស្រ័យទាំងស្រុងលើថាតើបុគ្គលិកប្រើស្ថានភាពត្រឹមត្រូវជាប់លាប់ ជាជាងប្រើប្រភេទ "លុបចោល" ទូទៅសម្រាប់គ្រប់យ៉ាង។ អង្គការដែលចាប់ផ្តើមប្រើការរំលឹកឌីជីថល (SMS សារជូនដំណឹងពីកម្មវិធី ឬការជូនដំណឹងតាមផតថល) គួរវាស់អត្រាមិនមកណាត់ជួបមុន និងក្រោយការផ្លាស់ប្តូរ សម្រាប់ក្រុមអ្នកជំងឺ និងប្រភេទសេវាដែលអាចប្រៀបធៀបបាន ព្រោះប្រសិទ្ធភាពនៃការរំលឹកមានឯកសារបញ្ជាក់ច្បាស់ក្នុងការសិក្សាចៃដន្យ និងការសិក្សាសង្កេត ប៉ុន្តែប្រែប្រួលតាមប្រជាជន និងបណ្តាញ។

## កំហុសដែលតែងកើតមាន

- **ប្រៀបធៀបអត្រាឆៅរវាងគ្លីនិកដែលមានការអនុវត្តកក់លើសចំនួនខុសគ្នា**៖ គ្លីនិកដែលកក់លើសចំនួនដោយចេតនាដើម្បីទូទាត់អត្រាមិនមកដែលរំពឹងទុក នឹងបង្ហាញអត្រាដែលមើលទៅខុសពីគ្លីនិកដែលមិនធ្វើបែបនោះ ដោយមិនទាក់ទងនឹងឥរិយាបថពិតរបស់អ្នកជំងឺ។
- **ច្រឡំការលុបចោលយឺតជាមួយការមិនមកពិតប្រាកដ**៖ ទាំងពីរមានមូលហេតុខុសគ្នា និងដំណោះស្រាយឌីជីថលខុសគ្នា (បញ្ហាលុបចោលយឺតតែងត្រូវបានដោះស្រាយដោយការកំណត់ពេលឡើងវិញដោយខ្លួនឯងងាយស្រួលជាង បញ្ហាមិនមកពិតប្រាកដតែងត្រូវបានដោះស្រាយដោយការរំលឹកប្រសើរជាង និងភាពត្រឹមត្រូវនៃព័ត៌មានទំនាក់ទំនង)។
- **លំអៀងអ្នករស់រានមានជីវិតពីគោលនយោបាយឈប់ព្យាបាល**៖ សេវាដែលឈប់ព្យាបាលអ្នកជំងឺបន្ទាប់ពីមិនមកច្រើនដង នឹងឃើញអត្រារបស់ខ្លួនប្រសើរឡើងដោយស្វ័យប្រវត្តិ ខណៈដែលគ្រាន់តែផ្លាស់ទីអ្នកជំងឺដដែលទៅកន្លែងផ្សេងក្នុងប្រព័ន្ធ។
- **ស្តីបន្ទោសអ្នកជំងឺចំពោះការមិនរួមបញ្ចូលឌីជីថល**៖ អ្នកជំងឺដែលគ្មានស្មាតហ្វូន ឬសេវាសារអត្ថបទអាចទុកចិត្តបាន នឹងមិនទទួលផលពីយុទ្ធសាស្ត្ររំលឹកឌីជីថលតែមួយប្រភេទទេ ដូច្នេះជាធម្មតាត្រូវការវិធីសាស្ត្រច្រើនបណ្តាញ (សំបុត្រ ទូរស័ព្ទ សារអត្ថបទ កម្មវិធី) ដើម្បីជៀសវាងការពង្រីកគម្លាតនៃការទទួលបានសេវា។
