# រង្វាស់សុខភាពឌីជីថល

សៀវភៅឯកសារយោងនៃនិយមន័យរង្វាស់សុខភាពឌីជីថល៖ រង្វាស់នីមួយៗមានន័យអ្វី របៀបគណនា ឧទាហរណ៍អនុវត្តជាក់ស្តែង ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន ព្រមទាំងកំហុសដែលតែងកើតមាន រៀបចំសម្រាប់អ្នកដែលកំពុងកសាង គ្រប់គ្រង និងវាយតម្លៃផលិតផល និងសេវាសុខភាពឌីជីថល។

ទើបតែចាប់ផ្តើម? សូមចាប់ផ្តើមជាមួយ [អត្រាទទួលយកផតថលអ្នកជំងឺ](topics/អត្រាទទួលយកផតថលអ្នកជំងឺ/) និង [អត្រាមិនមកតាមការណាត់ជួប](topics/អត្រាមិនមកតាមការណាត់ជួប/) ដែលជារង្វាស់ពីរដែលលេចឡើងស្ទើរតែគ្រប់ករណីសិក្សាអាជីវកម្មសុខភាពឌីជីថល។

## ការចូលរួមរបស់អ្នកជំងឺ និងការទទួលបានសេវា

- [អត្រាទទួលយកផតថលអ្នកជំងឺ](topics/អត្រាទទួលយកផតថលអ្នកជំងឺ/) — ការចុះឈ្មោះ ការធ្វើឱ្យសកម្ម និងការប្រើប្រាស់ជាក់ស្តែង ដែលជាអត្រាបីផ្សេងគ្នា ប៉ុន្តែតែងត្រូវបានច្រឡំជាលេខតែមួយ
- [អត្រាទស្សនកិច្ចសុខភាពពីចម្ងាយ](topics/អត្រាទស្សនកិច្ចសុខភាពពីចម្ងាយ/) — សមាមាត្រនៃការថែទាំដែលផ្តល់ពីចម្ងាយ និងមូលហេតុដែលមិនគួររាយការណ៍វីដេអូ និងទូរស័ព្ទជាលេខតែមួយ
- [អត្រាមិនមកតាមការណាត់ជួប](topics/អត្រាមិនមកតាមការណាត់ជួប/) — រង្វាស់ប្រតិបត្តិការចំណាស់ជាងគេក្នុងវិស័យថែទាំសុខភាព និងជាគោលដៅមួយដែលមានភស្តុតាងច្បាស់បំផុតសម្រាប់ការរំលឹកឌីជីថល
- [អត្រាភាពទៀងទាត់នៃការចូលរួមរបស់អ្នកជំងឺ](topics/អត្រាភាពទៀងទាត់នៃការចូលរួមរបស់អ្នកជំងឺ/) — ភាពទៀងទាត់ដែលអ្នកជំងឺធ្វើអន្តរកម្មជាមួយឧបករណ៍ឌីជីថលតាមពេលវេលា ខុសពីការគ្រាន់តែធ្លាប់ប្រើ
- [អត្រារក្សាអ្នកប្រើប្រាស់](topics/អត្រារក្សាអ្នកប្រើប្រាស់/) — ខ្សែកោងរក្សាតាមក្រុម (cohort) ដែលញែកផលិតផលមានលំនាំប្រើប្រាស់ស្ថិរភាព ចេញពីផលិតផលដែលគ្រាន់តែជិះលើរលកនៃភាពថ្មីថ្មោង
- [សមាមាត្រភាពស្អិតល្មម DAU/MAU](topics/សមាមាត្រភាពស្អិតល្មម-dau-mau/) — រង្វាស់វិភាគផលិតផលស្តង់ដារនៃកម្រិតនៃការចូលរួមទូទាំងមូលដ្ឋានអ្នកប្រើប្រាស់
- [ពិន្ទុអ្នកជំងឺណែនាំបន្ត (Net Promoter Score)](topics/ពិន្ទុអ្នកជំងឺណែនាំបន្ត/) — រង្វាស់ភាពពេញចិត្តដោយសំណួរតែមួយ ដែលប្រើយ៉ាងទូលាយ ហើយត្រូវបានរិះគន់យ៉ាងទូលាយផងដែរ
- [ពិន្ទុមាត្រដ្ឋានភាពងាយប្រើប្រព័ន្ធ (SUS)](topics/ពិន្ទុមាត្រដ្ឋានភាពងាយប្រើប្រព័ន្ធ/) — កម្រងសំណួរស្តង់ដារ ១០ ចំណុច ដែលវាស់បរិមាណថាកម្មវិធីមួយងាយប្រើប្រាស់កម្រិតណាពិតប្រាកដ

## ប្រតិបត្តិការថែទាំឌីជីថល និងសុវត្ថិភាព

- [អត្រាមិនអើពើការជូនដំណឹងគ្លីនិក](topics/អត្រាមិនអើពើការជូនដំណឹងគ្លីនិក/) — សញ្ញាស្តង់ដារនៃភាពនឿយហត់ពីការជូនដំណឹង (alert fatigue) ក្នុងប្រព័ន្ធគាំទ្រការសម្រេចចិត្តគ្លីនិក
- [រយៈពេលដោះស្រាយការបញ្ជូនបន្តឌីជីថល](topics/រយៈពេលដោះស្រាយការបញ្ជូនបន្តឌីជីថល/) — រង្វាស់ដំណើរការដែលបង្ហាញថាប្រព័ន្ធបញ្ជូនបន្តអេឡិចត្រូនិកសន្សំពេលវេលាពិតប្រាកដឬទេ
- [រយៈពេលដល់ការអន្តរាគមន៍](topics/រយៈពេលដល់ការអន្តរាគមន៍/) — ក្រុមគ្លីនិកឆ្លើយតបនឹងការជូនដំណឹងសុខភាពស្វ័យប្រវត្តិបានលឿនប៉ុនណា
- [ការកាត់បន្ថយចំនួនថ្ងៃគ្រែ](topics/ការកាត់បន្ថយចំនួនថ្ងៃគ្រែ/) — ចំនួនថ្ងៃគ្រែសម្រាកពេទ្យដែលសន្សំបានដោយផ្លាស់ប្តូរការព្យាបាលជាសះស្បើយទៅឱ្យមន្ទីរពេទ្យនិម្មិត ដែលតែងត្រូវរាយការណ៍ជាមួយរង្វាស់សុវត្ថិភាព

## លទ្ធផលគ្លីនិក និងគុណភាព

- [អត្រាភាពប្រសើរឡើងនៃសូចនាករជីវមាត្រ](topics/អត្រាភាពប្រសើរឡើងនៃសូចនាករជីវមាត្រ/) — សមាមាត្រអ្នកជំងឺដែលសម្រេចបានការផ្លាស់ប្តូរមានអត្ថន័យគ្លីនិកនៃសូចនាករជីវមាត្រដែលតាមដាន ដូចជា HbA1c ឬ BMI
- [អត្រាស្ថិរភាពនៃសូចនាករជីវមាត្រ](topics/អត្រាស្ថិរភាពនៃសូចនាករជីវមាត្រ/) — ការគ្រប់គ្រងបានប្រក្រតីក្នុងចន្លោះគោលដៅជាបន្តបន្ទាប់ ខុសពីភាពប្រសើរឡើងតែមួយដង
- [ភាពត្រឹមត្រូវនៃការចាត់ថ្នាក់និងបញ្ជូនអ្នកជំងឺ](topics/ភាពត្រឹមត្រូវនៃការចាត់ថ្នាក់និងបញ្ជូនអ្នកជំងឺ/) — ឧបករណ៍ចាត់ថ្នាក់អាទិភាព (triage) ដោយ AI ឬឌីជីថល បញ្ជូនអ្នកជំងឺទៅកម្រិតថែទាំត្រឹមត្រូវឬទេ
- [អត្រាអនុវត្តតាមការប្រើថ្នាំ](topics/អត្រាអនុវត្តតាមការប្រើថ្នាំ/) — សមាមាត្រនៃថ្ងៃដែលអ្នកជំងឺមានថ្នាំប្រើតាមវេជ្ជបញ្ជា
- [អត្រាចូលសម្រាកពេទ្យឡើងវិញ](topics/អត្រាចូលសម្រាកពេទ្យឡើងវិញ/) — រង្វាស់ដែលទាក់ទងដោយផ្ទាល់បំផុតនឹងសេដ្ឋកិច្ចអ្នកទូទាត់ និងកិច្ចសន្យាថែទាំផ្អែកលើតម្លៃ
- [អត្រាបំពេញ ePROM](topics/អត្រាបំពេញ-eprom/) — អត្រាបំពេញនៃរង្វាស់លទ្ធផលរាយការណ៍ដោយអ្នកជំងឺតាមអេឡិចត្រូនិក និងមូលហេតុដែលអត្រាធ្លាក់ចុះអាចជាសញ្ញាគ្លីនិកផ្ទាល់ខ្លួន
