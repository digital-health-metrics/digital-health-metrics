# ડિજિટલ હેલ્થ મેટ્રિક્સ

ડિજિટલ હેલ્થ મેટ્રિકની વ્યાખ્યાઓનું સંદર્ભ પુસ્તક: દરેક મેટ્રિકનો અર્થ શું છે, તેની ગણતરી કેવી રીતે કરવી, એક ઉદાહરણ, ડેટા સ્ત્રોતો અને મર્યાદાઓ, તથા સામાન્ય ભૂલો. ડિજિટલ હેલ્થ ઉત્પાદનો અને સેવાઓ બનાવનાર, ચલાવનાર અને તેનું મૂલ્યાંકન કરનાર લોકો માટે ગોઠવાયેલું.

અહીં નવા છો? [દર્દી પોર્ટલ અપનાવવાનો દર](topics/દર્દી-પોર્ટલ-અપનાવવાનો-દર/) અને [એપોઇન્ટમેન્ટ ન આવવાનો દર](topics/એપોઇન્ટમેન્ટ-ન-આવવાનો-દર/) થી શરૂ કરો — લગભગ દરેક ડિજિટલ હેલ્થ બિઝનેસ કેસમાં દેખાતાં બે મેટ્રિક.

## દર્દી જોડાણ અને પહોંચ

- [દર્દી પોર્ટલ અપનાવવાનો દર](topics/દર્દી-પોર્ટલ-અપનાવવાનો-દર/) — નોંધણી, સક્રિયકરણ અને સક્રિય ઉપયોગ; ત્રણ અલગ દર, જે ઘણી વાર એક તરીકે ભેળવી દેવાય છે
- [ટેલિહેલ્થ મુલાકાત દર](topics/ટેલિહેલ્થ-મુલાકાત-દર/) — દૂરથી અપાતી સંભાળનો હિસ્સો, અને વિડિયો તથા ટેલિફોનને એક આંકડા તરીકે કેમ ક્યારેય ન દર્શાવવા
- [એપોઇન્ટમેન્ટ ન આવવાનો દર](topics/એપોઇન્ટમેન્ટ-ન-આવવાનો-દર/) — આરોગ્યસંભાળનું સૌથી જૂનું સંચાલન મેટ્રિક, અને ડિજિટલ રિમાઇન્ડર માટેનું સૌથી સારી રીતે પુરવાર થયેલું લક્ષ્ય
- [દર્દી જોડાણ સાતત્ય દર](topics/દર્દી-જોડાણ-સાતત્ય-દર/) — દર્દી સમય જતાં ડિજિટલ સાધન સાથે કેટલી નિયમિતતાથી જોડાય છે, તેણે ક્યારેય ઉપયોગ કર્યો છે કે નહીં તેનાથી અલગ
- [વપરાશકર્તા રીટેન્શન દર](topics/વપરાશકર્તા-રીટેન્શન-દર/) — કોહોર્ટ રીટેન્શન વક્ર, જે ટકાઉ ઉપયોગની પેટર્ન ધરાવતા ઉત્પાદનને નવીનતાના મોજા પર સવાર ઉત્પાદનથી અલગ પાડે છે
- [DAU/MAU સ્ટિકીનેસ ગુણોત્તર](topics/dau-mau-સ્ટિકીનેસ-ગુણોત્તર/) — સમગ્ર વપરાશકર્તા આધારમાં જોડાણની તીવ્રતા માપવાનું પ્રમાણભૂત પ્રોડક્ટ-એનાલિટિક્સ માપ
- [દર્દી નેટ પ્રમોટર સ્કોર](topics/દર્દી-નેટ-પ્રમોટર-સ્કોર/) — વ્યાપકપણે વપરાતું, અને વ્યાપકપણે ટીકા પામેલું, એક-પ્રશ્નનું સંતોષ મેટ્રિક
- [સિસ્ટમ ઉપયોગિતા માપદંડ સ્કોર](topics/સિસ્ટમ-ઉપયોગિતા-માપદંડ-સ્કોર/) — 10 પ્રશ્નોની પ્રમાણિત પ્રશ્નાવલી, જે સોફ્ટવેર ખરેખર કેટલું ઉપયોગી છે તે માપે છે

- [ડિજિટલ રેફરલ પ્રક્રિયા સમય](topics/ડિજિટલ-રેફરલ-પ્રક્રિયા-સમય/) — ઇ-રેફરલ સિસ્ટમ ખરેખર સમય બચાવે છે કે નહીં તે બતાવતું પ્રક્રિયા મેટ્રિક
