# អត្រាទទួលយកផតថលអ្នកជំងឺ

អត្រាទទួលយកផតថលអ្នកជំងឺ (patient portal adoption rate) វាស់សមាមាត្រនៃអ្នកជំងឺមានសិទ្ធិ ដែលបានចុះឈ្មោះ និងប្រើប្រាស់ផតថលអ្នកជំងឺអនឡាញយ៉ាងសកម្ម (ឧទាហរណ៍ NHS App, Patient Access ឬផតថលភ្ជាប់នឹង EHR ដូចជា MyChart) ដើម្បីមើលកំណត់ត្រា កក់ការណាត់ជួប ឬផ្ញើសារទៅក្រុមថែទាំរបស់ខ្លួន។ វាជាសូចនាករកម្រិតចូលនៃការចូលរួមឌីជីថល៖ អ្នកជំងឺដែលមិនធ្លាប់ធ្វើឱ្យគណនីសកម្ម មិនអាចទទួលផលពីសេវាឌីជីថលណាមួយដែលបង្កើតលើផតថលបានទេ។

## ហេតុអ្វីបានជាសំខាន់

ផតថលបង្កើតតម្លៃតែនៅពេលអ្នកជំងឺប្រើវាប៉ុណ្ណោះ ដូច្នេះអង្គការគួរតាមដានការទទួលយកជាបណ្តាញចូល (funnel) ជាជាងលេខតែមួយ៖ ការចុះឈ្មោះ ការធ្វើឱ្យសកម្ម (សកម្មភាពដ៏មានន័យដំបូង) និងការប្រើប្រាស់សកម្ម (ការប្រើក្នុងចន្លោះពេលចុងក្រោយ) គឺជាអត្រាបីផ្សេងគ្នាដែលត្រូវបានច្រឡំគ្នាញឹកញាប់ពេក។ ក្រុមសេវាឌីជីថលតែងស្ថិតក្រោមសម្ពាធឱ្យរាយការណ៍តួលេខចំណងជើងតែមួយដែលមានលក្ខណៈអំណោយផល ហើយវាត្រូវការវិន័យដើម្បីទទូចឱ្យមានការបែងចែកដែលលំបាកជាង និងស្មោះត្រង់ជាង។ ការទទួលយកទាប ឬបែងចែកមិនស្មើក៏ជាសញ្ញាសមធម៌ផងដែរ៖ អ្នកជំងឺដែលមានវ័យចាស់ មានចំណេះដឹងឌីជីថលទាប មិននិយាយភាសាភាគច្រើន ឬខ្វះអ៊ីនធឺណិតល្បឿនលឿនដែលអាចទុកចិត្តបាន ឬស្មាតហ្វូន មានលទ្ធភាពតិចជាងគេក្នុងការត្រូវបានរាប់ក្នុងភាគយក ដូច្នេះអត្រាទទួលយកជាមធ្យមដែលកើនឡើងអាចបិទបាំងគម្លាតកាន់តែធំសម្រាប់អ្នកជំងឺដែលតែងត្រូវការទំនាក់ទំនងជាមួយសេវាច្រើនជាងគេ។

## របៀបគណនា

រាយការណ៍ទាំងបីដំណាក់កាល មិនមែនតែការចុះឈ្មោះប៉ុណ្ណោះ ហើយបញ្ជាក់ភាគបែងឱ្យច្បាស់ជានិច្ច៖

```
អត្រាចុះឈ្មោះ   = អ្នកជំងឺដែលបានបង្កើតគណនីផតថល / ចំនួនអ្នកជំងឺមានសិទ្ធិ × 100
អត្រាធ្វើឱ្យសកម្ម = អ្នកជំងឺដែលបានបញ្ចប់សកម្មភាពដ៏មានន័យដំបូង (មើលលទ្ធផល
                     កក់ពេល ផ្ញើសារ) / អ្នកជំងឺដែលមានគណនី × 100
អត្រាប្រើប្រាស់សកម្ម = អ្នកជំងឺដែលបានចូលប្រើយ៉ាងហោចណាស់មួយដងក្នុង ១២ ខែចុងក្រោយ /
                     ចំនួនអ្នកជំងឺមានសិទ្ធិ × 100
```

ចំនួនអ្នកជំងឺមានសិទ្ធិជាធម្មតាត្រូវបានកំណត់ជាអ្នកជំងឺដែលមានការជួបយ៉ាងហោចណាស់មួយជាមួយអង្គការក្នុងរយៈពេលមើលថយក្រោយដែលបានកំណត់ (ជាទូទៅ ២៤ ខែ) ដែលមានអាយុ និងស្ថានភាពយល់ព្រមអនុញ្ញាតឱ្យកាន់គណនីផ្ទាល់ខ្លួន។

## ឧទាហរណ៍អនុវត្ត

បណ្តាញថែទាំបឋមមួយបម្រើអ្នកជំងឺ ៥០,០០០ នាក់ដែលបំពេញនិយមន័យមានសិទ្ធិ។ ក្នុងចំណោមនោះ ៣២,០០០ បានចុះឈ្មោះផតថល (អត្រាចុះឈ្មោះ 64%)។ ក្នុងចំណោមអ្នកចុះឈ្មោះ ៣២,០០០ នាក់ ២៧,០០០ បានបញ្ចប់សកម្មភាពដ៏មានន័យយ៉ាងហោចណាស់មួយ ដូចជាការមើលលទ្ធផលតេស្ត (អត្រាធ្វើឱ្យសកម្ម 84% នៃអ្នកចុះឈ្មោះ)។ ក្នុង ១២ ខែចុងក្រោយ ២១,០០០ នាក់ក្នុងចំណោមអ្នកជំងឺមានសិទ្ធិដើម ៥០,០០០ នាក់ បានចូលប្រើយ៉ាងហោចណាស់មួយដង (អត្រាប្រើប្រាស់សកម្ម 42%)។ ការរាយការណ៍តែតួលេខចុះឈ្មោះ 64% នឹងបំផ្លើសការចូលរួមពិតប្រាកដយ៉ាងខ្លាំង ចំណែកតួលេខប្រើប្រាស់សកម្ម 42% គឺជាលេខដែលគួរជំរុញការសម្រេចចិត្តផ្នែកធនធានសម្រាប់កម្មវិធីផតថល។

## ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន

ទិន្នន័យវិភាគផតថលជាធម្មតាមកពីវេទិកាអ្នកផ្គត់ផ្គង់ផ្ទាល់ (ព្រឹត្តិការណ៍ចូលប្រើ ការប្រើមុខងារ) ឬពីកំណត់ហេតុសវនកម្មរបស់កំណត់ត្រាសុខភាពអេឡិចត្រូនិកមូលដ្ឋាន ហើយអង្គការគួរមានការសង្ស័យចំពោះផ្ទាំងគ្រប់គ្រងរបស់អ្នកផ្គត់ផ្គង់ដែលបង្ហាញតែចំនួនចុះឈ្មោះ។ ការចូលប្រើតាមតំណាង (ឪពុកម្តាយ ឬអ្នកមើលថែគ្រប់គ្រងគណនីជំនួសអ្នកជំងឺ) គួរត្រូវបានដាក់ស្លាក និងរាយការណ៍ដោយឡែក ព្រោះវាផ្លាស់ប្តូរថាអ្នកណាជា "អ្នកប្រើប្រាស់" ពិតប្រាកដ។ ជម្រើសភាគបែងសំខាន់ខ្លាំង៖ ការរាប់ធៀបនឹងបញ្ជីអ្នកជំងឺដែលបានចុះឈ្មោះសរុប ជាជាងប្រជាជនមានសិទ្ធិ និងអាចទាក់ទងបានពិតប្រាកដ នឹងតែងតែបង្ហាញការទទួលយកទាបជាងការពិត ចំណែកការរាប់ធៀបនឹងអ្នកជំងឺដែលត្រូវបានអញ្ជើញយ៉ាងសកម្មតែប៉ុណ្ណោះ នឹងតែងតែបំផ្លើស ដូច្នេះនិយមន័យមានសិទ្ធិគួរត្រូវបានកំណត់ និងផ្សព្វផ្សាយជាមួយរាល់អត្រាដែលរាយការណ៍។

## កំហុសដែលតែងកើតមាន

- **រាប់ការចុះឈ្មោះជាការទទួលយក**៖ គណនីដែលបានបង្កើតតែមិនដែលប្រើ មានតម្លៃជិតសូន្យ ដូច្នេះគួររាយការណ៍ការធ្វើឱ្យសកម្ម និងការប្រើប្រាស់សកម្មរួមជាមួយការចុះឈ្មោះ មិនមែនជំនួសវាទេ។
- **មិនអើពើការមិនរួមបញ្ចូលឌីជីថល**៖ តួលេខការទទួលយករួមអាចកើនឡើង ខណៈដែលគម្លាតរវាងក្រុមដែលរួមបញ្ចូលឌីជីថលច្រើនជាងគេ និងតិចជាងគេកាន់តែធំ ដូច្នេះគួរបែងចែកតាមអាយុ ភាពខ្វះខាត ភាសា និងពិការភាពជានិច្ច ប្រសិនបើអភិបាលកិច្ចទិន្នន័យអនុញ្ញាត។
- **ប្រៀបធៀបអង្គការដែលមាននិយមន័យមានសិទ្ធិខុសគ្នា**៖ កម្មវិធីផតថលដែលអញ្ជើញតែអ្នកជំងឺដែលមានអាសយដ្ឋានអ៊ីមែលកត់ត្រា នឹងរាយការណ៍អត្រាខ្ពស់ជាងកម្មវិធីដែលវាស់ធៀបនឹងបញ្ជីដែលបានចុះឈ្មោះទាំងមូល ដោយគ្មានភាពខុសគ្នាពិតប្រាកដនៃសមត្ថភាព។
- **ចាត់ទុកការចូលប្រើតែមួយដងជាការចូលរួមបន្ត**៖ ការមើលថយក្រោយ ១២ ខែគឺជារឿងធម្មតា ប៉ុន្តែបង្អួចខ្លីជាង (ឧទាហរណ៍ ៩០ ថ្ងៃ) ផ្តល់ការព្រមានដំបូងជាងអំពីការប្រើប្រាស់ដែលធ្លាក់ចុះ។
