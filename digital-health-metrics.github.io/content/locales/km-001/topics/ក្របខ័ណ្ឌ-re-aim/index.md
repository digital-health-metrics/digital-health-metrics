# ក្របខ័ណ្ឌ RE-AIM

RE-AIM គឺជាក្របខ័ណ្ឌវាយតម្លៃសុខភាពសាធារណៈ ដែលវាយតម្លៃអន្តរាគមន៍សុខភាពឌីជីថលតាមវិមាត្រប្រាំផ្សេងគ្នា — Reach (ការទៅដល់) Effectiveness (ប្រសិទ្ធភាព) Adoption (ការទទួលយក) Implementation (ការអនុវត្ត) និង Maintenance (ការរក្សា) — ជាជាងតាមរង្វាស់តែមួយ។ វាមានដើម្បីកែតម្រូវទម្រង់បរាជ័យទូទៅ និងជាក់លាក់ក្នុងការវាយតម្លៃសុខភាពឌីជីថល៖ កម្មវិធីដែលរាយការណ៍ទិន្នន័យប្រសិទ្ធភាពគួរឱ្យចាប់អារម្មណ៍ពីប្រជាជនសាកល្បងតូចដែលមានការលើកទឹកចិត្ត ខណៈមិនដែលត្រូវបានទទួលយកកម្រិតធំ ឬមិនដែលត្រូវបានរក្សាហួសរយៈពេលសាកល្បងដែលមានមូលនិធិ មិនបានបង្ហាញតម្លៃសុខភាពសាធារណៈពិតប្រាកដទេ ទោះតួលេខលទ្ធផលចំណងជើងរបស់វាមើលទៅល្អដោយឡែកប៉ុនណា។

## ហេតុអ្វីបានជាសំខាន់

ការសាកល្បងសុខភាពឌីជីថលតែងត្រូវបានវាយតម្លៃលើប្រសិទ្ធភាពតែប៉ុណ្ណោះ — តើរង្វាស់លទ្ធផលប្រសើរឡើងសម្រាប់អ្នកដែលបានប្រើវាឬអត់ — ខណៈទុកវិមាត្រផ្សេងទៀតទាំងបួនមិនបានវាស់ ឬមិនបានរាយការណ៍ ដែលបង្កលំអៀងជាប្រព័ន្ធដល់មូលដ្ឋានភស្តុតាងឆ្ពោះទៅរកអន្តរាគមន៍ដែលដំណើរការល្អក្នុងលក្ខខណ្ឌឧត្តមគតិ កម្រិតតូច ប៉ុន្តែមិនប្រាប់អ្វីអំពីថាតើវាដំណើរការកម្រិតធំ ទៅដល់ប្រជាជនដែលត្រូវការវាច្រើនបំផុត ឬនៅរស់រានហួសមូលនិធិដំបូង និងភាពរំភើបដំបូងរបស់វាឬអត់។ RE-AIM ត្រូវបានបង្កើតជាពិសេសដើម្បីបង្ខំអ្នកវាយតម្លៃឱ្យរាយការណ៍អំពីសុពលភាពខាងក្រៅ (តើនេះនឹងដំណើរការកន្លែងផ្សេងឬអត់ សម្រាប់អ្នកណា) រួមជាមួយសុពលភាពខាងក្នុង (តើនេះបានដំណើរការនៅទីនេះឬអត់) ដែលសំខាន់ខ្លាំងសម្រាប់អ្នកណាដែលកំពុងសម្រេចចិត្តថាតើត្រូវផ្តល់មូលនិធិ បញ្ជាទិញ ឬពង្រីកអន្តរាគមន៍សុខភាពឌីជីថលដោយផ្អែកលើលទ្ធផលនៃការសិក្សា ឬការសាកល្បងតែមួយ។ ដោយសារវិមាត្រទាំងប្រាំអាចវាស់បានទាំងកម្រិតបុគ្គល និងកម្រិតអង្គការ ឬបរិបទ RE-AIM ក៏លាតត្រដាងការដោះដូរ — ឧទាហរណ៍ អន្តរាគមន៍ដែលមានប្រសិទ្ធភាពខ្ពស់ដែលផ្តល់ដោយបុគ្គលិកដែលជ្រើសរើសខ្ពស់ និងបណ្តុះបណ្តាលខ្ពស់ (ប្រសិទ្ធភាពខ្លាំង ភាពតំណាងនៃការទទួលយកខ្សោយ) — ដែលរង្វាស់រួមតែមួយនឹងលាក់ទាំងស្រុង។

## របៀបអនុវត្ត

```
Reach (ការទៅដល់)          = សមាមាត្រនៃប្រជាជនគោលដៅមានសិទ្ធិដែលចូលរួម
                              និងថាតើអ្នកចូលរួមតំណាងប្រជាជនមានសិទ្ធិនោះកម្រិតណា
                              (មិនត្រឹមចំនួនអ្នកចូលរួមឆៅ)

Effectiveness (ប្រសិទ្ធភាព) = ផលប៉ះពាល់លើលទ្ធផលចម្បង រួមទាំងគុណភាពជីវិត
                              និងផលវិបាកអវិជ្ជមានដែលមិនបានបំណង មិនត្រឹមតែ
                              រង្វាស់លទ្ធផលចំណងជើងតែមួយ

Adoption (ការទទួលយក)      = សមាមាត្រ និងភាពតំណាងនៃបរិបទ និងបុគ្គលិក/
                              អ្នកផ្តល់ដែលទទួលយកអន្តរាគមន៍
                              ធៀបនឹងបរិបទ និងបុគ្គលិកមានសិទ្ធិទាំងអស់

Implementation (ការអនុវត្ត) = ភាពជាប់លាប់ និងភាពស្មោះត្រង់នៃការផ្តល់ដូចបំណង
                              ពេលវេលា និងថ្លៃដើមដែលត្រូវការដើម្បីផ្តល់វា
                              និងការកែសម្រួលដែលបានធ្វើតាមផ្លូវ

Maintenance (ការរក្សា)     = កម្រិតដែលអន្តរាគមន៍ក្លាយជាផ្នែកនៃការអនុវត្តជាប្រចាំ
                              រយៈពេលវែង ទាំងកម្រិតបុគ្គល (ឥទ្ធិពលកម្រិតបុគ្គល
                              ដែលស្ថិរភាព) និងកម្រិតបរិបទ/អង្គការ
                              (ការធ្វើជាស្ថាប័ន)
```

## ឧទាហរណ៍អនុវត្ត

កម្មវិធីការពារជំងឺទឹកនោមផ្អែមឌីជីថលមួយត្រូវបានសាកល្បងឆ្លងគ្លីនិកថែទាំបឋម ២០ ក្នុងតំបន់មួយដែលមានគ្លីនិកមានសិទ្ធិសរុប ២០០។ Reach ត្រូវបានវាយតម្លៃថាអ្នកជំងឺ ១,២០០ នាក់ក្នុងចំណោមអ្នកជំងឺមានសិទ្ធិប៉ាន់ស្មាន ១៥,០០០ នាក់ឆ្លងគ្លីនិកសាកល្បង ២០ (8%) ដោយរកឃើញថាអ្នកចូលរួមក្មេងជាង និងមានចំណេះដឹងឌីជីថលខ្ពស់ជាងប្រជាជនមានសិទ្ធិទាំងមូលបន្តិច — គម្លាតភាពតំណាងដែលគួរកត់សម្គាល់ ជាជាងមិនអើពើ។ Effectiveness បង្ហាញការថយចុះមានអត្ថន័យគ្លីនិកនៃ HbA1c មធ្យមក្នុងចំណោមអ្នកបញ្ចប់ ប៉ុន្តែអត្រាបោះបង់ខ្ពស់មានន័យថាឥទ្ធិពលនេះត្រូវបានរំលាយនៅពេលវាយតម្លៃលើមូលដ្ឋាន intention-to-treat ឆ្លងអ្នកជំងឺដែលបានចុះឈ្មោះទាំងអស់ មិនត្រឹមអ្នកបញ្ចប់។ Adoption គឺ ២០ ក្នុងចំណោមគ្លីនិកមានសិទ្ធិ ២០០ (10%) ប្រមូលផ្តុំក្នុងគ្លីនិកដែលមានហេដ្ឋារចនាសម្ព័ន្ធឌីជីថលខ្ពស់ជាងមធ្យមស្រាប់ — ម្តងទៀត ជាកង្វល់ភាពតំណាង។ ការវាយតម្លៃភាពស្មោះត្រង់នៃ Implementation រកឃើញថាគ្លីនិកភាគច្រើនបានផ្តល់កម្មវិធីតាមការរចនាភាគច្រើន ទោះបីគ្លីនិកពីរបានកាត់ខ្លីដំណើរការណែនាំចូលរួមយ៉ាងខ្លាំងក្រោមសម្ពាធពេលវេលា។ ការវាយតម្លៃ Maintenance មួយឆ្នាំបន្ទាប់ពីមូលនិធិសាកល្បងបានបញ្ចប់ រកឃើញថាមានតែ ៦ ក្នុងចំណោមគ្លីនិកដើម ២០ នៅដំណើរការកម្មវិធីយ៉ាងសកម្ម — លទ្ធផលដែលនៅពេលរាយការណ៍រួមជាមួយតួលេខប្រសិទ្ធភាពដែលមានសង្ឃឹមដំបូង ផ្តល់រូបភាពពេញលេញ និងស្មោះត្រង់ជាងអំពីអនាគតក្នុងពិភពពិតរបស់កម្មវិធី ជាងទិន្នន័យប្រសិទ្ធភាពតែឯង។

## ប្រភពទិន្នន័យ និងចំណុចត្រូវប្រុងប្រយ័ត្ន

វិមាត្រ RE-AIM នីមួយៗជាធម្មតាទាញពីប្រភពទិន្នន័យខុសគ្នា៖ Reach និង Adoption ពីកំណត់ត្រាចុះឈ្មោះ និងសិទ្ធិ Effectiveness ពីទិន្នន័យគ្លីនិក ឬលទ្ធផល (តែងជាទិន្នន័យដដែលដែលបានប្រើគណនារង្វាស់ជាក់លាក់កន្លែងផ្សេងក្នុងសៀវភៅនេះ ដូចជាអត្រាភាពប្រសើរឡើងនៃសូចនាករជីវមាត្រ) Implementation ពីបញ្ជីត្រួតពិនិត្យភាពស្មោះត្រង់ កំណត់ហេតុការផ្តល់ ឬការសង្កេតដោយផ្ទាល់ និង Maintenance ពីការវាយតម្លៃតាមដានដែលធ្វើឡើងយូរបន្ទាប់ពីរយៈពេលវាយតម្លៃដំបូង — មានន័យថាការវាយតម្លៃ RE-AIM ពេញលេញមិនអាចបញ្ចប់នៅចំណុចតែមួយក្នុងពេលវេលាទេ ហើយតម្រូវឱ្យមានការធ្វើផែនការវាយតម្លៃតាំងពីដំបូង មិនមែនបន្ថែមបែបថយក្រោយ។ ដោយសារការរាយការណ៍វិមាត្រទាំងប្រាំដោយស្មោះត្រង់ (រួមទាំងលទ្ធផលខ្សោយលើវិមាត្រខ្លះ) ជាការងារច្រើនជាង និងមិនសូវអំណោយផលជាងការរាយការណ៍តែប្រសិទ្ធភាព ការវាយតម្លៃសុខភាពឌីជីថលដែលបានបោះពុម្ពរាយការណ៍តិចជាង Reach, Adoption និង Maintenance ធៀបនឹង Effectiveness ជាសមាមាត្រ — ជាលំនាំលំអៀងបោះពុម្ពដែលគេស្គាល់ ដែលអ្នកណាប្រើភស្តុតាងដែលដាក់ស្លាក RE-AIM ដើម្បីជូនដំណឹងដល់ការសម្រេចចិត្ត គួរតែប្រុងប្រយ័ត្ន។

## កំហុសដែលតែងកើតមាន

- **រាយការណ៍ប្រសិទ្ធភាពតែប៉ុណ្ណោះ ហើយហៅថាជាការវាយតម្លៃ RE-AIM**៖ ការប្រើឈ្មោះ RE-AIM ខណៈរាយការណ៍តែមួយក្នុងចំណោមវិមាត្រទាំងប្រាំ បំផ្លាញគោលបំណងរបស់ក្របខ័ណ្ឌ ហើយមិនគួរត្រូវបានពិពណ៌នាថាជាការវាយតម្លៃ RE-AIM ឡើយ។
- **វាស់ Reach និង Adoption ជាចំនួនឆៅ ជាជាងសមាមាត្រនៃប្រជាជនមានសិទ្ធិ**៖ ចំនួនអ្នកចូលរួមឆៅធំអាចនៅតែតំណាងចំណែកតូច និងមិនតំណាងនៃអ្នកដែលអន្តរាគមន៍គួរទៅដល់ដោយឧត្តមគតិ ដូច្នេះគួរគណនាធៀបនឹងភាគបែងមានសិទ្ធិពេញលេញជានិច្ច។
- **វាយតម្លៃ Maintenance ឆាប់ពេក**៖ ការធ្វើជាស្ថាប័ន និងឥទ្ធិពលស្ថិរភាពអាចវិនិច្ឆ័យបានតែយូរបន្ទាប់ពីមូលនិធិដំបូង ឬឥទ្ធិពលភាពថ្មីថ្មោងរសាត់ ការវាយតម្លៃដែលធ្វើភ្លាមៗក្រោយការសាកល្បងបញ្ចប់មិនអាចនិយាយអំពី Maintenance បានឡើយ ទោះវិមាត្របួនផ្សេងទៀតមើលទៅបែបណាក៏ដោយ។
- **ចាត់ទុកវិមាត្រទាំងប្រាំថាមានទម្ងន់ស្មើគ្នា ឬអាចបូករួមជាពិន្ទុតែមួយ**៖ RE-AIM ដោយចេតនាគឺជាទម្រង់ច្រើនវិមាត្រ មិនមែនជាលេខតែមួយទេ ការរួមបញ្ចូលវិមាត្រទៅជាពិន្ទុផ្សំតែមួយ បោះបង់ភាពមើលឃើញនៃការដោះដូរដែលក្របខ័ណ្ឌត្រូវបានរចនាដើម្បីរក្សា។
