# ອັດຕາການປັບປຸງຕົວຊີ້ວັດຊີວະພາບ

ອັດຕາການປັບປຸງຕົວຊີ້ວັດຊີວະພາບ ແມ່ນສັດສ່ວນຂອງຄົນເຈັບທີ່ລົງທະບຽນໃນໂຄງການສຸຂະພາບດິຈິຕອນ ແລະ ບັນລຸການປັບປຸງທີ່ມີນັຍສຳຄັນທາງຄລີນິກໃນຕົວຊີ້ວັດຊີວະພາບທີ່ຕິດຕາມ — ສ່ວນຫຼາຍແມ່ນຮີໂມໂກລບິນທີ່ມີນ້ຳຕານຈັບ (HbA1c) ໃນໂຄງການພະຍາດເບົາຫວານ ແລະ ພະຍາດທາງເມຕາບໍລິກຫົວໃຈ ຫຼື ດັດຊະນີມວນກາຍ (BMI) ໃນໂຄງການຄວບຄຸມນ້ຳໜັກ — ໃນໄລຍະການລົງທະບຽນທີ່ກຳນົດໄວ້. ມັນເປັນຕົວຊີ້ວັດຜົນໄດ້ຮັບທີ່ສຸດທ້າຍຮອງຮັບຄຳອ້າງທາງຄລີນິກຂອງຜະລິດຕະພັນສຸຂະພາບດິຈິຕອນ: ຕົວເລກການມີສ່ວນຮ່ວມ ແລະ ການນຳໃຊ້ອະທິບາຍວ່າຜະລິດຕະພັນຖືກໃຊ້ແນວໃດ ແຕ່ການປັບປຸງຕົວຊີ້ວັດຊີວະພາບໃກ້ຄຽງກັບຫຼັກຖານວ່າມັນໄດ້ຜົນ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ໂຄງການສຸຂະພາບດິຈິຕອນມັກຖືກຂາຍ ແລະ ຈັດຊື້ຈັດຈ້າງດ້ວຍຄຳສັນຍາວ່າຈະປັບປຸງຜົນໄດ້ຮັບດ້ານສຸຂະພາບ ແລະ ອັດຕາການປັບປຸງຕົວຊີ້ວັດຊີວະພາບແມ່ນວິທີທີ່ກົງທີ່ສຸດ ແລະ ວັດແທກໄດ້ເພື່ອທົດສອບຄຳສັນຍານັ້ນຕໍ່ເກນທີ່ຍອມຮັບທາງຄລີນິກສະເພາະ ແທນທີ່ຈະເປັນຄຳອ້າງກວ້າງໆກ່ຽວກັບ "ສຸຂະພາບທີ່ດີຂຶ້ນ". ຜູ້ຈ່າຍເງິນ, ນາຍຈ້າງ ແລະ ລະບົບສຸຂະພາບນັບມື້ນັບຜູກການຈ່າຍຄືນ ຫຼື ການຕໍ່ສັນຍາກັບການປ່ຽນແປງຂອງຕົວຊີ້ວັດຊີວະພາບທີ່ພິສູດໄດ້ ດັ່ງນັ້ນໂຄງການທີ່ບໍ່ສາມາດລາຍງານອັດຕານີ້ຢ່າງໜ້າເຊື່ອຖືຈະເສຍປຽບທັງທາງການຄ້າ ແລະ ທາງຄລີນິກ. ຕົວຊີ້ວັດນີ້ຍັງເປັນການກວດສອບວິໄນຂອງການອອກແບບໂຄງການ: ການລາຍງານການມີສ່ວນຮ່ວມ (ການເຂົ້າສູ່ລະບົບ, ຂໍ້ຄວາມທີ່ສົ່ງ) ງ່າຍກວ່າການລາຍງານຜົນໄດ້ຮັບຫຼາຍ ແລະ ທີມງານຄວນສົງໄສໂຄງການໃດກໍຕາມທີ່ລາຍງານອັນແລກຢ່າງກະຕືລືລົ້ນ ແຕ່ຄຸມເຄືອກ່ຽວກັບອັນຫຼັງ.

## ວິທີຄຳນວນ

```
ອັດຕາການປັບປຸງຕົວຊີ້ວັດຊີວະພາບ = ຄົນເຈັບທີ່ບັນລຸການປັບປຸງທີ່ມີນັຍສຳຄັນ
                                   ທາງຄລີນິກທີ່ກຳນົດໄວ້ / ຄົນເຈັບທີ່ມີ
                                   ການວັດແທກພື້ນຖານ ແລະ ການຕິດຕາມທີ່ຖືກຕ້ອງ × 100

ເກນທີ່ມີນັຍສຳຄັນທາງຄລີນິກທີ່ນິຍົມໃຊ້:
  HbA1c   — ຫຼຸດລົງ ≥ 0.5 ຈຸດເປີເຊັນ, ຫຼື ບັນລຸເປົ້າໝາຍທີ່ກຳນົດ
            (ເຊັ່ນ < 7.0%) ຈາກຄ່າພື້ນຖານທີ່ຢູ່ນອກຊ່ວງ
  BMI     — ຫຼຸດນ້ຳໜັກຕົວ ≥ 5% ຂອງນ້ຳໜັກພື້ນຖານ ແລະ ຄົງໄວ້ຈົນເຖິງ
            ຈຸດວັດແທກຕິດຕາມ

ລາຍງານແຍກຕາມແຕ່ລະຕົວຊີ້ວັດຊີວະພາບທີ່ຕິດຕາມ; ຢ່າລວມການປັບປຸງ HbA1c ແລະ
BMI ເຂົ້າເປັນເປີເຊັນ "ການປັບປຸງ" ລວມດຽວ.
```

## ຕົວຢ່າງການຄຳນວນ

ໂຄງການສຸຂະພາບດິຈິຕອນດ້ານພະຍາດທາງເມຕາບໍລິກຫົວໃຈລົງທະບຽນຄົນເຈັບ 800 ຄົນທີ່ມີ HbA1c ພື້ນຖານຢູ່ນອກຊ່ວງ. ໃນຈຳນວນນີ້, 620 ຄົນມີທັງຄ່າພື້ນຖານທີ່ຖືກຕ້ອງ ແລະ ການວັດຕິດຕາມທີ່ 6 ເດືອນ (180 ຄົນຂາດການຕິດຕາມ ແລະ ຖືກຕັດອອກຈາກຕົວຫານ ບໍ່ໄດ້ນັບເປັນຄວາມລົ້ມເຫຼວ). ໃນ 620 ຄົນທີ່ມີການວັດຄູ່, 340 ຄົນບັນລຸການຫຼຸດລົງຢ່າງໜ້ອຍ 0.5 ຈຸດເປີເຊັນ. ອັດຕາການປັບປຸງຕົວຊີ້ວັດຊີວະພາບແມ່ນ 340 / 620 × 100 = 55%. ການລາຍງານເມື່ອປຽບທຽບກັບທັງໝົດ 800 ຄົນທີ່ລົງທະບຽນ (340 / 800 = 42.5%) ຈະປົນການຂາດການຕິດຕາມເຂົ້າກັບຄວາມລົ້ມເຫຼວຂອງການປິ່ນປົວ ເຮັດໃຫ້ອັດຕາຕ່ຳກວ່າຈິງສຳລັບຄົນເຈັບທີ່ໄດ້ວັດແທກສຳເລັດຈິງ.

## ແຫຼ່ງຂໍ້ມູນ ແລະ ຂໍ້ຄວນລະວັງ

ຄ່າພື້ນຖານ ແລະ ຄ່າຕິດຕາມຂອງຕົວຊີ້ວັດຊີວະພາບໂດຍທົ່ວໄປມາຈາກອຸປະກອນເຊື່ອມຕໍ່ (ເຄື່ອງວັດນ້ຳຕານ Bluetooth ຫຼື ເຄື່ອງຊັ່ງນ້ຳໜັກອັດສະລິຍະ), ຜົນຫ້ອງທົດລອງທີ່ນຳເຂົ້າຈາກບັນທຶກສຸຂະພາບເອເລັກໂຕຣນິກ ຫຼື ຄ່າທີ່ຄົນເຈັບລາຍງານເອງ — ແລະ ທັງສາມແຫຼ່ງນີ້ມີຄວາມໜ້າເຊື່ອຖືແຕກຕ່າງກັນຫຼາຍ ດັ່ງນັ້ນຄວນລາຍງານແຫຼ່ງຂໍ້ມູນຄຽງຄູ່ກັບອັດຕາ. ການຂາດການຕິດຕາມບໍ່ຄ່ອຍເປັນແບບສຸ່ມ: ຄົນເຈັບທີ່ເຊົາມີສ່ວນຮ່ວມໃນໂຄງການມັກເປັນຄົນທີ່ມີໂອກາດປັບປຸງໜ້ອຍທີ່ສຸດ ດັ່ງນັ້ນອັດຕາການປັບປຸງສູງທີ່ຄຳນວນສະເພາະຄົນເຈັບທີ່ສຳເລັດການຕິດຕາມ ອາດຈະສູງເກີນຜົນກະທົບທີ່ແທ້ຈິງໃນລະດັບປະຊາກອນຂອງໂຄງການ. ຜົນກະທົບຕາມລະດູການ ແລະ ການຖົດຖອຍສູ່ຄ່າສະເລ່ຍມີຈິງທັງ HbA1c ແລະ ນ້ຳໜັກ ດັ່ງນັ້ນໂຄງການຄວນປຽບທຽບກັບກຸ່ມຄວບຄຸມໃນເວລາດຽວກັນ ຫຼື ໃນອະດີດເມື່ອເປັນໄປໄດ້ ແທນທີ່ຈະຖືວ່າການປັບປຸງໃດໆເປັນຫຼັກຖານຂອງຜົນຈາກໂຄງການ.

## ຈຸດອ່ອນທີ່ຄວນລະວັງ

- **ການຕັດ ແທນທີ່ຈະລາຍງານ ການຂາດການຕິດຕາມ**: ການຕັດຄົນເຈັບທີ່ບໍ່ມີການວັດຕິດຕາມອອກຈາກຕົວຫານຢ່າງງຽບໆ ສາມາດເຮັດໃຫ້ອັດຕາການປັບປຸງທີ່ປາກົດສູງຂຶ້ນຢ່າງຫຼວງຫຼາຍ; ຄວນລາຍງານອັດຕາການສຳເລັດການວັດຕິດຕາມຄຽງຄູ່ກັບອັດຕາການປັບປຸງເອງສະເໝີ.
- **ການປົນຄ່າທີ່ລາຍງານເອງ ແລະ ຄ່າຈາກອຸປະກອນໂດຍບໍ່ໃສ່ປ້າຍ**: ນ້ຳໜັກທີ່ລາຍງານເອງມີຄວາມໜ້າເຊື່ອຖືຕ່ຳກວ່າຄ່າຈາກເຄື່ອງຊັ່ງອັດສະລິຍະທີ່ເຊື່ອມຕໍ່ຢ່າງເປັນລະບົບ ແລະ ການປົນສອງແຫຼ່ງເຮັດໃຫ້ບໍ່ເຫັນວ່າການປັບປຸງທີ່ປາກົດມີຫຼາຍປານໃດເປັນສິ່ງລົບກວນຂອງການວັດ.
- **ບໍ່ມີກຸ່ມຄວບຄຸມ ຫຼື ສະຖານະການປຽບທຽບ (counterfactual)**: ຕົວຊີ້ວັດຊີວະພາບຊຳເຮື້ອຫຼາຍຢ່າງຜັນແປ ຫຼື ຖົດຖອຍສູ່ຄ່າສະເລ່ຍເອງ; ອັດຕາການປັບປຸງແບບກຸ່ມດຽວທີ່ບໍ່ມີກຸ່ມປຽບທຽບເປັນຫຼັກຖານທີ່ຊີ້ໃຫ້ເຫັນ ແຕ່ບໍ່ແມ່ນຂໍ້ສະຫຼຸບກ່ຽວກັບຜົນຂອງໂຄງການ.
- **ການຖືວ່າການປ່ຽນແປງສະເລ່ຍເລັກນ້ອຍເປັນຫຼັກຖານຂອງການປັບປຸງກວ້າງຂວາງ**: ການປັບປຸງສະເລ່ຍເລັກນ້ອຍໃນລະດັບປະຊາກອນອາດຖືກຂັບເຄື່ອນໂດຍຜູ້ຕອບສະໜອງຢ່າງແຮງບໍ່ກີ່ຄົນ ໃນຂະນະທີ່ຄົນເຈັບສ່ວນໃຫຍ່ບໍ່ປ່ຽນແປງ; ຄວນລາຍງານການແຈກຢາຍ (ເຊັ່ນ ສັດສ່ວນທີ່ຂ້າມເກນທີ່ມີນັຍສຳຄັນທາງຄລີນິກ) ບໍ່ແມ່ນພຽງການປ່ຽນແປງສະເລ່ຍ.
