# ເວລາດຳເນີນການສົ່ງຕໍ່ດິຈິຕອນ

ເວລາດຳເນີນການສົ່ງຕໍ່ດິຈິຕອນ (digital referral turnaround time) ແມ່ນເວລາທີ່ຜ່ານໄປ ນັບແຕ່ການສົ່ງຕໍ່ເອເລັກໂຕຣນິກຖືກສົ່ງໂດຍແພດຜູ້ສົ່ງຕໍ່ ຈົນຮອດຖືກຄັດກອງ ແລະ ຖືກຮັບ, ປະຕິເສດ ຫຼື ນັດໝາຍໂດຍບໍລິການຜູ້ຮັບ. ມັນເປັນຕົວຊີ້ວັດກະບວນການ (ການໄຫຼ) ທີ່ແຕກຕ່າງຈາກເວລາລໍຖ້າທັງໝົດຂອງຄົນເຈັບ ແລະ ເປັນໜຶ່ງໃນຈຸດທີ່ຊັດເຈນທີ່ສຸດທີ່ການປ່ຽນແປງລະບົບດິຈິຕອນ (e-referral ທີ່ມີໂຄງສ້າງ, ການຄັດກອງດ້ວຍຮູບພາບ, ແບບຟອມສົ່ງຕໍ່ມາດຕະຖານ) ສາມາດສະແດງໃຫ້ເຫັນວ່າຂັບເຄື່ອນຕົວເລກການດຳເນີນງານ ບໍ່ແມ່ນພຽງຄະແນນຄວາມພໍໃຈ.

## ເປັນຫຍັງຈຶ່ງສຳຄັນ

ຂັ້ນຕອນການຄັດກອງທີ່ຊ້າ ຫຼື ມີຄວາມຜັນແປສູງເພີ່ມຄວາມຊັກຊ້າກ່ອນທີ່ຄົນເຈັບຈະເຂົ້າສູ່ລາຍຊື່ລໍຖ້າທາງຄລີນິກເສຍອີກ ແລະ ເນື່ອງຈາກຄວາມຊັກຊ້ານັ້ນເກີດຂຶ້ນກ່ອນການດູແລທາງຄລີນິກຈະເລີ່ມ ມັນຈຶ່ງເປັນຂອງເສຍໃນກະບວນການລ້ວນໆທີ່ເຄື່ອງມືດິຈິຕອນຢູ່ໃນຕຳແໜ່ງທີ່ດີທີ່ຈະກຳຈັດ. ລະບົບສົ່ງຕໍ່ທີ່ບັງຄັບໃຫ້ມີວົງຈອນ "ສົ່ງກັບຄືນຜູ້ສົ່ງຕໍ່" ເມື່ອຂາດຂໍ້ມູນ ສ້າງວົງຈອນເຮັດຊ້ຳທີ່ງ່າຍທີ່ຈະມອງຂ້າມ ຖ້າວັດເວລາດຳເນີນການສະເພາະການສົ່ງຕໍ່ທີ່ຜ່ານຢ່າງສະອາດຕັ້ງແຕ່ຄັ້ງທຳອິດ. ເມື່ອບໍລິການນຳແບບຟອມສົ່ງຕໍ່ດິຈິຕອນທີ່ມີໂຄງສ້າງ, ຊ່ອງບັງຄັບຕື່ມ ຫຼື ການຄັດກອງດ້ວຍຮູບພາບ (ເຊັ່ນ ໃນ teledermatology) ມາໃຊ້ ເວລາດຳເນີນການມັກເປັນຕົວຊີ້ວັດດຽວທີ່ຊັກຊວນທີ່ສຸດໃນການສະແດງປະໂຫຍດ ເພາະສາມາດວັດກ່ອນ ແລະ ຫຼັງການປ່ຽນແປງດ້ວຍເຄື່ອງມືດຽວກັນ.

## ວິທີຄຳນວນ

```
ເວລາດຳເນີນການ = ເວລາ(ການຕັດສິນໃຈຄັດກອງ) − ເວລາ(ການສົ່ງຕໍ່)

ລາຍງານຄ່າມັດທະຍານ ແລະ ເປີເຊັນໄທລ໌ສູງ (ໂດຍທົ່ວໄປແມ່ນທີ 90) ບໍ່ແມ່ນສະເພາະຄ່າສະເລ່ຍ
ເພາະການແຈກຢາຍຖືກດຶງໄປທາງຂວາຫຼາຍຈາກການສົ່ງຕໍ່ທີ່ຖືກສົ່ງກັບຄືນ ຫຼື ຊັບຊ້ອນ.

ພິຈາລະນາເວລາຂອງຂັ້ນຕອນຍ່ອຍ ເມື່ອລະບົບບັນທຶກໄດ້:
  ການສົ່ງ → ບໍລິການໄດ້ຮັບ
  ໄດ້ຮັບ → ການຕັດສິນໃຈຄັດກອງ
  ການຕັດສິນໃຈຄັດກອງ → ນັດໝາຍທີ່ຈອງແລ້ວ (ເມື່ອກ່ຽວຂ້ອງ)
```

## ຕົວຢ່າງການຄຳນວນ

ບັນທຶກການກວດສອບຂອງລະບົບ e-referral ສະແດງວ່າເວລາມັດທະຍານຈາກການສົ່ງຈົນຮອດການຕັດສິນໃຈຄັດກອງແມ່ນ 1.8 ວັນໃນທຸກສາຂາ ໂດຍເວລາເປີເຊັນໄທລ໌ທີ 90 ແມ່ນ 6 ວັນ ເຊິ່ງສ່ວນໃຫຍ່ຖືກຂັບເຄື່ອນໂດຍການສົ່ງຕໍ່ທີ່ຖືກສົ່ງກັບຄືນຜູ້ສົ່ງຍ້ອນຂາດຂໍ້ມູນທາງຄລີນິກ. ເສັ້ນທາງ teledermatology ທີ່ໃຊ້ການຄັດກອງດ້ວຍຮູບພາບໃນແພລດຟອມດຽວກັນ ບັນລຸເວລາດຳເນີນການມັດທະຍານ 4 ຊົ່ວໂມງ ແລະ ເປີເຊັນໄທລ໌ທີ 90 ແມ່ນ 1 ວັນ ເພາະຮູບຖ່າຍ ແລະ ປະຫວັດທີ່ມີໂຄງສ້າງເກືອບສະເໝີພຽງພໍສຳລັບການຕັດສິນໃຈຄັດກອງ ໂດຍບໍ່ຕ້ອງຕິດຕໍ່ສື່ສານເພີ່ມເຕີມ.

## ແຫຼ່ງຂໍ້ມູນ ແລະ ຂໍ້ຄວນລະວັງ

ບັນທຶກການກວດສອບຂອງລະບົບ e-referral ຫຼື ລະບົບຈັດການການສົ່ງຕໍ່ເອງແມ່ນແຫຼ່ງຫຼັກ ໂດຍໃຊ້ເວລາທີ່ການສົ່ງ ແລະ ການຕັດສິນໃຈ; ອົງການຄວນຢືນຢັນວ່າ "ໂມງ" ຢຸດໃນຂະນະທີ່ການສົ່ງຕໍ່ຖືກສົ່ງກັບຄືນເພື່ອຂໍຂໍ້ມູນເພີ່ມເຕີມ ຫຼື ແລ່ນຕໍ່ເນື່ອງ ເພາະສອງນິຍາມໃຫ້ຕົວເລກທີ່ແຕກຕ່າງກັນຢ່າງມີນັຍສຳຄັນສຳລັບກະບວນການພື້ນຖານດຽວກັນ. ຄວນລາຍງານເວລາດຳເນີນການເປັນເວລາປະຕິທິນ ຫຼື ເວລາຊົ່ວໂມງເຮັດວຽກຢ່າງສອດຄ່ອງ ເພາະຜົນກະທົບຂອງທ້າຍອາທິດ ແລະ ວັນພັກສາມາດບິດເບືອນການປຽບທຽບລະຫວ່າງບໍລິການທີ່ມີຮູບແບບການເຮັດວຽກຕ່າງກັນ.

## ຈຸດອ່ອນທີ່ຄວນລະວັງ

- **ການວັດສະເພາະການສົ່ງຕໍ່ທີ່ "ສະອາດ"**: ການຕັດການສົ່ງຕໍ່ທີ່ຖືກປະຕິເສດ ຫຼື ສົ່ງກັບຄືນອອກຈາກການຄຳນວນປິດບັງພາລະການເຮັດຊ້ຳ ທີ່ເຄື່ອງມືດິຈິຕອນມັກມີຈຸດປະສົງສະເພາະທີ່ຈະຫຼຸດ.
- **ການລາຍງານຄ່າສະເລ່ຍແທນຄ່າມັດທະຍານ ແລະ ເປີເຊັນໄທລ໌**: ການສົ່ງຕໍ່ທີ່ໃຊ້ເວລາດົນ ແລະ ຖືກສົ່ງກັບຄືນຈຳນວນນ້ອຍສາມາດດຶງຄ່າສະເລ່ຍໃຫ້ສູງກວ່າປະສົບການຕົວຈິງຂອງຄົນເຈັບທົ່ວໄປຫຼາຍ.
- **ການສັບສົນເວລາດຳເນີນການກັບເວລາລໍຖ້າທັງໝົດ**: ເວລາດຳເນີນການກວມສະເພາະຂັ້ນຕອນການຄັດກອງ; ປະສົບການທັງໝົດຂອງຄົນເຈັບຍັງລວມລາຍຊື່ລໍຖ້າທາງຄລີນິກຂັ້ນຕອນຕໍ່ໄປ ເຊິ່ງເປັນຕົວຊີ້ວັດແຍກຕ່າງຫາກທີ່ຖືກຄວບຄຸມໂດຍຂໍ້ຈຳກັດດ້ານກຳລັງການຮອງຮັບແຍກຕ່າງຫາກ.
- **ການບໍ່ແຍກຂັ້ນຕອນຍ່ອຍ**: ບໍລິການທີ່ວັດສະເພາະເວລາຈາກຕົ້ນຈົນຈົບບໍ່ສາມາດບອກໄດ້ວ່າຕົວເລກທີ່ຊ້າເກີດຈາກຜູ້ສົ່ງຕໍ່ສົ່ງຂໍ້ມູນບໍ່ຄົບ, ຈາກກຳລັງການຄັດກອງຂອງບໍລິການຜູ້ຮັບ ຫຼື ທັງສອງ.
